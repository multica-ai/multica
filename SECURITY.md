# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**, or use [this link](https://github.com/multica-ai/multica/security/advisories/new). Do not open a public issue, pull request, or discussion for a vulnerability.

Include the affected component, the version or commit, steps to reproduce, and the impact you observed. We acknowledge reports, keep the reporter updated in the advisory, and credit the reporter when the advisory is published unless they prefer otherwise.

## Fixing a Vulnerability

Maintainers fix a reported vulnerability in the advisory's temporary private fork, release the fix, and then publish the advisory. A public pull request for a security fix describes the corrected behavior only, as described in [AGENTS.md](AGENTS.md#public-repository-writing).

## Supported Versions

Security fixes ship in the latest release. Self-hosted deployments receive them by upgrading to the latest release.
