# CodeGraph introduction captures

These PNGs are cropped from the actual Multica contribution UI in the local
review environment. They show registration, the three usage scopes and a
successful symbol query against the public
[`expressjs/serve-static`](https://github.com/expressjs/serve-static) repository.
No generated UI, provider conversation or simulated agent data is shown.

Captures exclude application navigation, account details, host addresses, tokens
and credential values. Registration explicitly uses anonymous access to this
public repository. A zero assignment count reflects the real review state.

Each scene has light/dark and English/Simplified Chinese variants. Other UI
languages use the English captures; Chinese locales use the Chinese captures.
The scope thumbnail displays three crops of the same image for readability;
opening the image shows the original three-column capture.

When the depicted controls change, refresh these crops from the real application
and review both themes. Keep screenshot changes in the same contribution as the
corresponding interface changes.
