# Autopilots source map

- `server/cmd/multica/cmd_autopilot.go` registers `list`, `get`, `create`, `update`, `delete`, `trigger`, `runs`, `trigger-add`, `trigger-update`, `trigger-delete`, `trigger-rotate-url` → `/api/autopilots`, `/api/autopilots/{id}/trigger`, `/api/autopilots/{id}/runs`, trigger subroutes.
- `server/internal/service/autopilot.go`: `DispatchAutopilot`, `AdmitAutopilotWebhookDelivery` (sync, idempotent), `DispatchAutopilotForWebhookDelivery` (worker); creates `autopilot_run`, switches on `execution_mode`: `create_issue`→`dispatchCreateIssue`, `run_only`→`dispatchRunOnly`. `resolveAutopilotLeader` → squad leader; `AgentReadiness` blocks unready agents.
- Ingress: `server/cmd/server/router.go` — authenticated `/api/autopilots` + unauth webhook `/api/webhooks/autopilots/{token}`; `server/internal/handler/autopilot_webhook.go` stores deliveries, admits idempotent run for `200 accepted|skipped` + `run_id`; `server/internal/handler/webhook_delivery_worker.go` claims queued deliveries with expiring DB leases, resumes via `autopilot_run.webhook_delivery_id` (no duplicate runs).
- `GET /api/autopilots/cron-preview?expr=&tz=` (`server/internal/handler/autopilot_cron_preview.go`) → `{next_runs}` (3 × RFC3339 UTC) or `400`; compute-only, workspace-gated.
- Authz (`server/internal/handler/autopilot.go`): write = creator/owner-admin/collaborator (`autopilotWriteByOwnership`, `memberCanWriteAutopilot`, `requireAutopilotWrite`); reads open; `GetAutopilot` redacts `webhook_token`/`webhook_path`/`webhook_url` for non-writers. Dispatch-time gate: `shouldSkipDispatch` (ANDed).
- Collaborators: `autopilot_collaborator` table (migration 128), `POST /api/autopilots/{id}/collaborators` (`{user_id}`) / `DELETE .../{userId}` → updated `{collaborators}`; gated by narrower `requireAutopilotAccessManagement` (no re-grant/revoke — no privilege escalation); `GetAutopilot` stamps `can_write`, `can_manage_access`; UI: `packages/views/autopilots/components/manage-access-dialog.tsx`.
