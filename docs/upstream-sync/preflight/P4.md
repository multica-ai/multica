# P4 — Migrations multi-dir

**Verdict:** PASS — with critical context.

**Hypothesis:** The migrate tool can be modified to scan TWO migration directories (`server/migrations/` upstream + `server/migrations/cerebro/` cerebro) and run them in deterministic order.

## What we found

- **Tool:** custom Go migrator, ~140 LOC, `server/cmd/migrate/main.go`. No external library — uses `pgxpool` directly + `schema_migrations(version TEXT PK)`.
- **Discovery (lines 60-78):**
  ```go
  files, _ := filepath.Glob(filepath.Join(migrationsDir, "*"+suffix))
  sort.Strings(files)
  ```
  Trivial to extend.
- **Highest upstream migration:** `067_task_queue_claim_candidate_index` (on `upstream/main`).
- **CRITICAL:** cerebro fork already has 20 files matching `9NNN_*.sql` living in `server/migrations/` (not yet split). Examples: `9001_artifact`, `9008_member_enforcement_toggles`, `9009_project_access`. **The split is the work, not a precondition.**
- **`idempotent_test.go`** also globs `*.up.sql` in one dir — must be updated in lockstep.

## Multi-dir pattern (minimal diff)

```go
dirs := []string{"server/migrations", "server/migrations/cerebro"}
var files []string
for _, d := range dirs {
    matches, _ := filepath.Glob(filepath.Join(d, "*"+suffix))
    files = append(files, matches...)
}
sort.Slice(files, func(i, j int) bool {
    return filepath.Base(files[i]) < filepath.Base(files[j])  // basename sort
})
```

The basename sort is the key trick — `9001_*` sorts after `067_*` regardless of directory.

## Risks / gotchas

- **Namespace clash:** upstream at 067, growing ~1 migration/PR. Gap of ~9000 won't be reached for years. Document reservation in `server/migrations/cerebro/README.md` + add CI lint rejecting new `server/migrations/9*.sql` outside `cerebro/` subdir.
- **Transactions:** current tool has no per-pass transaction — partial failure already leaves inconsistent state. Multi-dir doesn't change this. Mitigated by idempotency contract.
- **Down-migrations:** current code reverses the same sorted slice — multi-dir merge + reverse-sort works identically.
