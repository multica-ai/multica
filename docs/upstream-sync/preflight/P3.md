# P3 — sqlc multi-source

**Verdict:** PASS

**Hypothesis:** sqlc.yaml can be configured to read queries from BOTH `server/pkg/db/queries/` and `server/internal/cerebro/queries/`, generating Go code from both sources without conflict.

## What we did

1. Read `server/sqlc.yaml`: single-package, `version: "2"`, queries `pkg/db/queries/`, schema `migrations/`, output `pkg/db/generated`, package `db`, driver `pgx/v5`.
2. Confirmed sqlc binary version: **v1.31.1** (homebrew). v2-config supports multi-package via list under `sql:`.
3. Empirical proof in `/tmp/preflight-P3/`: scratch sqlc.yaml with two entries pointing to two query+migration roots. `sqlc generate` produced two independent Go packages with their own `db.go` and `models.go`. No conflict.
4. Confirmed `Makefile:220` runs `cd server && sqlc generate` — same command picks up extra entries with no Makefile change.

## Risks / gotchas

- **Cross-package struct collisions:** if cerebro reads upstream tables via sqlc, naming is independent (different Go packages, different import paths) but cerebro's `schema` must list the upstream migrations dir too — sqlc reads schema from DDL, not a live DB.
- **No build-tag conflict:** each `out` is a different Go package.
- **Migration ordering:** sqlc orders SQL files alphabetically inside a directory; two separate `schema` dirs are independent unless explicitly listed together.

## Phase 0 recommendations

- Generated code: `server/internal/cerebro/db/generated/`, package `cerebrodb` (avoids collision with `db` alias).
- Cerebro queries: `server/internal/cerebro/queries/`. Cerebro migrations: `server/internal/cerebro/db/migrations/` (or shared `server/migrations/cerebro/` per P4 split).
- Naming convention: prefix cerebro tables with `cerebro_` (already in use: `cerebro_kickback`, `cerebro_pricelist`).
- If cerebro queries reference upstream tables, set `schema` to a list: `["migrations/", "internal/cerebro/db/migrations/"]` on the cerebro entry only.

### Concrete sqlc.yaml diff

```yaml
  - engine: "postgresql"
    queries: "internal/cerebro/queries/"
    schema:
      - "migrations/"
      - "internal/cerebro/db/migrations/"
    gen:
      go:
        package: "cerebrodb"
        out: "internal/cerebro/db/generated"
        sql_package: "pgx/v5"
        emit_json_tags: true
        emit_empty_slices: true
```
