# Repository Guidelines

**Read [`CLAUDE.md`](CLAUDE.md) first.** It is the authoritative file for architecture, coding rules, and conventions in this repository, and it applies to every agent regardless of which tool you are running under.

This file exists only so that agents looking for `AGENTS.md` find their way there. It deliberately restates nothing — a second copy of a rule is a rule that will eventually disagree with itself.

Two more pointers:

- [`docs/AGENTS.md`](docs/AGENTS.md) — the documentation standard: which tier a document belongs to, and the rules every document follows.
- `Makefile`, `package.json`, and `pnpm-workspace.yaml` — the source of truth for the command list.
