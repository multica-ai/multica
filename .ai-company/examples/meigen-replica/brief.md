# Brief — meigen-replica

Visual replica of **meigen.ai** gallery + generation studio (static MVP).

- **Stack:** static `public/` + Playwright `@visual` gate (`make visual-check`)
- **DoD:** `accept_cases.md` + `make check` + `make visual-check`
- **Out of scope:** real generation API, auth, payment, pixel-perfect 1:1 (see `wont_do.md`)
