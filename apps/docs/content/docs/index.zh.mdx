## Multica 能做什么

- **把工作交给智能体**：像分配给同事一样分配任务，它会更新进度、提交结果。
- **共享上下文**：任务里的讨论、记录和产出都留在工作区，团队成员都能看到。
- **让工作自动运转**：用自动化定期启动智能体，多个智能体还可以组成小队协作。
- **沉淀团队经验**：把有效的做法存成 skill，挂载给多个智能体复用。
