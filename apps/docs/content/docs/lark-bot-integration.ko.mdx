Multica 에이전트를 Feishu Bot으로 연결하면 팀 멤버가 Feishu에서 에이전트와 DM을 나누고 그룹에서 @멘션하거나 `/issue`로 이슈를 만들 수 있습니다. 대화와 실행 기록은 계속 Multica 워크스페이스에 저장됩니다.

Bot 하나는 에이전트 하나에만 대응합니다. Feishu에서 여러 에이전트를 사용하려면 각 에이전트에 별도의 Bot을 연결하세요.

## Bot 연결

에이전트 owner, 워크스페이스 owner, admin이 연결을 시작할 수 있습니다.

1. **에이전트**를 열고 Feishu에 연결할 에이전트를 선택합니다.
2. **연동**으로 이동해 **Feishu에 연결**을 클릭합니다.
3. Feishu로 QR 코드를 스캔하고 승인을 확인합니다.
4. Multica로 돌아옵니다. 페이지에 **Feishu에 연결됨**이 표시되면 사용할 수 있습니다.

QR 코드는 일회용 자격 증명이며 만료되면 다시 생성하면 됩니다. 이미 연결된 에이전트에는 스캔 메뉴가 다시 표시되지 않습니다. 이름이나 권한을 조정하려면 **Feishu에서 관리**를 클릭하세요.

<Callout type="info">
현재 새 연결은 중국 본토 버전 Feishu에서만 만들 수 있습니다. 기존 국제 버전 Lark 연결은 계속 사용하고 관리할 수 있습니다.
</Callout>

## 처음 사용

멤버가 Bot에 처음 메시지를 보내면 계정 연결 링크를 받습니다.

1. 링크를 열고 Multica에 로그인합니다.
2. 연결할 워크스페이스 계정을 확인합니다.
3. Feishu로 돌아가 메시지를 다시 보냅니다.

연결을 마쳐야 Multica가 메시지를 보낸 워크스페이스 멤버를 확인할 수 있습니다. 멤버가 아닌 사람은 Bot을 사용할 수 없습니다.

## Feishu에서 작업 요청

### DM

Bot에 바로 메시지를 보내면 됩니다. 연속된 메시지는 같은 Multica 대화에 유지되며 에이전트의 답변도 현재 대화로 돌아옵니다.

### 그룹 채팅

먼저 Bot을 그룹 채팅에 추가한 뒤 `@Bot`과 요구 사항을 함께 작성합니다. Bot은 자신을 명시적으로 @멘션한 메시지에만 응답합니다. 실행할 때는 현재 대화에서 읽을 수 있는 최근 컨텍스트를 함께 사용합니다.

### 이슈 만들기

다음과 같이 보냅니다.

```text
/issue 로그인 후 리디렉션 문제 수정
Safari에서 로그인에 성공해도 로그인 페이지에 계속 머뭅니다.
```

첫 줄이 제목이 되고 나머지 내용이 설명이 됩니다. `/issue`만 보내면 Multica가 이전 메시지를 제목으로 사용하려고 시도합니다.

## 연결 관리

**설정 → 연동**에서 워크스페이스에 연결된 Bot을 확인할 수 있습니다. 워크스페이스 owner와 admin은 여기서 연결을 해제할 수 있고, 에이전트 owner도 해당 에이전트의 **연동** 페이지에서 자신의 Bot을 관리할 수 있습니다.

연결을 해제하면 Bot이 새 메시지를 받지 않습니다. 기존 대화와 감사 기록은 함께 삭제되지 않습니다.

## 자체 호스팅 설정

Multica Cloud에는 추가 설정이 필요 없습니다. 자체 호스팅 환경에서는 Bot 자격 증명 암호화에 사용할 키를 먼저 설정해야 합니다.

```dotenv
MULTICA_LARK_SECRET_KEY=<base64로 인코딩한 32바이트 키>
```

다음과 같이 생성할 수 있습니다.

```bash
openssl rand -base64 32
```

API 서비스를 다시 시작한 뒤 에이전트의 **연동** 페이지에서 Bot을 연결하세요. 이 키는 장기간 보관해야 합니다. 키를 바꾸거나 잃어버리면 기존 자격 증명을 복호화할 수 없으므로 다시 연결해야 합니다.

`MULTICA_LARK_HTTP_BASE_URL`과 `MULTICA_LARK_CALLBACK_BASE_URL`은 프록시, 테스트 같은 특수한 배포에서만 사용하며 일반적으로 설정할 필요가 없습니다.

## 자주 묻는 문제

- **연결 버튼이 없음**: 현재 계정이 에이전트 owner, 워크스페이스 owner, admin인지 확인하고 자체 호스팅 키가 설정되었는지 확인합니다.
- **QR 코드 만료**: 팝업을 닫고 연결을 다시 시작합니다.
- **Bot이 계정 연결을 요구함**: 연결 링크를 열고 해당 워크스페이스의 Multica 계정으로 로그인합니다.
- **Bot이 실행되지 않음**: 에이전트가 보관 처리되었는지, 사용하는 [런타임](/daemon-runtimes)이 온라인인지 확인합니다.
