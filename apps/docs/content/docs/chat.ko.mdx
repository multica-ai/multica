대화는 아직 명확한 이슈가 되지 않은 작업에 적합합니다. 아이디어를 정리하고, 워크스페이스 상황을 조회하고, 방안을 논의하거나, 에이전트에게 작은 태스크를 먼저 맡길 수 있습니다.

**대화(Chat)는 당신과 [에이전트](/agents) 사이의 일대일 소통입니다** — [이슈](/issues) 보드에서 벗어나는 것입니다. 에이전트는 기본적으로 **이슈 컨텍스트가 없으며** — 당신의 보드를 보고 있지 않고, 대화를 스스로 이슈로 바꾸지도 않습니다 — 대화 전체가 **완전히 비공개**입니다([워크스페이스](/workspaces) 내의 다른 누구도, admin을 포함해서, 이 대화를 볼 수 없습니다). 에이전트와 접근 방식을 논의하거나, 브레인스토밍을 하거나, 어떤 이슈에도 속하지 않는 질문을 하기에 적합합니다.

대화는 **특정 이슈에 연결되지 않습니다**. 에이전트가 이슈 설명과 댓글을 자동으로 받지는 않지만, 권한 범위 안에서 Multica CLI로 워크스페이스, 프로젝트, 이슈, 스킬을 조회할 수 있습니다.

대화에 배경을 추가할 수도 있습니다. 입력란 왼쪽 아래의 **+**를 클릭하고 **프로젝트 컨텍스트**를 선택해 대화에 [프로젝트](/projects)를 연결하세요. 에이전트는 실행할 때 해당 프로젝트의 설명과 저장소 같은 리소스를 받습니다.

![에이전트와의 대화: 질문에 표로 정리된 답변이 돌아온 모습](/images/docs/chat-conversation.webp)

## 대화 시작

1. 사이드바에서 **대화**를 엽니다.
2. 새 대화를 클릭하고 실행 권한이 있는 에이전트를 선택합니다.
3. 메시지를 입력합니다. 이미지나 파일을 첨부할 수도 있습니다.
4. 전송하면 Multica가 이 메시지에 대한 실행을 만들고 답변은 현재 대화로 돌아옵니다.

런타임이 오프라인이면 다시 온라인이 될 때까지 메시지가 기다립니다. 에이전트가 보관 처리되거나 호출 권한을 잃으면 새 메시지를 보낼 수 없습니다.

첫 메시지를 보내기 전에 선택한 에이전트에 설정된 추천이 최대 3개 표시됩니다. 선택하면 전체 프롬프트가 전송되지 않고 입력창에 채워져 먼저 수정할 수 있습니다. 추천이 없는 에이전트에는 현지화된 범용 예시가 사용됩니다.

## 대화와 이슈 선택

| 필요 | 더 적합한 방식 |
|---|---|
| 빠른 질문, 방안 탐색, 개인 초안 처리 | **대화** |
| 담당자, 상태, 우선순위, 결과물을 명확히 지정 | **이슈** |
| 팀 멤버가 배경을 확인하고 논의를 이어가게 하기 | **이슈** |
| 작업 기록을 만들 필요 없이 워크스페이스 정보를 임시로 확인 | **대화** |

Multica에서 만든 직접 대화는 만든 사람만 볼 수 있으며 다른 워크스페이스 멤버와 관리자도 읽을 수 없습니다. 팀이 함께 확인해야 하는 결론은 이슈, 프로젝트 설명, 스킬 중 하나로 정리하세요.

## 여러 대화 턴의 컨텍스트

같은 대화에서는 가능한 한 AI 코딩 도구의 기존 세션을 이어가므로 이후 메시지에서 앞선 내용을 반복할 필요가 없습니다. Multica는 세션 식별자를 저장하고, 이후 실행을 해당 세션에 접근할 수 있는 런타임으로 라우팅합니다.

로컬 세션이 더 이상 존재하지 않거나 컨텍스트를 이어갈 수 없거나 이전 오류가 재사용에 적합하지 않으면 런타임이 새 세션을 시작합니다. 대화의 이전 메시지는 그대로 남습니다.

## 실행 확인 및 중지

에이전트가 실행 중이면 화면에 현재 단계와 도구 활동이 표시됩니다. **상세 보기**를 펼치면 더 자세한 실행 과정을 확인할 수 있습니다.

중단하려면 입력란 옆의 중지 버튼을 클릭하세요. 대화에 이미 반환된 내용은 유지되며 아직 처리를 시작하지 않은 입력은 가능한 경우 편집란으로 복원됩니다.

## 대화 목록 정리

대화는 이름 변경, 고정, 보관, 삭제할 수 있습니다.

- **고정**하면 자주 쓰는 대화가 목록 앞쪽에 유지됩니다.
- **보관**하면 대화가 "보관됨"으로 이동하고 읽기 전용이 됩니다.
- **보관 해제**하면 메시지를 다시 보낼 수 있습니다.
- **삭제**하면 대화와 그 안의 메시지가 영구적으로 제거됩니다.

대화가 Slack 같은 외부 채널에 연결되어 있다면 보관할 때 연결이 끊어집니다. 보관을 해제해도 연결은 복원되지 않으므로 다시 연결해야 합니다.

<Callout type="warning">
대화 삭제는 취소할 수 없으며 아직 끝나지 않은 실행도 중지합니다. 당분간 필요하지 않다면 보관하세요.
</Callout>
