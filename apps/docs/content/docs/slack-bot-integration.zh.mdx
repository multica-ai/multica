已有 Slack Bot 连接会继续保留 Slack app 与一个[智能体](/agents)的映射。成员仍可私聊 Bot、在频道中 @ 它、发送文件，以及使用 `/issue`。

<Callout type="info">
  新的智能体级 Slack 连接入口已退役。已有连接继续运行，并显示在 **Settings → Integrations**。
</Callout>

## 使用已有 Bot

- 私聊会成为与已绑定智能体的 Multica [Chat](/chat)。
- 频道和群聊中只有 @ Bot 的消息会触发运行。
- 符合条件的消息所带文件会复制到 Multica 存储，供智能体使用。
- **`/issue <标题>`** 会以已绑定工作区成员的身份创建 issue。
- **`/new <消息>`** 会保留历史，但不带之前的对话上下文运行。

首次发消息时可能会返回一次性的账号绑定链接。请使用属于该工作区的 Multica 账号打开。这个身份回调是独立合同，不是新的智能体连接。

## 管理保留连接

在 **Settings → Integrations** 查看已有 Bot 及其已绑定智能体。工作区所有者和管理员可以断开连接；已有对话和审计记录会继续保留。

## 自部署

已有加密 Slack 凭证需要 `MULTICA_SLACK_SECRET_KEY`。请稳定保留这个密钥，否则已保存的凭证将无法解密。Socket Mode 主动向外连接，因此保留连接不需要公开 Request URL。

## 故障排查

- **没有新的连接操作**：智能体级浏览器连接已退役。
- **Bot 不响应**：确认保留连接仍为 active、已绑定智能体未归档，并且 [Runtime](/daemon-runtimes) 在线。
