아래 키는 macOS 기준으로 적었습니다. Windows와 Linux에서는 `⌘`를 `Ctrl`로 바꿔 읽으면 되고, 표에는 두 가지를 모두 적어 두었습니다.

## 검색

`⌘K`를 누르거나 사이드바 위쪽의 **검색...**을 클릭하면 검색 창이 열립니다. 아무것도 입력하지 않으면 **새 태스크**와 최근에 연 태스크가 보입니다. 키워드를 입력하면 결과가 그룹별로 표시됩니다.

| 그룹 | 찾을 수 있는 것 |
|---|---|
| **페이지** | 인박스, 채팅, 태스크, 프로젝트, 에이전트, 설정 같은 워크스페이스 페이지. |
| **명령어** | 새 태스크, 새 프로젝트, 라이트·다크·시스템 테마로 전환. 태스크 상세를 열어 둔 상태에서는 태스크 링크 복사, 식별자 복사, 모든 댓글 접기, 모든 댓글 펼치기도 나옵니다. |
| **멤버** | 이름이나 이메일로 찾습니다. |
| **워크스페이스** | 내가 속한 다른 워크스페이스. 선택하면 그쪽으로 전환됩니다. |
| **프로젝트**, **태스크** | 제목뿐 아니라 프로젝트 설명, 태스크 설명, 댓글도 검색합니다. 일치한 부분이 결과 아래에 표시되고, 완료된 태스크도 포함됩니다. |
| **취소됨** | 취소된 프로젝트와 태스크는 다른 결과와 섞이지 않고 맨 끝에 모아서 표시됩니다. |

결과를 선택하면 바로 이동합니다. `⌘`(Windows / Linux에서는 `Ctrl`)를 누른 채 클릭하거나 Enter를 누르면 새 탭에서 엽니다. `Esc`로 검색 창을 닫습니다.

## 키보드 단축키

| 동작 | macOS | Windows / Linux | 참고 |
|---|---|---|---|
| 검색 열기 | `⌘K` | `Ctrl+K` | |
| 태스크 만들기 | `C` | `C` | 평소 쓰는 생성 방식을 엽니다. 프로젝트 페이지에서 누르면 그 프로젝트가 미리 채워집니다. |
| 왼쪽 사이드바 전환 | `⌘B` | `Ctrl+B` | |
| 오른쪽 사이드바 전환 | `⌘/` | `Ctrl+/` | 태스크 상세처럼 오른쪽 사이드바가 있는 페이지에서만 쓸 수 있습니다. |
| 채팅 창 전환 | `⌘J` | `Ctrl+J` | 열면 커서가 메시지 입력란에 놓입니다. [어느 페이지에서나 채팅하기](/chat#어느-페이지에서나-채팅하기)를 참고하세요. |
| 태스크에서 찾기 | `⌘F` | `Ctrl+F` | 아래 설명 참고. |
| 알림 보관 | `E` | `E` | 인박스에서 열어 둔 알림을 보관합니다. 보관함을 보는 중에는 보관을 해제합니다. |
| 보내기 | `⌘↵` | `Ctrl+Enter` | 댓글과 채팅 메시지를 보내고, 새 태스크를 만들 때도 씁니다. |
| 뒤로 가기 | `⌘[` | `Ctrl+[` | |
| 앞으로 가기 | `⌘]` | `Ctrl+]` | |

키 하나짜리 단축키(`C`, `E`)와 뒤로 가기·앞으로 가기는 입력란에서 글을 쓰는 동안에는 동작하지 않습니다.

**탐색** 그룹에는 인박스, 채팅, 내 태스크, 태스크, 프로젝트, 자동화, 에이전트, 스쿼드, 사용량, 런타임, Skills, 설정으로 이동하는 동작도 있습니다. 모두 기본 키가 없으니 자주 쓰는 것에 직접 지정하세요.

### 고정 시스템 단축키

아래 단축키는 바꿀 수 없습니다. `Esc`를 제외하면 [데스크톱 앱](/desktop-app)에서만 동작하고, 브라우저에서는 브라우저가 이 키를 처리합니다.

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 설정 열기 | `⌘,` | `Ctrl+,` |
| 활성 탭 닫기 | `⌘W` | `Ctrl+W` |
| 1~8번째 탭 선택 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 마지막 탭 선택 | `⌘9` | `Ctrl+9` |
| 확대 / 축소 / 확대/축소 재설정 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 대화상자 또는 메뉴 닫기 | `Esc` | `Esc` |

## 단축키 바꾸기

<Steps>
<Step>

**설정 → 단축키**를 엽니다. 동작이 많을 때는 위쪽 검색란에서 이름으로 찾으세요.

</Step>
<Step>

동작 오른쪽의 키를 클릭하고 '키를 누르세요'가 보이면 새 조합을 누릅니다. `Esc`는 취소, `Delete`는 그 동작의 키를 지웁니다.

</Step>
<Step>

각 행 오른쪽 끝의 두 버튼으로 그 동작을 기본값으로 되돌리거나 사용하지 않게 할 수 있습니다. 위쪽의 **기본값 복원**은 모든 사용자 지정을 한 번에 되돌립니다.

</Step>
</Steps>

단축키는 지금 쓰는 기기에만 저장됩니다. 다른 컴퓨터를 쓰거나 브라우저와 데스크톱 앱을 오갈 때는 다시 설정해야 합니다.

다음 조합은 등록되지 않으며, 키 아래에 이유가 표시됩니다.

- 이미 다른 동작에 지정된 조합.
- 브라우저, 데스크톱 창, 운영체제가 쓰는 조합. 예를 들어 `⌘W`, `⌘R`, `⌘Q`, `⌘,`, 복사·붙여넣기 같은 편집 키, `⌘0`–`⌘9`, 확대/축소 키입니다. 브라우저에서는 `⌘P`, `⌘L`, `⌘T`, `⌘N`, `⌘D`, `⌘U`도 쓸 수 없지만 데스크톱 앱에서는 쓸 수 있습니다. Windows와 Linux에서는 Win / Super 키가 들어간 조합을 모두 쓸 수 없습니다.
- 검색 열기, 채팅 창 전환, 태스크에서 찾기처럼 입력란에서도 동작하는 단축키에는 `⌘`, `Ctrl`, `Control` 중 하나가 있어야 합니다. 글을 쓰다가 잘못 실행되지 않게 하기 위해서입니다.
- **보내기**에는 `↵`나 `⌘↵`만 쓸 수 있습니다.

<Callout>
**보내기**를 `↵`로 바꾸면 줄바꿈은 `Shift+Enter`로 합니다. 단락을 넣거나, 목록을 이어 가거나, 코드 블록에서 줄을 바꿀 수 있습니다.
</Callout>

## 태스크에서 찾기

태스크 상세 페이지에서 `⌘F`를 누르면 브라우저 찾기 대신 Multica의 찾기 막대가 열립니다. 브라우저 찾기는 화면에 그려진 댓글만 찾지만, 이 막대는 제목, 설명, 모든 댓글을 포함한 타임라인 전체를 검색합니다.

대소문자는 구분하지 않습니다. 찾기 막대에는 '현재/전체' 개수가, 결과가 없으면 '일치 항목 없음'이 표시됩니다. `↵`는 다음 항목, `Shift+Enter`는 이전 항목으로 이동하고 `Esc`로 닫습니다. 중간에 서식이 바뀌는 문자열(절반만 굵게 등)은 찾지 못합니다.

데스크톱 앱에서는 지금 보이는 탭만 `⌘F`에 반응합니다.

## 환경설정

개인 설정은 **설정 → 환경설정**에 있고, 바꾸면 바로 적용됩니다. 그룹마다 저장 위치가 다릅니다.

| 그룹 | 설정 | 저장 위치 |
|---|---|---|
| **언어 및 지역** | 언어: English, 中文, 한국어, 日本語, Français. 바꾸면 페이지가 다시 로드됩니다.<br />시간대: 기본값은 브라우저를 따릅니다. 모든 워크스페이스의 날짜와 차트에 쓰이며, 전체 시간대에서 검색해 고를 수 있습니다. | 계정(다른 기기에도 동기화) |
| **모양** | 테마: 라이트, 다크, 시스템. 검색 창에 '테마'를 입력해 바꿀 수도 있습니다. | 이 기기 |
| **댓글 및 채팅** | **댓글 입력란을 하단에 고정**: 긴 타임라인을 읽는 동안에도 댓글 입력란이 보입니다.<br />**실행 중인 에이전트에 답장할 때**: 기본값을 '현재 실행에 추가'와 '이번 실행 후 시작' 중 무엇으로 할지 정합니다. 보내기 전에 메시지마다 바꿀 수 있습니다. [실행 중인 에이전트에게 끼어들기](/mentioning-agents#실행-중인-에이전트에게-끼어들기)를 참고하세요.<br />**플로팅 채팅 창**: 끄면 오른쪽 아래 채팅 버튼이 더 이상 표시되지 않습니다. | 이 기기 |
| **태스크 열기** | 카드나 행을 클릭했을 때 전체 페이지와 사이드 미리보기 중 어디로 열지 정합니다. Shift+클릭하면 다른 쪽으로 열립니다. | 이 기기 |
| **태스크 생성 시 표시할 필드** | '에이전트로 생성'과 '수동 생성' 각각의 툴바에 항상 표시할 필드. 숨긴 필드도 ⋯ 메뉴에서 쓸 수 있고, 값이 있는 동안에는 자동으로 표시됩니다. | 이 기기의 현재 워크스페이스 |
