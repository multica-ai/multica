아래 키는 macOS 기준으로 적었습니다. Windows와 Linux에서는 `⌘`를 `Ctrl`로 바꿔 읽으면 되고, 표에는 두 가지를 모두 적어 두었습니다.

## 검색

`⌘K`를 누르거나 앱 레일의 **검색...** 을 클릭하면 검색 창이 열립니다. 아무것도 입력하지 않으면 **새 태스크**와 최근에 연 태스크가 보입니다. 키워드를 입력하면 결과가 그룹별로 표시됩니다.

| 그룹 | 찾을 수 있는 것 |
|---|---|
| **페이지** | 인박스, 채팅, 태스크, 프로젝트, 에이전트, 설정 같은 워크스페이스 페이지. |
| **뷰** | 기본 태스크 뷰와 접근 가능한 저장된 뷰를 이름으로 찾습니다. |
| **명령어** | 새 태스크, 새 프로젝트, 라이트·다크·시스템 테마로 전환. 태스크 상세를 열어 둔 상태에서는 태스크 링크 복사, 식별자 복사, 모든 댓글 접기, 모든 댓글 펼치기도 나옵니다. |
| **멤버** | 이름이나 이메일로 찾습니다. |
| **워크스페이스** | 내가 속한 다른 워크스페이스. 선택하면 그쪽으로 전환됩니다. |
| **프로젝트**, **태스크** | 제목뿐 아니라 프로젝트 설명, 태스크 설명, 댓글도 검색합니다. 일치한 부분이 결과 아래에 표시되고, 완료된 태스크도 포함됩니다. |
| **취소됨** | 취소된 프로젝트와 태스크는 다른 결과와 섞이지 않고 맨 끝에 모아서 표시됩니다. |
| **에이전트에게 맡기기** | 입력하는 동안 항상 마지막 행에 표시됩니다. 선택하면 **에이전트로 만들기**가 열리고, 입력한 내용과 현재 프로젝트가 채워지며 열려 있는 태스크가 상위 태스크가 됩니다. 거기서 확인하기 전에는 아무것도 만들어지지 않습니다. |

결과를 선택하면 바로 이동합니다. `⌘`(Windows / Linux에서는 `Ctrl`)를 누른 채 클릭하거나 Enter를 누르면 새 탭에서 엽니다. `Esc`로 검색 창을 닫습니다.

## 키보드 단축키

입력란 밖이라면 어디서든 `?`를 누르면 모든 단축키를 볼 수 있습니다. 지금 페이지에서 쓰는 그룹이 **현재 페이지** 표시와 함께 맨 앞에 오고, 위쪽 칸에 입력하면 이름으로 걸러 볼 수 있습니다. 아래쪽 링크는 **설정 → 단축키**를 엽니다.

| 동작 | macOS | Windows / Linux | 참고 |
|---|---|---|---|
| 키보드 단축키 보기 | `?` | `?` | |
| 검색 열기 | `⌘K` | `Ctrl+K` | |
| 태스크 만들기 | `C` | `C` | 평소 쓰는 생성 방식을 엽니다. 프로젝트 페이지에서 누르면 그 프로젝트가 미리 채워집니다. |
| 왼쪽 사이드바 전환 | `⌘B` | `Ctrl+B` | |
| 오른쪽 사이드바 전환 | `⌘/` | `Ctrl+/` | 태스크 상세처럼 오른쪽 사이드바가 있는 페이지에서만 쓸 수 있습니다. |
| 채팅 창 전환 | `⌘J` | `Ctrl+J` | 열면 커서가 메시지 입력란에 놓입니다. [어느 페이지에서나 채팅하기](/chat#어느-페이지에서나-채팅하기)를 참고하세요. |
| Multica에 묻기 | `⇧⌘J` | `Ctrl+Shift+J` | 플로팅 채팅 창에서 새 채팅을 시작합니다. |
| 태스크에서 찾기 | `⌘F` | `Ctrl+F` | 아래 설명 참고. |
| 알림 보관 | `E` | `E` | 인박스 페이지에서 열어 둔 알림을 보관하고 다음 알림을 엽니다. 보관됨 탭에서는 열어 둔 알림을 인박스로 되돌립니다. [인박스](/inbox#알림-처리)를 참고하세요. |
| 구독 해제 후 보관 | `⇧E` | `Shift+E` | 인박스 페이지에서 열어 둔 알림의 태스크 구독을 해제하고 보관한 뒤 다음 알림을 엽니다(나 또는 내 에이전트의 태스크가 아닐 때 사용 가능). [인박스](/inbox#알림-처리)를 참고하세요. |
| 알림 미루기 | `H` | `H` | 인박스 페이지에서 열어 둔 태스크를 미루고 다음 알림을 엽니다. 미뤄둔 태스크에서는 지금 되돌립니다. |
| 알림 읽지 않음 / 읽음 전환 | `U` | `U` | 인박스 페이지에서 열어 둔 활성 알림을 닫지 않고 읽지 않음/읽음 상태를 전환합니다. |
| 다음 알림 | `J` | `J` | 인박스 페이지에서 보관하지 않고 현재 탭의 다음 알림으로 이동합니다. |
| 이전 알림 | `K` | `K` | 인박스 페이지에서 보관하지 않고 현재 탭의 이전 알림으로 이동합니다. |
| 인박스 작업 실행 취소 | `Z` | `Z` | 보관, 미루기, 구독 해제 확인 알림이 보이는 동안 그 동작을 취소합니다. 확인 알림이 없으면 보관된 현재 알림을 인박스로 되돌리거나, **인박스가 비었습니다** 화면에 표시된 작업을 취소합니다. |
| 보내기 | `⌘↵` | `Ctrl+Enter` | 댓글과 채팅 메시지를 보내고, 새 태스크를 만들 때도 씁니다. |
| 음성 입력 | 지정 안 됨 | 지정 안 됨 | Desktop 전용. 먼저 설정 → 음성 입력에서 켜세요. [음성 입력](/desktop-app#음성-입력)을 참고하세요. |
| 뒤로 가기 | `⌘[` | `Ctrl+[` | |
| 앞으로 가기 | `⌘]` | `Ctrl+]` | |

키 하나짜리 단축키와 뒤로 가기·앞으로 가기는 입력란에서 글을 쓰는 동안에는 동작하지 않습니다.

### 페이지로 이동

`G`를 누른 뒤 1.5초 안에 두 번째 키를 누릅니다.

| 키 | 이동할 곳 |
|---|---|
| `G` `I` | 인박스 |
| `G` `M` | 내 태스크 |
| `G` `T` | 태스크 |
| `G` `P` | 프로젝트 |
| `G` `C` | 채팅 |
| `G` `A` | 에이전트 |

설정의 **탐색** 그룹에는 자동화, 스쿼드, 사용량, 런타임, Skills, 설정으로 이동하는 동작도 있으며 기본 키는 없습니다. 자주 쓰는 것에 직접 지정하세요. 인박스로 이동하면 인박스 페이지가 열리며, 알림 목록 자체는 작업 패널에서 고정됨 바로 아래 섹션에 있습니다. 내 태스크로 이동하면 내 태스크 페이지가 열리며, 작업 패널의 **내 작업** 뷰와는 다릅니다.

`G`가 두 번째 키를 기다리는 동안 그 키는 이동에 쓰입니다. `G` 다음의 `P`는 우선순위 설정이 아니라 프로젝트를 엽니다. 다른 키를 누르면 기다림이 끝나고 그 키는 원래대로 동작합니다.

### 태스크 다루기

이 키들은 눈앞의 태스크에 동작합니다. 열려 있는 태스크 페이지, 사이드 미리보기의 태스크, 목록에서 선택한 태스크, 또는 목록 커서가 있는 행입니다. 각 키는 검색창의 해당 명령과 같은 선택기를, 그 태스크나 선택에 맞춘 상태로 엽니다.

| 동작 | 키 | 참고 |
|---|---|---|
| 상태 변경 | `S` | |
| 담당자 지정 | `A` | |
| 우선순위 설정 | `P` | |
| 라벨 편집 | `L` | |
| 마감일 설정 | `⇧D` | Windows와 Linux에서는 `Shift+D`. |
| 프로젝트로 이동 | `⇧P` | Windows와 Linux에서는 `Shift+P`. |
| 빠른 작업 실행 | `Q` | 태스크 하나에서, 워크스페이스에 활성화된 빠른 작업이 있을 때. |
| 답글 | `R` | 열린 태스크의 댓글 입력란으로 커서를 옮깁니다. |

게스트는 `R`만 쓸 수 있습니다.

### 목록과 보드에서 이동

태스크 목록, 표, 보드에서는 아래 키로 태스크 사이를 커서가 움직입니다. 이 키들은 바꿀 수 없습니다. 마우스로 행을 가리키면 커서가 그 행으로 옮겨 가 숨고, 다음 키는 그 행에서 이어집니다.

| 동작 | macOS | Windows / Linux | 참고 |
|---|---|---|---|
| 아래 / 위로 이동 | `J` / `K` 또는 `↓` / `↑` | `J` / `K` 또는 `↓` / `↑` | 처음 누르면 맨 위에서, 위로 누르면 맨 아래에서 시작합니다. |
| 보드 열 이동 | `←` / `→` | `←` / `→` | 보드에서만. 보드의 사이드 미리보기에서는 `H` / `L`도 같습니다. |
| 열기 | `↵` | `Enter` | 환경설정의 **태스크 열기**에 따라 엽니다. |
| 미리보기 | `Space` | `Space` | 사이드 미리보기를 열거나 닫습니다. |
| 선택 | `X` | `X` | 태스크를 선택에 넣거나 뺍니다. |
| 선택 확장 | `⇧↓` / `⇧↑` | `Shift+↓` / `Shift+↑` | |
| 모두 선택 | `⌘A` | `Ctrl+A` | 커서가 보이거나 선택한 것이 있을 때. |
| 선택 해제 | `Esc` | `Esc` | `Esc`를 한 번 더 누르면 커서가 숨습니다. |

### 고정 시스템 단축키

아래 단축키는 바꿀 수 없습니다. `Esc`를 제외하면 [데스크톱 앱](/desktop-app)에서만 동작하고, 브라우저에서는 브라우저가 이 키를 처리합니다.

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 설정 열기 | `⌘,` | `Ctrl+,` |
| 활성 탭 닫기 | `⌘W` | `Ctrl+W` |
| 1~8번째 탭 선택 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 마지막 탭 선택 | `⌘9` | `Ctrl+9` |
| 확대 / 축소 / 확대/축소 재설정 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 대화상자 또는 메뉴 닫기 | `Esc` | `Esc` |

## 단축키 바꾸기

<Steps>
<Step>

**설정 → 단축키**를 엽니다. 동작이 많을 때는 위쪽 검색란에서 이름으로 찾으세요.

</Step>
<Step>

동작 오른쪽의 키를 클릭하고 '키를 누르세요'가 보이면 새 조합을 누릅니다. `Esc`는 취소, `Delete`는 그 동작의 키를 지웁니다.

**탐색** 동작에는 `G` 다음 `U`처럼 키 두 개를 이어서 기록할 수도 있습니다. 글자 하나를 누르면 행이 두 번째 키를 기다립니다. `↵`는 글자 하나로 확정하고, `Backspace`는 처음부터 다시 합니다.

</Step>
<Step>

각 행 오른쪽 끝의 두 버튼으로 그 동작을 기본값으로 되돌리거나 사용하지 않게 할 수 있습니다. 위쪽의 **기본값 복원**은 모든 사용자 지정을 한 번에 되돌립니다.

</Step>
</Steps>

단축키는 지금 쓰는 기기에만 저장됩니다. 다른 컴퓨터를 쓰거나 브라우저와 데스크톱 앱을 오갈 때는 다시 설정해야 합니다.

다음 조합은 등록되지 않으며, 키 아래에 이유가 표시됩니다.

- 이미 다른 동작에 지정된 조합. 키 하나는 그 키로 시작하는 연속 키와도 겹칩니다. 인박스로 이동이 `G` 다음 `I`인 동안에는 다른 동작에 `G` 하나만 지정할 수 없습니다.
- **탐색**이 아닌 동작의 연속 키, 또는 첫 키가 일반 글자·숫자·기호가 아닌 연속 키.
- 브라우저, 데스크톱 창, 운영체제가 쓰는 조합. 예를 들어 `⌘W`, `⌘R`, `⌘Q`, `⌘,`, 복사·붙여넣기 같은 편집 키, `⌘0`–`⌘9`, 확대/축소 키입니다. 브라우저에서는 `⌘P`, `⌘L`, `⌘T`, `⌘N`, `⌘D`, `⌘U`도 쓸 수 없지만 데스크톱 앱에서는 쓸 수 있습니다. Windows와 Linux에서는 Win / Super 키가 들어간 조합을 모두 쓸 수 없습니다.
- 검색 열기, 채팅 창 전환, 태스크에서 찾기처럼 입력란에서도 동작하는 단축키에는 `⌘`, `Ctrl`, `Control` 중 하나가 있어야 합니다. 글을 쓰다가 잘못 실행되지 않게 하기 위해서입니다. 음성 입력은 예약된 조합이 아니라면 `Option` / `Alt`와 `Space`처럼 문자를 입력하지 않는 키의 조합도 허용합니다.
- **보내기**에는 `↵`나 `⌘↵`만 쓸 수 있습니다.

<Callout>
**보내기**를 `↵`로 바꾸면 줄바꿈은 `Shift+Enter`로 합니다. 단락을 넣거나, 목록을 이어 가거나, 코드 블록에서 줄을 바꿀 수 있습니다.
</Callout>

## 태스크에서 찾기

태스크 상세 페이지에서 `⌘F`를 누르면 브라우저 찾기 대신 Multica의 찾기 막대가 열립니다. 브라우저 찾기는 화면에 그려진 댓글만 찾지만, 이 막대는 제목, 설명, 모든 댓글을 포함한 타임라인 전체를 검색합니다.

대소문자는 구분하지 않습니다. 찾기 막대에는 '현재/전체' 개수가, 결과가 없으면 '일치 항목 없음'이 표시됩니다. `↵`는 다음 항목, `Shift+Enter`는 이전 항목으로 이동하고 `Esc`로 닫습니다. 중간에 서식이 바뀌는 문자열(절반만 굵게 등)은 찾지 못합니다.

데스크톱 앱에서는 지금 보이는 탭만 `⌘F`에 반응합니다.

## 환경설정

개인 설정은 **설정 → 환경설정**에 있고, 바꾸면 바로 적용됩니다. 그룹마다 저장 위치가 다릅니다.

| 그룹 | 설정 | 저장 위치 |
|---|---|---|
| **언어 및 지역** | 언어: English, 简体中文, 繁體中文, 한국어, 日本語, Français, Español, Русский. 바꾸면 페이지가 다시 로드됩니다.<br />시간대: 기본값은 브라우저를 따릅니다. 모든 워크스페이스의 날짜와 차트에 쓰이며, 전체 시간대에서 검색해 고를 수 있습니다. | 계정(다른 기기에도 동기화) |

[실행 중인 에이전트에게 끼어들기](/mentioning-agents#실행-중인-에이전트에게-끼어들기)를 참고하세요.<br />**댓글 속 이미지**: 댓글의 이미지를 **썸네일** 또는 **원본 크기**로 표시합니다.<br />**플로팅 채팅 창**: 끄면 상태 표시줄의 빠른 채팅이 사라집니다(좁은 창에서는 오른쪽 아래 둥근 채팅 버튼도 표시되지 않습니다).<br />**Multica에게 묻기 에이전트**: 현재 워크스페이스에서 하단 바로 새 채팅을 시작할 때 사용할 에이전트(기본값은 **마지막으로 사용한 에이전트**, **플로팅 채팅 창**이 켜져 있어야 사용 가능). | 이 기기(Multica에게 묻기 에이전트는 워크스페이스별 저장) |
