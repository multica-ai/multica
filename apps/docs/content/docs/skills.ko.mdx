스킬은 워크스페이스에서 재사용할 수 있는 작업 방법의 묶음입니다. `SKILL.md`가 기본 파일이며 스크립트, 템플릿, 참고 자료를 함께 넣을 수도 있습니다.

스킬을 [에이전트](/agents)에 추가하면 에이전트가 관련 작업을 실행할 때 그 안의 설명을 사용합니다. 같은 방법을 각 에이전트 지시문에 따로 복사할 필요가 없고, 수정할 때도 한 곳만 관리하면 됩니다.

## 스킬과 에이전트 지시문

| | 에이전트 지시문 | 스킬 |
|---|---|---|
| **저장하기 적합한 내용** | 해당 에이전트의 장기적인 역할, 경계, 결과물 요구 사항 | 특정 작업 유형에서 재사용할 수 있는 단계, 자료, 도구 |
| **사용 범위** | 에이전트 한 명에게만 속하며 모든 실행에 제공 | 여러 에이전트에 추가하고 개별적으로 활성화하거나 비활성화 가능 |
| **예시** | "프런트엔드 코드만 검토하고 직접 수정하지 않기" | 접근성 점검 체크리스트와 보고서 템플릿 |

## 스킬 생성 또는 가져오기

워크스페이스의 **스킬** 페이지에서 "새 스킬"을 선택하면 네 가지 방법을 사용할 수 있습니다.

| 방법 | 적합한 경우 |
|---|---|
| **직접 만들기** | 빈 `SKILL.md`에서 작성합니다. |
| **로컬에서 가져오기** | `SKILL.md`가 있는 폴더, 또는 이 컴퓨터의 `.skill` / `.zip` 아카이브를 선택합니다. |
| **URL에서 가져오기** | GitHub, ClawHub, Skills.sh에 게시된 스킬을 가져옵니다. |
| **런타임에서 복사** | 연결된 컴퓨터의 스킬을 스캔하고 선택한 내용을 워크스페이스로 복사합니다. |

런타임에서 복사되는 내용은 그 시점의 파일 스냅샷입니다. 이후 로컬 파일이 바뀌어도 워크스페이스 버전은 자동으로 업데이트되지 않습니다. 다시 가져오거나 Multica에서 수정해야 합니다.

같은 아카이브 형식은 CLI에서도 사용할 수 있습니다.

```bash
multica skill import --file ./review-helper.skill
```

가져올 때 워크스페이스에 같은 이름의 스킬이 이미 있으면 가져오기를 중단하거나, 기존 내용을 덮어쓰거나, 새 이름으로 저장하거나, 건너뛸 수 있습니다. 가져오기를 통한 덮어쓰기는 해당 스킬의 생성자만 할 수 있습니다. 워크스페이스 `admin`이 앱 안에서 수정할 수 있더라도 가져오기로는 덮어쓸 수 없습니다. 워크스페이스에 이미 있는 스킬의 새 버전을 받으려면 [가져온 스킬 업데이트](#가져온-스킬-업데이트)를 사용하세요.

## 가져온 스킬 업데이트

GitHub, ClawHub, Skills.sh에서 가져온 스킬은 소스에 대한 참조를 유지합니다. 최신 버전을 받으려면 스킬 페이지의 **업데이트** 버튼(또는 목록 행 메뉴의 "소스에서 업데이트")을 사용하거나 CLI를 사용하세요:

```bash
multica skill refresh <skill-id>
```

스킬은 소스에서 다시 다운로드되어 그 자리에서 교체됩니다:

- **유지되는 것**: 스킬의 정체성 — 에이전트 할당, 라벨, 생성자, 생성 시각. 에이전트가 다시 추가할 필요가 없습니다.
- **교체되는 것**: 이름(소스에서 이름이 바뀌면 따라감), 설명, `SKILL.md`, 모든 지원 파일. 스킬에 대한 로컬 편집 내용은 덮어쓰기됩니다.

스킬의 생성자와 워크스페이스 `owner`, `admin`이 소스에서 업데이트할 수 있습니다. 수동으로 만들었거나, 압축 파일에서 가져왔거나, 런타임에서 복사한 스킬은 호스팅된 소스가 없어 이 방법으로 업데이트할 수 없습니다. 다시 가져오세요.

여러 스킬을 한 번에 업데이트하려면 스킬 목록에서 선택한 뒤 선택 도구 모음의 **업데이트**를 사용하세요. 호스팅된 소스가 있는 선택된 스킬은 모두 소스에서 다시 다운로드되며, 소스가 없는 스킬은 건너뜁니다.

## 스킬 내용

모든 스킬에는 기본 파일 `SKILL.md`가 있습니다. 이 파일에 다음 내용을 명확히 작성하세요.

- 스킬이 적합한 상황
- 시작 전에 확인할 사항
- 실행 단계
- 결과를 제출할 형식
- 중지하고 멤버에게 확인해야 할 경우

다음과 같은 지원 파일도 추가할 수 있습니다.

```text
SKILL.md
references/api-conventions.md
templates/review-report.md
scripts/check.sh
```

`SKILL.md`는 예약된 경로이므로 같은 이름의 지원 파일을 다시 만들 수 없습니다. 지원 파일은 기본 파일과 함께 에이전트에 제공됩니다.

## 에이전트에 추가

스킬을 만들거나 가져온 뒤에는 구체적인 에이전트에 추가해야 합니다. 스킬 페이지에서 에이전트를 선택하거나 에이전트의 **스킬** 탭을 열어 관리할 수 있습니다.

- 한 에이전트가 여러 스킬을 사용할 수 있습니다.
- 하나의 스킬을 여러 에이전트가 사용할 수 있습니다.
- 잠시 필요하지 않다면 스킬을 삭제하지 않고 연결을 비활성화할 수 있습니다.
- 수정한 내용은 이후 실행부터 적용되며 이미 실행 중인 작업에는 영향을 주지 않습니다.

해당 에이전트를 수정할 권한이 있는 멤버만 스킬을 추가, 제거, 비활성화할 수 있습니다.

## 워크스페이스 스킬과 저장소의 스킬

워크스페이스 스킬은 Multica에 저장되며 팀이 함께 관리하고 여러 에이전트에 추가하기에 적합합니다.

일부 AI 코딩 도구는 `.claude/skills/` 또는 `.agents/skills/` 같은 코드 저장소의 프로젝트 수준 스킬을 직접 읽습니다. 이 파일들은 계속 저장소에서 관리되며 Multica가 자동으로 워크스페이스 스킬로 등록하지 않습니다. 구체적인 지원 방식은 사용하는 도구에 따라 다릅니다. [AI 코딩 도구 비교](/providers)를 참고하세요.

연결된 컴퓨터에 설치된 런타임의 로컬 스킬(Claude Code와 Codex)은 에이전트의 **스킬** 탭에 표시되며 에이전트별로 비활성화할 수 있습니다. 비활성화 역시 해당 에이전트를 수정할 권한이 있어야 합니다.

## 수정 권한

모든 워크스페이스 멤버가 스킬을 만들거나 가져올 수 있습니다. 생성자와 워크스페이스 `owner`, `admin`은 스킬을 수정하거나 삭제할 수 있습니다. 다른 멤버는 보고 사용할 수 있지만 내용을 덮어쓸 수 없습니다.

삭제는 영구적이며 해당 스킬이 모든 에이전트에서 동시에 제거됩니다.

<Callout type="warning">
외부에서 가져온 스킬에는 스크립트, 명령, 안전하지 않은 지시가 포함될 수 있습니다. Multica는 이를 대신 검토하거나 서명하거나 격리하지 않습니다. 가져온 내용은 그대로 에이전트의 실행에 제공되므로 출처를 신뢰할 수 있어야 합니다.
</Callout>
