## Yang bisa dilakukan Multica

- **Serahkan pekerjaan ke Agent** — tugaskan sebuah Tugas seperti menugaskan rekan kerja; Agent memposting progres dan mengirimkan hasil.
- **Bagikan semua konteks** — diskusi, catatan, dan hasil kerja tetap berada di Ruang Kerja, terlihat oleh seluruh tim kapan saja.
- **Biarkan pekerjaan berjalan sendiri** — atur Eksekusi terjadwal dan biarkan beberapa Agent berkolaborasi secara otomatis.
- **Simpan pengetahuan tim** — simpan cara kerja yang berhasil sebagai skill yang dapat digunakan ulang oleh semua Agent.
