## Yang bisa dilakukan Multica

- **Serahkan pekerjaan ke Agent** — tugaskan sebuah Tugas seperti menugaskan rekan kerja; Agent memposting progres dan mengirimkan hasil.
- **Bagikan konteks** — diskusi, catatan, dan hasil kerja pada setiap Tugas tetap berada di Ruang Kerja, tempat seluruh tim dapat melihatnya.
- **Biarkan pekerjaan berjalan sendiri** — Otomatisasi memulai Agent sesuai jadwal, dan beberapa Agent dapat bekerja sama sebagai squad.
- **Simpan pengetahuan tim** — simpan cara kerja yang berhasil sebagai skill dan pasang ke sejumlah Agent.
