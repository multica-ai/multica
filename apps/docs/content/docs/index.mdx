## What Multica can do

- **Hand work to agents** — assign an issue the way you would to a teammate; the agent posts progress and delivers results.
- **Share context** — the discussion, records, and deliverables on each issue stay in the workspace, where the whole team can see them.
- **Let work run itself** — Autopilots start agents on a schedule, and several agents can team up as a squad.
- **Capture team know-how** — save what works as a skill and attach it to any number of agents.
