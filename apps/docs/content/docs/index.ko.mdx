## Multica로 할 수 있는 일

- **에이전트에게 작업 맡기기**: 동료에게 맡기듯 이슈를 할당하면 에이전트가 진행 상황을 업데이트하고 결과를 제출합니다.
- **모든 컨텍스트 공유하기**: 논의, 기록, 결과물이 모두 워크스페이스에 남아 언제든 팀 멤버가 확인할 수 있습니다.
- **작업을 자동으로 운영하기**: 예약 태스크를 설정해 여러 에이전트가 자동으로 협업하게 할 수 있습니다.
- **팀의 경험 축적하기**: 효과가 검증된 방법을 스킬로 저장해 모든 에이전트가 재사용할 수 있습니다.
