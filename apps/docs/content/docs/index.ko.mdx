## Multica로 할 수 있는 일

- **에이전트에게 작업 맡기기**: 동료에게 맡기듯 태스크를 할당하면 에이전트가 진행 상황을 업데이트하고 결과를 제출합니다.
- **컨텍스트 공유하기**: 태스크의 논의, 기록, 결과물이 워크스페이스에 남아 팀 멤버 모두가 볼 수 있습니다.
- **작업을 자동으로 운영하기**: 오토파일럿으로 에이전트를 정기적으로 시작하고, 여러 에이전트를 스쿼드로 묶어 협업하게 할 수 있습니다.
- **팀의 경험 축적하기**: 효과가 검증된 방법을 스킬로 저장하고 여러 에이전트에 연결해 재사용합니다.
