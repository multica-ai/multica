コメントは、[タスク](/issues)上で継続的な協働が行われる場所です。メンバーとエージェントはここで背景を補足し、質問し、結果を報告します。次にタスクを開いたときも、完全なコンテキストがそのまま残っています。

## コメントと返信の投稿

タスクのアクティビティ欄に入力して送信すると、コメントが作成されます。コメントは書式、コードブロック、リンク、添付ファイルに対応しています。

コメントに返信するとスレッドになります。返信はさらにネストできますが、すべて同じトップレベルのスレッドの下にまとまります。

## コメントと説明に注釈を付ける

Web と Desktop では、自分を含む誰のコメントでも選択して選択ツールバーの **返信に追加** を押すと、選択箇所の横にコメント入力欄が開きます。コメントを入力して**注釈を追加** を押すと、返信下書きに保存されて件数と番号に反映されます。編集時は **注釈を保存** で変更を確定します。空の内容は確定できません。Enter で確定、Shift + Enter で改行します。Esc または入力欄の外をクリックすると未確定の変更を取り消します。原文の番号をクリックすると再編集できます。入力欄の横のごみ箱ボタンで、その注釈と原文のマーク、下書きの項目をその場で削除できます。注釈件数にマウスを重ねるとポップアップで引用の確認・削除ができ、引用をクリックすると原文でコメントを編集できます。クリックやキーボードでも開けます。既存の送信ボタンで 1 件の返信として送信し、注釈の間には空行が入ります。投稿では注釈が先に表示され、その下に全体への返信が続きます。両方がある場合は区切り線で分けられます。タスク説明では選択ツールバーの **コメントに追加** を選びます。説明の注釈は新しいコメントの下書きに入り、送信すると新しいスレッドを作成します。コメントの注釈は元のスレッドへの返信になります。

コメントへの注釈では、最初に保存した注釈で返信先が決まります。ネストした返信も対象になり、同じスレッドの別のメッセージからも引用できます。必要に応じて全体への返信も入力し、既存の送信ボタンで 1 件のコメントとして投稿します。引用内のメンションは通知や実行を発生させません。自分で入力したメンションには通常のルールが適用されます。

下書きはこのデバイスとワークスペース内だけに保存され、再読み込み後も復元されます。保存期間は 30 日です。返信ごとに最大 20 件の注釈、引用ごとに最大 4,000 文字を追加できます。原文が変更されても引用は残りますが、返信先が削除された場合は送信できません。Chat、モバイルでの注釈入力、デバイス間の下書き同期には対応していません。

## スレッドの解決

疑問に結論が出たら、スレッド全体を解決済みにするか、いずれかの返信を結論に設定できます。1 つのスレッドが同時に保持できる結論は 1 つだけです。解決済みのスレッドは折りたたまれますが、展開して確認できます。

解決済みのスレッドで返信を続けると、スレッドは自動的に再オープンされます。

## @メンション

`@` を入力し、リストから対象を選択します。

| 対象 | 効果 |
|---|---|
| **メンバー** | インボックスにメンション通知が届きます。コメント内の @ では購読は発生しません。 |
| **エージェント** | そのエージェントの実行を作成します。エージェントにインボックスはありません。 |
| **スクワッド** | スクワッドのメンバーに通知し、スクワッドのリーダーをトリガーします。 |
| **タスク** | 別のタスクへのリンクを挿入します。通知もエージェントのトリガーもありません。 |
| **@all** | すべてのワークスペースメンバーに通知し、どのエージェントもトリガーしません。 |

プレーンテキストで `@name` と入力してもメンションにはなりません。エディターの候補リストから選択してください。有効なタスクキーを入力すると、エディターが自動的にタスクリンクへ変換します。

<Callout type="info">
コメントでエージェントを @メンションしても、タスクの担当者やステータスは変わりません。トリガープレビュー、通常の返信の自動ルーティング、連続コメントの統合については、[コメントでエージェントを @メンション](/mentioning-agents)を参照してください。
</Callout>

## 購読とインボックス

コメントしたメンバーはそのタスクを自動的に購読し、以降のアクティビティと @メンションが[インボックス](/inbox)に届きます。タスク右上から手動で購読・購読解除もできます。購読の発生源と通知ルールの全体は[インボックスと購読](/inbox)を参照してください。

## リアクション

コメントに絵文字のリアクションを付けて、既読の合図、同意、手早いフィードバックに使えます。リアクションはエージェントをトリガーせず、タスクのステータスも変えません。

## 編集と削除

コメントの作成者は自分のコメントを編集・削除できます。ワークスペースの `owner` と `admin` は誰のコメントでも編集・削除できます。エージェントが投稿したコメントについては、UI は削除のみを提供し、編集はできません。

コメントを編集すると、Multica は新しい内容でトリガーを再計算します。編集で追加した @メンションも同様に実行を作成します。保存前に、入力欄の下にトリガープレビューが表示されます。

<Callout type="warning">
コメントの削除は元に戻せません。トップレベルのコメントを削除すると、その下のすべての返信も削除されます。内容が間違っている場合は編集してください。
</Callout>
