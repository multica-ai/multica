二つのツールで、あなたが会社の舵を取れるようにします。**会社のコントロール** はワークスペース全体で自動化された作業を止め、**ガバナンスログ** は会社のガバナンスのあり方を変えるすべての変更を記録します。ログは編集も削除もできません。

## 会社の状態

会社は次の三つの状態のいずれかになります。

| 状態 | ルーティンとデリゲートの実行 | チャットとあなたが開始した実行 |
| --- | --- | --- |
| `running`（稼働中） | 通常どおり実行 | 通常どおり実行 |
| `paused`（一時停止） | 理由 `company_paused` で保留されます。オートパイロットはスキップされ、ウェイクアップは発火しません。 | 引き続き動作 |
| `quiet`（静穏） | 静穏時間の終わりまで延期され、破棄はされません | 引き続き動作 |

一時停止中は、ナレッジの自動公開とパイプラインの自動進行が止まり、常時承認も適用されません。秘書のブリーフとチャットは動き続けるので、会社の状況を見たり会社と話したりできます。

会社のヘッダーにある **Pause**（一時停止）で会社を一時停止します。**stop running work**（実行中の作業を停止）を付けると、進行中のルーティンとデリゲートの実行もキャンセルされます。

```bash
multica company status
multica company pause --stop-running
multica company resume
```

オーナーと管理者は一時停止と再開ができます。メンバーは状態を確認できます。

### 静穏時間

静穏時間は、ワークスペースのタイムゾーンで定められた毎日の時間帯で、その間はルーティンの実行が延期されます。既定は22:00から07:00です。延期された実行は、時間帯の終わりに開始されます。何も破棄されません。

```bash
multica company quiet --enable --start 22:00 --end 07:00 --timezone Europe/Paris
multica company quiet --disable
```

時刻はタイムゾーン内の `HH:MM` です。静穏時間は **Controls**（コントロール）タブでも設定できます。

<Callout type="info">
一時停止すると、約一分以内にルーティンの実行が止まります。Webhook によって開始された実行は、デーモンが取得する時点で保留されるため、一時停止中の実行一覧には `issue_created` と表示されることがあります。それでも実行は開始されません。
</Callout>

## ガバナンスログ

ログは、会社のガバナンスのあり方を変える操作を追記だけで記録する台帳です。対象は次のとおりです。

- プロポーザルポリシーの作成、取り消し、自動承認での使用；
- 予算の設定、延長、保留、解除；
- 自律性レベルの変更；
- 適用・取り消しされた組織変更；
- ナレッジの自動公開；
- ステージを強制されたイニシアチブ；
- 会社の一時停止と再開；
- 有効化された目標；
- 公開されたレビュー。

各エントリには、種類、実行者（人、エージェント、システム、またはポリシー）、対象、サマリー、詳細があります。**ガバナンス** の **Log**（ログ）タブを開くと、種類、実行者、対象で絞り込んだり、CSV をエクスポートしたりできます。

```bash
curl -H "Authorization: Bearer $MULTICA_TOKEN" -H "X-Workspace-ID: $WORKSPACE_ID" \
  "$MULTICA_API/api/governance/events?kind=budget_hold"
curl -H "Authorization: Bearer $MULTICA_TOKEN" -H "X-Workspace-ID: $WORKSPACE_ID" \
  -o governance.csv "$MULTICA_API/api/governance/events.csv"
```

CSV のエクスポートは50,000行が上限です。それを超えると HTTP 413 を返すので、絞り込みを狭めてから再度エクスポートしてください。

ログには、アプリケーションから更新や削除を行う経路はありません。ワークスペース全体を削除したときだけ消えます。保存期間は無期限です。

## システムの健全性

**Controls** タブには、各定期ジョブの最後の成功時刻と遅延、配信の失敗、ナレッジのサイドカーの状態、予算ゲートのキャッシュの経過時間が表示されます。API は `GET /api/governance/health` です。止まっているジョブは、ブリーフにリスクとして記載されます。

## 制限

- 会社の状態のエンドポイントは、`GET` と `PUT /api/company/company-state`、および `PUT /api/company/quiet-hours` です。上記の CLI コマンドはこれらをラップしています。
