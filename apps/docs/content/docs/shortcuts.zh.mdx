## 搜索

按 `⌘K`，或者点侧边栏顶部的**搜索...**，打开搜索框。不输入时，这里列出**新建任务**和你最近打开过的任务。输入关键词后，结果分组显示：

| 分组 | 能找到什么 |
|---|---|
| **页面** | 收件箱、聊天、任务、项目、智能体、设置等工作区页面。中文名称可以用拼音搜，例如输入 `renwu` 找到"任务"。 |
| **命令** | 新建任务、新建项目，切换浅色、深色主题或跟随系统主题。打开任务详情时还有复制任务链接、复制标识符、收起全部评论、展开全部评论。 |
| **成员** | 按姓名或邮箱查找，中文姓名同样支持拼音。 |
| **工作区** | 你加入的其他工作区，选中后切换过去。 |
| **项目**、**任务** | 匹配标题，也匹配项目说明、任务描述和评论。命中的片段显示在结果下方；已完成的任务也会出现。 |
| **已取消** | 已取消的项目和任务统一排在最后，不会挤到前面。 |

选中结果后直接跳转。按住 `⌘`（Windows / Linux：`Ctrl`）再点击或按回车，会在新标签页里打开。按 `Esc` 关闭搜索框。

## 键盘快捷键

| 操作 | macOS | Windows / Linux | 说明 |
|---|---|---|---|
| 打开搜索 | `⌘K` | `Ctrl+K` | |
| 新建任务 | `C` | `C` | 打开你常用的创建方式。在项目页按，新任务会预先填好这个项目。 |
| 显示或隐藏左侧边栏 | `⌘B` | `Ctrl+B` | |
| 显示或隐藏右侧边栏 | `⌘/` | `Ctrl+/` | 只在有右侧栏的页面可用，例如任务详情。 |
| 显示或隐藏聊天窗 | `⌘J` | `Ctrl+J` | 打开时光标落在输入框里。见[悬浮聊天窗](/chat#在任意页面打开悬浮聊天窗)。 |
| 在任务中查找 | `⌘F` | `Ctrl+F` | 见下文。 |
| 归档通知 | `E` | `E` | 归档收件箱里当前打开的通知；查看已归档时则取消归档。 |
| 发送 | `⌘↵` | `Ctrl+Enter` | 发送评论和聊天消息，也用于提交新任务。 |
| 后退 | `⌘[` | `Ctrl+[` | |
| 前进 | `⌘]` | `Ctrl+]` | |

单键快捷键（`C`、`E`）和后退、前进在输入框里不起作用，避免打字时误触。

**导航**类操作还有前往收件箱、聊天、我的任务、任务、项目、自动化、智能体、小队、统计、运行时、Skills 和设置，默认都没有设置按键，需要时自己绑定。

### 固定的系统快捷键

下面这些不能修改。除了 `Esc`，其余只在[桌面端](/desktop-app)有效；网页版里这些按键由浏览器处理。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 打开设置 | `⌘,` | `Ctrl+,` |
| 关闭当前标签页 | `⌘W` | `Ctrl+W` |
| 选择第 1–8 个标签页 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 选择最后一个标签页 | `⌘9` | `Ctrl+9` |
| 放大 / 缩小 / 重置缩放 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 关闭对话框或菜单 | `Esc` | `Esc` |

## 修改快捷键

<Steps>
<Step>

打开**设置 → 快捷键**。操作多时，用顶部的搜索框按名称查找。

</Step>
<Step>

点击某个操作右侧的按键，看到"请按键"后按下新的组合。`Esc` 取消，`Delete` 清除这个操作的按键。

</Step>
<Step>

每行右侧的两个按钮分别把这一项恢复默认、停用这一项。顶部的**恢复默认设置**会一次撤销所有自定义。

</Step>
</Steps>

快捷键只保存在当前设备上。换一台电脑，或者从浏览器换到桌面端，需要重新设置。

录入时会拒绝几类组合，并在按键下方说明原因：

- 已经分给其他操作的组合。
- 浏览器、桌面窗口或系统占用的组合，例如 `⌘W`、`⌘R`、`⌘Q`、`⌘,`、复制粘贴这类编辑键、`⌘0`–`⌘9` 和缩放键。网页版里 `⌘P`、`⌘L`、`⌘T`、`⌘N`、`⌘D`、`⌘U` 也不能用，桌面端可以。Windows 和 Linux 上带 Win / Super 键的组合都不能用。
- 打开搜索、聊天窗、在任务中查找这类在输入框里也生效的操作，必须带 `⌘`、`Ctrl` 或 `Control`，否则打字时会误触。
- **发送**只能是 `↵` 或 `⌘↵`。

<Callout>
把**发送**改成 `↵` 后，换行改用 `Shift+Enter`：它会插入新段落、继续列表，或者在代码块里换行。
</Callout>

## 在任务中查找

在任务详情页按 `⌘F`，打开的是 Multica 自己的查找栏，不是浏览器的查找。浏览器查找只能找到已经滚动到屏幕上的评论；这里会把整条时间线都纳入查找，包括标题、描述和所有评论。

查找不区分大小写，查找栏显示"当前 / 总数"，没有结果时显示"无匹配结果"。按 `↵` 跳到下一个，`Shift+Enter` 跳到上一个，`Esc` 关闭。一段文字中间跨了格式（例如一半加粗）时，查不到这段。

在桌面端，只有当前显示的标签页会响应 `⌘F`。

## 偏好设置

个人偏好在**设置 → 偏好设置**里，改动立即生效。各组的保存范围不同：

| 分组 | 设置 | 保存在 |
|---|---|---|
| **语言与地区** | 语言：English、中文、한국어、日本語、Français。切换后页面会重新加载。<br />时区：默认跟随浏览器；用于所有工作区的日期和图表，可以搜索全部时区。 | 账号，其他设备同步 |
| **外观** | 主题：浅色、深色、跟随系统。也可以在搜索框里输入"主题"切换。 | 当前设备 |
| **评论与聊天** | **固定底部评论栏**：开启时，阅读很长的时间线也能随时看到评论框。<br />**回复正在运行的智能体时**：默认"插话到当前运行"还是"本轮结束后开始"，发送前每条消息仍可单独改，见[给正在运行的智能体插话](/mentioning-agents#给正在运行的智能体插话)。<br />**悬浮聊天窗**：关闭后，页面右下角不再显示聊天按钮。 | 当前设备 |
| **打开任务** | 点击卡片或行时打开详情页还是悬浮预览。按住 Shift 点击会打开另一种。 | 当前设备 |
| **创建任务时显示的字段** | 分别为"智能体创建"和"手动创建"选择工具栏上常驻的字段。隐藏的字段仍可从 ⋯ 菜单使用，有值时自动显示。 | 当前设备上的当前工作区 |
