**予算** は、一つのスコープと一つの期間について支出の上限を設定します。支出は、そのスコープが行った実行から集計されます。上限に近づくと予算は警告します。`hold`（保留）モードで上限に達すると、そのスコープの新しい自動実行は、表示された理由とともに、あなたが対応するまで待機します。

## 予算を設定する

**ガバナンス** を開き、**Budgets**（予算）タブを選びます。次の項目を指定して予算を作成します。

| フィールド | 意味 |
| --- | --- |
| Scope（スコープ） | 会社、フロア、スクワッド、イニシアチブ |
| Period（期間） | 週、月、または四半期 |
| Amount（金額） | 一期間の上限。米ドル単位 |
| Soft limit（ソフトリミット） | 予算が警告を始める割合。既定は80% |
| Mode（モード） | `warn` は警告のみ。`hold` は上限に達した時点で新しい実行を保留します。 |
| Run classes（実行クラス） | 予算が保留できる実行の種類。既定ではルーティンと委任。 |

作成ダイアログの既定は `warn` です。モードを指定せずに保存された予算は `hold` になります。まだテストしていない新しい予算は、`warn` から始めるほうが安全です。

予算は `budget` プロポーザルによっても作成されます。スクワッドのリーダーが金額、理由、期待される効果を添えて提出します。承認されると予算が設定されます。イニシアチブの計画ステージのゲートを承認すると、月額100ドルの `warn` 予算が作成されます。スターター会社は、会社全体に対して月額500ドルの `warn` 予算を作成します。[スターター会社](/starter-company)を参照してください。

## 実行クラス

各実行はクラスに属し、予算がその実行を保留できるかどうかはクラスで決まります。

| クラス | 開始者 | 予算で保留されるか |
| --- | --- | --- |
| `human` | 人が、コメント、チャット、または割り当てによって開始 | 決して保留されません。いつでも会社と話せます。 |
| `routine` | オートパイロット、ウェイクアップ、運用レビュー | 予算のクラスに含まれていれば保留される |
| `delegated` | あるスクワッドのエージェントが別のスクワッドに渡した作業、またはスクワッドのリーダーによる振り分け | 予算のクラスに含まれていれば保留される |

秘書の毎日のブリーフと、その補完実行は対象外です。

## 保留の仕組み

チェックは、キューに入った作業がデーモンに渡されるときと、オートパイロットの発行時に行われます。`hold` モードの予算は、支出に、そのスコープで実行中の作業のために予約された費用を加えた額が、金額と追加分の合計に達したとき、タスクを保留します。実行中の各作業の予約額は、そのスコープの最近の実行費用の90パーセンタイルです。

保留されたタスクはキューに残ります。失敗にはなりません。プラットフォームはタスクごとに一件の保留を記録し、予算の保留一覧に **budget hold**（予算保留）という理由とともに表示します。保留された自動実行は、その理由付きでスキップとして記録されます。予算が延長されたり上限が引き上げられたり、あなたが保留を解除したり、期間が切り替わったり、タスクがキャンセルされたりすると、保留は解除されます。

予算のカウンターは実行が終わるたびに更新されるため、タスクを取得するたびに実行履歴を読む必要はありません。数字は数秒遅れることがあります。

## あなたの操作

- 現在の期間を金額分 **延長**します。延長は記録されます。
- 予算を **引き上げ**ます。
- 保留を一度に **解除**します。保留されたタスクは再び取得可能になります。
- 何もしない。期間が切り替わります。

さらに必要なスクワッドのリーダーは、代わりに `budget` プロポーザルを提出できます。各延長、解除、保留は[ガバナンスログ](/controls-and-log)に表示されます。

<Callout type="info">
支出は実行が作成された期間に計上され、時刻は UTC です。実行コストは、プロバイダーが報告した場合はその値を使います。報告がない場合は、サーバーがトークン数と自身の価格表から推定します。
</Callout>

## 制限

- 予算は Budgets タブで管理するほか、`GET` と `POST /api/budgets`、`PATCH /api/budgets/{id}`、`POST /api/budgets/{id}/extend`、`POST /api/budgets/{id}/release-holds`、`GET /api/budgets/{id}/periods`、`GET /api/budget-holds` で操作できます。CLI に予算のコマンドはありません。
- リクエストボディは16 KiB までです。
