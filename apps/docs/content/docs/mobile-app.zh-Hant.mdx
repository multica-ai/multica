Multica iOS 客戶端目前還沒有上架 App Store。你可以在 Mac 上從公開的原始碼倉庫構建 Release 版本，再安裝到自己的 iPhone。Android 沿用同一 React Native 客戶端，可構建已簽名、獨立執行的 APK。

安裝後的 App 預設連線 Multica Cloud，用已有帳號登入即可。工作區、任務、評論和執行記錄都儲存在服務端，不需要從 Web 或 Desktop 同步。

## Android APK

準備 JDK 17 和 Android SDK 36，設定倉庫外的 Release 簽名金鑰，再從倉庫根目錄執行：

```bash
pnpm -C apps/mobile android:release
```

APK 預設連線 Multica Cloud，不需要 Metro。簽名、環境變體、自託管位址和安裝驗證見 [Android 構建指南](https://github.com/multica-ai/multica/blob/main/apps/mobile/docs/android-release.md)。首版不包含背景推播。下文為 iPhone 安裝說明。

## 準備工作

你需要：

- 一臺安裝了 Xcode 的 Mac；
- 已在 **Xcode → Settings → Accounts** 中登入的 Apple ID；
- 一臺透過 USB 連線的 iPhone；
- 在 iPhone 的**設定 → 隱私與安全性**中開啟開發者模式；
- Node.js、pnpm 和 Git。

Xcode 或真機開發環境未配置時，先完成 Expo 的 [iOS Device 環境配置](https://docs.expo.dev/get-started/set-up-your-environment/)。

## 安裝到 iPhone

<Steps>
<Step>
克隆倉庫並安裝依賴：

```bash
git clone https://github.com/multica-ai/multica.git
cd multica
pnpm install
```
</Step>
<Step>
從倉庫根目錄執行：

```bash
pnpm ios:mobile:device:prod:release
```

這會構建一個不依賴 Metro 的 Release 版本，並安裝到已連線的 iPhone。第一次構建需要下載 iOS 依賴並編譯 React Native，之後會重複使用 Xcode 快取。
</Step>
<Step>
在 iPhone 上開啟 App。如果系統阻止開啟，到**設定 → 通用 → VPN 與裝置管理**中信任對應的開發者憑證。
</Step>
</Steps>

## 免費簽名的 7 天限制

免費 Apple ID 簽名的 App 只能使用 7 天。到期後，把 iPhone 重新連線到 Mac，並再次執行同一條構建命令即可續簽。

Apple Developer Program 帳號簽名的有效期更長，也可以用於 TestFlight 和正式分發。無論使用哪種簽名，服務端資料都不會因為重新安裝或續簽而丟失。

## 簽名失敗

如果 Xcode 提示 `No matching provisioning profiles found`，預設 bundle identifier 可能不屬於你的 Apple ID。換成自己控制的反向網域後重新構建：

```bash
export EXPO_BUNDLE_IDENTIFIER_PROD=com.yourname.multica
pnpm ios:mobile:device:prod:release
```

這個值只需要在你的 Apple Developer team 中可用，不影響 Multica 帳號或工作區。

## 更新

iOS 自助安裝版不會自動更新。拉取最新程式碼、更新依賴並重新構建：

```bash
git pull --ff-only
pnpm install
pnpm ios:mobile:device:prod:release
```

## 連線自託管例項

在登入頁開啟**伺服器設定**，或登入後前往**設定 → 伺服器設定**。填寫 **API 位址**（後端根位址）和**網頁位址**（瀏覽器與連結使用的位址）後儲存。兩個位址可同網域，也可使用不同網域。重新啟動 App 後仍會保留，無需重新打包。按下**還原 Cloud 預設位址**後儲存，即可回到 Multica Cloud。

兩個位址都需要 HTTPS，且憑證須受裝置信任。支援自訂連接埠和基礎路徑，例如 API `https://multica.example.com:8443/backend`、網頁 `https://multica.example.com:8443/app`。API 位址結尾的 `/api` 會移除，由介面路徑自動加入；`/auth` 和 `/ws` 使用同一個後端根位址。交付的 APK 不支援 HTTP，也不會略過憑證驗證。裝置須能存取填寫的位址；`localhost` 指手機本身。

修改任一位址會登出，清除本機草稿、工作區選擇和快取。請在所選實例上重新登入。伺服器上的資料仍保留在原實例。檔案與圖片會向所選實例取得新的簽署位址，不會把登入 token 交給外部瀏覽器。

開發建置和首次安裝預設值見儲存庫中的 [`apps/mobile/README.md`](https://github.com/multica-ai/multica/blob/main/apps/mobile/README.md)。
