---
title: 微信 Bot
description: 掃碼透過 iLink 將微信帳號連接到 Multica AI 代理。
---

Multica 參考騰訊 [OpenClaw Weixin 外掛](https://github.com/Tencent/openclaw-weixin) 的協定，直接連接微信 iLink Bot 服務。這與企業微信渠道獨立，不需要安裝 OpenClaw，也不透過桌面微信自動化收發訊息。

## 連線

1. 以工作區 owner 或 admin 身分登入，開啟 AI 代理的 "設定 → 整合"，選擇 "連接微信"。
2. 用**你自己的微信帳號**掃碼，並在手機上確認。微信要求驗證碼時，在彈窗中輸入手機顯示的數字。
3. 在微信中向機器人傳送一條新私訊。AI 代理需要線上的執行環境才能執行任務。

掃碼的微信帳號會繫結到發起連線的 Multica 使用者，訊息按該使用者的工作區權限執行。請勿分享 QR 碼或讓他人代掃。其他微信帳號和群聊訊息不會被接收。

登入視窗最多保留五分鐘，微信也可能提前讓 QR 碼失效。過期後重新產生即可。關閉彈窗會取消待確認的登入。已連接到其他 AI 代理或工作區的機器人必須先中斷原連線。帳號是否可用由微信決定，微信可能要求驗證或拒絕連線。

## 訊息與命令

- 文字訊息會繼續同一個 Multica 聊天，最終回覆以純文字返回微信。長回覆按完整 Unicode 字元分段，不提供串流編輯。
- `/new [訊息]` 新建聊天；`/clear [訊息]` 重設目前聊天的 AI 代理上下文；`/issue <標題>` 建立任務並分配給此 AI 代理。
- 配置物件儲存後，圖片、檔案、影片和未轉寫的語音會作為附件進入聊天。微信提供的語音轉寫作為文字處理；Multica 不額外提供語音辨識，也不轉換 SILK 音訊。
- AI 代理最終回覆中的附件會傳送回微信。支援的圖片和 MP4 影片使用原生媒體訊息，其他格式（包括音訊）使用檔案訊息。本適配器限制每次傳輸不超過 **20 MiB**。檔案傳送失敗時會提示，檔案仍保留在 Multica 中。
- 暫不支援群聊、通訊錄、主動通知、展開合併轉傳訊息或讀取引用訊息的歷史內文。

回覆需要微信簽發的目前會話上下文憑據。如果上下文過期導致拒絕傳送，請傳送一條新訊息。Multica 不假定固定的上下文有效期。API 成功僅表示微信接受了請求，不代表對方已收到或已讀；傳送回應遺失時記錄為結果不明，不自動重傳。

## 中斷連線

在 AI 代理的 "整合" 分頁或 "設定 → 訊息渠道 → 微信" 中選擇 "中斷連線"。新訊息停止進入 AI 代理，已儲存的回覆上下文會刪除，Multica 聊天記錄保留。微信明確返回授權過期時也會停用連線，需要重新掃碼。

## 自託管配置

產生一個持久儲存的加密金鑰：

```sh
openssl rand -base64 32
```

將結果配置為 API 服務的 `MULTICA_WEIXIN_SECRET_KEY`，然後重新啟動服務。所有副本使用相同金鑰，並與部署金鑰和備份一起妥善儲存。更換金鑰會導致原憑據無法解密，需要重新連接機器人。未配置時不開放連線入口，Docker Compose 已傳遞此變數。

API 服務需要透過 HTTPS 存取 `ilinkai.weixin.qq.com`、微信返回的 `*.weixin.qq.com` 區域位址和 `novac2c.cdn.weixin.qq.com`。無需公網 webhook 或入站通道。瀏覽器只接收 QR 碼顯示內容及狀態；機器人憑據和回覆上下文在伺服器端加密儲存。

執行常規資料庫遷移。共用渠道管理器跨副本確保每個安裝只有一條長輪詢，入站引擎接受整個批次後才儲存游標。最終回覆透過資料庫投遞租約去重。待傳送事件位於記憶體中，服務重新啟動可能中斷回覆；結果不明的傳送不會重播，答案與附件仍可在 Multica 檢視。

協定參考：騰訊 `@tencent-weixin/openclaw-weixin` **2.4.10**，原始碼提交 [`874637a`](https://github.com/Tencent/openclaw-weixin/tree/874637a0dbc24050f72d1385add4fc6170a2d726) 及其[協定文件](https://github.com/Tencent/openclaw-weixin/blob/874637a0dbc24050f72d1385add4fc6170a2d726/docs/protocol_zh_CN.md)。本適配器由 Go 原生實作，不依賴該外掛執行。微信的協定行為和帳號資格可能獨立於 Multica 版本變更。
