先看你希望智能体做什么：负责一条任务、处理一次具体请求，还是按固定安排反复工作。

<TriggerChooserDemo />

| 你想做什么 | 使用什么 |
|---|---|
| 让智能体负责一条任务 | 把[任务分配](/assigning-issues)给智能体或小队。 |
| 请求帮助，保留原来的负责人 | 在评论中 [@智能体](/mentioning-agents)，或回复它的评论继续讨论。 |
| 经常发送同一类请求 | 保存成[快捷操作](/quick-actions)，例如代码审查，在任务中直接使用。 |
| 让任务按固定步骤交给不同处理人 | 为项目选择[工作流](/workflows)，安排每一步由谁接手。 |
| 问一个问题，不需要新建任务 | 与智能体[开始对话](/chat)。 |
| 按时间或外部事件开展重复性工作 | 创建[自动化](/autopilots)。 |
| 让智能体之后再回到某条任务 | 在任务上添加[唤醒](/issue-wakeups)，设好要等的时间或事件。 |

你只能调用自己有权限运行的智能体。发送评论前，检查输入框下方的触发预览；只想留言而不叫醒智能体时，使用 `/note`。处于 `backlog` 的任务会等待你准备好再开始。

## 查看进展

在发起工作的任务或对话中跟进回复。打开[执行日志](/tasks)，可以查看智能体的进展、停止或重试。工作还未开始时，先检查智能体的电脑是否在线，后续检查方法见[故障排查](/troubleshooting)。
