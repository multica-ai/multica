**イニシアチブ**は一つのベンチャーです。製品、機能ライン、市場実験などが該当します。あなたは「請求ツールはどうなっている？」というように考えます。プロジェクト（作業のまとまり）でも、Issue（一つのタスク）でもありません。

イニシアチブは **パイプライン** の中を進みます。パイプラインは固定されたステージの並びです。各ステージには責任スクワッドと、達成すべき成果物（通常はナレッジドキュメント）があります。

## ステージ

既定のパイプラインには7つのステージがあります。各ステージは Issue のステータスでもあるため、イニシアチブに紐づく Issue がその進捗に追従します。

| ステージ | スターター会社での責任スクワッド | 代表的な成果物 |
| --- | --- | --- |
| Validate（検証） | Product Discovery | 検証レポート |
| Define（定義） | Product Analysis | プロダクトブリーフ、分析 |
| Plan（計画） | Planning | ロードマップ、予算申請、PRD |
| Build（構築） | Build | テストレポート、リリース候補 |
| Launch（公開） | Release & Ops | 公開計画、公開チェックリスト |
| Operate（運用） | Support | メトリクスレポート |
| Learn（学習） | Build | 振り返り |

公開のゲートは常にあなたが決めます。計画のゲートは予算申請を承認します。運用ステージは、継続・拡大・終了の三つの結果のいずれかになるレビューゲートで終わります。スターター会社がこれらのスクワッドを作成します。[スターター会社](/starter-company)を参照してください。

## イニシアチブを始める

イニシアチブは次の二つの方法で始まります。

- **承認された機会。** スクワッドが論拠を添えて `opportunity` プロポーザルを提出します。承認すると、対象ステージ（既定では `validate`）でイニシアチブが作成されます。
- **直接作成。** パイプラインのページから作成するか、`POST /api/initiatives` を使います。CLI には作成コマンドがありません。

## ボードとイニシアチブのパネル

**パイプライン**ページには、ステージごとの列とイニシアチブごとのカードがあるボードが表示されます。カードを開くとパネルが表示されます。パネルには、論拠、現在のステージと責任スクワッド、必要な成果物（不要なものは **Waive**（免除）できます）、あなたの判断を待つゲート、イニシアチブのコメント、ステージ変更のタイムラインが含まれます。

管理者は、イニシアチブを任意のステージへ **Force**（強制）で進めることもできます。強制はガバナンスログに記録されます。

## イニシアチブを進める

責任スクワッドは、そのステージを確認（attest）することで進めます。成果物が揃うとイニシアチブは先へ進みます。

```bash
multica initiative list
multica initiative show <id>
multica initiative attest <id>   # 責任スクワッドが実行。成果物が揃えば進む
multica initiative advance <id>  # 現在のステージの終了条件が満たされていれば次へ進む
multica initiative shelve <id>   # イニシアチブを一時停止。オーナーと管理者のみ
```

その他の操作は API またはアプリから行います。イニシアチブを前のステージに差し戻す、終了する、一時停止したものを再開する、などです。一時停止と終了はガバナンスログに記録されます。

ステージゲートはあなたの判断が必要です。ゲートのステージが準備できると、システムは `stage_gate` プロポーザルを提出します。承認するとイニシアチブが進み、却下するとイニシアチブは差し戻され、リーダーに通知されます。[プロポーザル](/proposals)を参照してください。

<Callout type="info">
公開は自動では行われません。自律性のレベルに関係なく、公開ゲートはあなたが決定します。[自律性と承認](/autonomy-and-approvals)を参照してください。
</Callout>

## 作業成果の保存先

イニシアチブが生み出すドキュメントは、**ventures**（ベンチャー）ナレッジベースに、イニシアチブごとのフォルダーとして保存されます。各ステージのビルドや開始作業は、イニシアチブのボードプロジェクト内の Issue です。
