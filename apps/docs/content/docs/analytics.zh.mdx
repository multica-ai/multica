侧边栏的**统计**页汇总整个工作区的智能体用量：费用、token、耗时和运行数，以及失败的运行。工作区成员都能打开它。每个运行时自己的用量在运行时详情页，一条任务花了多少在它的**运行记录**里，见下文。

## 页面结构

页面分**用量**和**错误**两个页签，共用右上角的两个筛选：

- **时间范围**：`1d`、`7d`、`30d`（默认）、`90d`、`180d`。`1d` 指今天，从你所在时区的 0 点算起，不是最近 24 小时。
- **项目**：默认**全部项目**。选定项目后，只统计这个项目下任务的运行；对话等不属于任何任务的运行不计入。

日期按你的时区切分：先用**设置 → 偏好设置 → 时区**里的设置，没设置时用浏览器时区。页头显示当前时区和数据更新时间。统计数据由服务器每 5 分钟汇总一次，页面开着时也按这个间隔刷新，刚结束的运行可能要过几分钟才出现；想马上看可以点刷新按钮。

切到错误页签后，地址栏会带上 `?tab=errors`，把链接发给同事，对方打开就是错误页签。

## 用量页签

顶部四个数字：

| 卡片 | 内容 |
| --- | --- |
| **费用** | 估算的美元费用，算法见[费用怎么算](#费用怎么算) |
| **Token** | 输入、输出、缓存读取、缓存写入的合计；下面一行单列输入和输出 |
| **耗时** | 已结束运行的执行时长之和，从开始执行算到结束 |
| **运行数** | 时间范围内结束的运行，以及其中失败的个数 |

耗时和运行数只算真正开始执行过的运行（已完成、失败或中途取消），排队时就被取消的不算。

趋势卡片在同一条时间轴上切换 Token、费用、耗时、运行数四种指标，**按天**和**按周**两种粒度。`30d` 和 `90d` 两种都能选；`1d`、`7d` 只能按天，`180d` 只能按周。按周时每周从周一开始，还没过完的本周颜色较浅，悬停会标出"未满 · 已过 N / 7 天"。

**排行榜**按智能体列出 Token、费用、耗时和运行数，可以按其中任意一项排序，默认显示前 10 个，点**展开全部**看其余的。排行榜里可能有两行汇总：

- **已删除的智能体**：已经删除的智能体的用量合并成一行，保证各行加起来仍等于顶部合计。
- **其他智能体**：你看不到的智能体合并成一行。工作区所有者和管理员能看到所有成员创建的智能体；普通成员看不到别人的私有智能体，它们的用量只在这里出现，不显示名字。

某个智能体有运行没上报 token 时，它的 Token 和费用前面会加 `≥`，名字下方注明有几次运行未上报用量。

## 错误页签

顶部是**失败运行**、**失败率**和**受影响智能体**。失败率按时间范围内结束的全部运行计算，卡片下方写着分子和分母。

下面依次是：

- **每日错误**（或每周错误）：每段颜色是一类失败。
- **失败构成**：时间范围内全部失败按类别拆分。点**展开错误码**换成原始的失败原因码，可以拿去搜日志或贴到任务里。
- **问题最多的智能体**：默认按失败数排序，前 8 个之后要展开。按**失败率**排序时，运行不足 10 次的智能体排在后面，因为样本太少，比例参考价值有限。点智能体名字进入它的详情页，能看到最近的运行和每次失败的原因。

失败原因码归成七类：

| 类别 | 包括 | 一般怎么处理 |
| --- | --- | --- |
| 认证 | 模型服务认证失败或无权限、缺少 API key 等配置 | 在 AI 编程工具里重新登录，或补齐配置 |
| 限流 | 限流、容量不足、配额或余额用尽 | 稍后重试，或提高额度 |
| 超时 | 执行超时、工具长时间无响应、Codex 停滞 | 缩小任务范围，或调整超时设置 |
| 模型服务 | 模型服务端错误、网络故障、模型不可用、请求被拒 | 稍后重试，或换一个可用模型 |
| 运行时 | 运行时离线、守护进程重启、排队过期、skill 包下载失败、找不到工具或版本过旧、准备运行环境失败 | 检查执行这次运行的电脑 |
| 智能体 | 工具进程异常退出、输出无法解析、上下文超出、达到轮次上限、智能体报告无法继续 | 查看执行记录，调整任务后重试 |
| 其他 | 无法归类的失败 | 查看原始错误码和执行记录 |

每个原因码的含义和处理见[运行 · 失败原因参考](/tasks#失败原因参考)。

## 费用怎么算

统计里的费用都是估算值，单位美元，不是 AI 编程工具或模型服务商的账单：

- Multica 内置一张各模型的公开价目表，按每百万 token 分别给输入、输出、缓存读取和缓存写入定价，用它乘以上报的 token 数。
- AI 编程工具自己报告了费用时（例如 Grok Build），这部分直接用报告的数字，不再估算。
- 价目表里没有的模型，token 照常计入，费用按 $0 计算。在运行时的用量里可以给这些模型[设置自定义价格](#自定义价格)。
- 有些模型的提示超过一定长度后单价会上浮，汇总数据区分不出每次请求的长度，统一按标准价算，这类运行的估算可能偏低。

token 由 AI 编程工具上报。工具没有上报时，这次运行仍计入耗时和运行数，但不计 token 和费用。例如目前的 GitHub Copilot CLI 不在输出中提供 token 数，用它的智能体在排行榜上会显示 `≥` 和未上报的次数。

## 运行时的用量

打开**运行时**，进入某个运行时的详情页，可以看到这个运行时的用量。私有运行时的用量只有所有者能看到，公开运行时的用量所有成员都能看到。

- 顶部是**费用**、**缓存节省**和 **Token**。费用下方是和上一个等长时间段的对比；缓存节省估算缓存读取按原价计费会多花多少，下方是缓存命中率。
- **这个运行时在何时消耗**：按天或按周显示费用或 Token。切到**热力图**，用方格颜色深浅显示最近 26 周每天的费用，不受上面的时间范围影响。
- **按智能体分摊**和**按模型分摊**：这段时间的费用分别落在哪些智能体、哪些模型上。
- **每日明细表**：展开后按日期和模型列出每类 token 的数量。

运行时页的时间范围是 `7d`、`30d`、`90d`、`180d`。

## 自定义价格

所选时间范围里有模型不在价目表中时，运行时的用量上方会提示有几个模型没有维护价格，相关 token 未计入费用。点**设置自定义价格**，为每个模型填入输入、输出、缓存读取和缓存写入的单价，单位是美元 / 百万 token，然后保存。所有模型都有价格后，这里仍保留**编辑自定义价格**按钮，方便以后修改。要移除某个模型的价格，清空它的全部字段再保存，或点它旁边的删除按钮。

<Callout type="info">
自定义价格只保存在当前这台设备的浏览器或桌面应用里，不同步到账号，也不会分享给工作区其他成员；同一台设备上的所有工作区都会用它。其他成员看到的费用里，这些模型仍按 $0 计算。
</Callout>

自定义价格只用于价目表里没有的模型，不能覆盖内置价格，也不影响 AI 编程工具自己报告的费用。保存后，这台设备上的统计页、运行时用量和任务的运行记录都会按新价格重新计算。

## 任务的花费

每条任务右侧的**执行日志**会显示这条任务的**已花费**、**Token** 和**智能体工作**时长，以及每次运行一根的费用条。点合计、费用条或**打开时间线**，打开**运行记录**对话框：

- 顶部汇总**已花费**、**Token**（其中多少来自缓存）、**输出**、**智能体工作**和**运行次数**。智能体工作是各次运行时长之和，旁边的"历时"是从第一次运行开始到最后一次结束经过的时间；运行次数旁边列出失败、取消和进行中的次数。
- 图表切**按次**时每次运行一根柱，可以看费用、Token 或智能体工作；切**累计**时显示累计费用随时间增长的曲线。
- **按智能体**和**按模型**两条色带显示费用落在谁身上、哪个模型上。
- 下方按天列出每次运行；展开**运行详情**能看到这次运行的费用明细和缓存命中节省了多少。

对话框底部会注明费用是估算值，以及哪些模型没有价格。

## 用 CLI 查看

```bash
multica issue usage <issue-id>
multica runtime usage <runtime-id> --days 30
```

`issue usage` 输出一条任务的 token 合计（输入、输出、缓存读取、缓存写入）和运行次数。`RUNS` 是已结束的运行数，`METERED_RUNS` 是上报了用量的运行数，`UNREPORTED` 是没有上报的；有运行没上报时，token 数前面带 `>=`，表示实际只会更多。

`runtime usage` 按日期、工具和模型列出一个运行时的 token 用量，`--days` 默认 90，最大 365。

两条命令的表格只有 token，不含费用估算；加 `--output json` 输出接口返回的原始数据。
