Multica iOS 클라이언트는 아직 App Store에 출시되지 않았습니다. Mac에서 공개 소스 저장소의 Release 버전을 빌드해 자신의 iPhone에 설치할 수 있습니다. Android에서는 동일한 React Native 클라이언트로 서명된 독립 실행 APK를 빌드할 수 있습니다.

설치된 앱은 기본적으로 Multica Cloud에 연결되며 기존 계정으로 로그인하면 됩니다. 워크스페이스, 태스크, 댓글, 실행 기록은 모두 서버에 저장되므로 Web이나 Desktop에서 동기화할 필요가 없습니다.

## Android APK

JDK 17과 Android SDK 36을 준비하고 저장소 외부의 Release 서명 키를 설정한 다음 루트에서 실행하세요:

```bash
pnpm -C apps/mobile android:release
```

APK는 기본적으로 Multica Cloud에 연결하며 Metro가 필요 없습니다. 서명, 환경 변형, 자체 호스팅 주소 및 설치 검증은 [Android 빌드 가이드](https://github.com/multica-ai/multica/blob/main/apps/mobile/docs/android-release.md)를 참고하세요. 백그라운드 푸시 알림은 포함되지 않습니다. 아래는 iPhone 설치 안내입니다.

## 준비 사항

다음 항목이 필요합니다.

- Xcode가 설치된 Mac
- **Xcode → Settings → Accounts**에서 로그인한 Apple ID
- USB로 연결된 iPhone
- iPhone의 **설정 → 개인정보 보호 및 보안**에서 활성화한 개발자 모드
- Node.js, pnpm, Git

Xcode 또는 실제 기기 개발 환경이 설정되지 않았다면 먼저 Expo의 [iOS Device 환경 설정](https://docs.expo.dev/get-started/set-up-your-environment/)을 완료하세요.

## iPhone에 설치

<Steps>
<Step>
저장소를 clone하고 의존성을 설치합니다.

```bash
git clone https://github.com/multica-ai/multica.git
cd multica
pnpm install
```
</Step>
<Step>
저장소 루트에서 다음 명령을 실행합니다.

```bash
pnpm ios:mobile:device:prod:release
```

Metro에 의존하지 않는 Release 버전을 빌드해 연결된 iPhone에 설치합니다. 처음 빌드할 때는 iOS 의존성을 내려받고 React Native를 컴파일하며 이후에는 Xcode 캐시를 재사용합니다.
</Step>
<Step>
iPhone에서 앱을 엽니다. 실행이 차단되면 **설정 → 일반 → VPN 및 기기 관리**에서 해당 개발자 인증서를 신뢰하도록 설정하세요.
</Step>
</Steps>

## 무료 서명의 7일 제한

무료 Apple ID로 서명한 앱은 7일 동안만 사용할 수 있습니다. 만료되면 iPhone을 Mac에 다시 연결하고 같은 빌드 명령을 실행해 서명을 갱신하세요.

Apple Developer Program 계정으로 서명하면 유효 기간이 더 길고 TestFlight와 정식 배포에도 사용할 수 있습니다. 어떤 서명을 사용하더라도 재설치나 서명 갱신으로 서버 데이터가 사라지지 않습니다.

## 서명 실패

Xcode에 `No matching provisioning profiles found`가 표시되면 기본 bundle identifier가 Apple ID에 속하지 않을 수 있습니다. 자신이 제어하는 역방향 도메인으로 바꾼 뒤 다시 빌드하세요.

```bash
export EXPO_BUNDLE_IDENTIFIER_PROD=com.yourname.multica
pnpm ios:mobile:device:prod:release
```

이 값은 자신의 Apple Developer team에서 사용할 수 있기만 하면 되며 Multica 계정이나 워크스페이스에는 영향을 주지 않습니다.

## 업데이트

직접 설치한 iOS 버전은 자동으로 업데이트되지 않습니다. 최신 코드를 pull하고 의존성을 업데이트한 뒤 다시 빌드하세요.

```bash
git pull --ff-only
pnpm install
pnpm ios:mobile:device:prod:release
```

## 자체 호스팅 인스턴스 연결

로그인 화면의 **Server settings** 또는 로그인 후 **Settings → Server settings**를 엽니다. **API URL**(백엔드 루트)과 **Web URL**(브라우저와 링크 주소)을 입력하고 저장하세요. 같은 도메인과 분리된 호스트를 모두 지원하며 재시작 후에도 유지됩니다. 다시 빌드할 필요가 없습니다. **Restore Cloud defaults**를 선택한 후 저장하면 Multica Cloud로 돌아갑니다.

두 주소 모두 기기가 신뢰하는 인증서의 HTTPS를 사용해야 합니다. 사용자 지정 포트와 기본 경로를 지원합니다. 예: API `https://multica.example.com:8443/backend`, Web `https://multica.example.com:8443/app`. API 주소 끝의 `/api`는 제거되고 요청 경로가 자동으로 추가합니다. `/auth`와 `/ws`도 같은 백엔드 루트를 사용합니다. 배포 APK는 HTTP나 인증서 검증 우회를 지원하지 않습니다. `localhost`는 휴대전화 자체를 가리킵니다.

주소 하나라도 변경하면 로그아웃되고 로컬 초안, 워크스페이스 선택, 캐시가 지워집니다. 선택한 인스턴스에서 다시 로그인하세요. 서버 데이터는 원래 인스턴스에 남습니다. 파일과 이미지는 선택한 서버에서 새 서명 URL을 받아 사용하며 세션 토큰을 외부 브라우저에 보내지 않습니다.

개발 빌드와 최초 설치 기본값은 [`apps/mobile/README.md`](https://github.com/multica-ai/multica/blob/main/apps/mobile/README.md)를 참고하세요.
