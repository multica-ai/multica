Multica のエージェントを WeCom（企業微信）のスマート Bot として接続すると、チームメンバーは Bot に DM を送る、グループで @メンションする、`/issue` でイシューを作成するといった操作ができます。会話と実行記録は引き続き Multica ワークスペースに保存されます。

各スマート Bot に接続できるエージェントは 1 つだけです。WeCom で複数のエージェントを使う場合は、エージェントごとに Bot を接続してください。

## Bot を接続する

エージェントの所有者、ワークスペースの owner、admin が接続を開始できます。

1. **エージェント**を開き、WeCom に接続するエージェントを選びます。
2. **連携**を開き、**WeCom に接続**をクリックします。
3. WeCom で QR コードをスキャンし、新しいスマート Bot の作成を承認します。
4. Multica に戻ります。画面に **WeCom に接続済み**と表示されたら利用できます。

QR コードの有効期限は 5 分です。期限が切れた場合は **再スキャン** をクリックして再生成してください。

<Callout type="info">
スキャンするたびに WeCom 側で新しいスマート Bot が作成されます。既存の Bot を再承認することはありません。エージェントを切断してから再接続すると、以前とは異なる Bot が作られます。以前の Bot が再利用されたり復元されたりすることはありません。
</Callout>

接続済みのエージェントにはスキャン画面は再表示されません。Bot の名前変更や権限管理は Multica では行えないため、WeCom の管理画面から操作してください。

## 初回利用

メンバーが DM で初めて Bot にメッセージを送ると、アカウント連携用のリンクが届きます。

1. リンクを開き、Multica にログインします。
2. 紐づけるワークスペースのアカウントを確認します。
3. WeCom に戻り、もう一度メッセージを送ります。

連携が完了すると、Multica はメッセージを送ったワークスペースメンバーを特定できるようになります。ワークスペースのメンバーではないユーザーは Bot を利用できません。これは Bot をスキャンしてインストールした本人にも当てはまります。Bot のインストールと、自分の WeCom アカウントを連携することは別のステップです。

連携リンクは Bot との DM でのみ発行されます。グループチャットでは、未連携のメンバーはまず Bot に DM するよう案内されます。

## WeCom から仕事を依頼する

### DM

Bot にそのままメッセージを送ります。後続のメッセージは同じ Multica のチャットセッションに保持され、エージェントの返信も現在の DM に返されます。

### グループチャット

Bot をグループへ追加し、`@` に続けて依頼内容を入力します。Bot が応答するのは、明示的に @メンションされたメッセージだけです。実行時には、現在のセッションで読み取れる直近のコンテキストも利用します。

### イシューを作成する

次のように送信します。

```text
/issue ログイン後のリダイレクトを修正する
Safari ではログインに成功してもログイン画面に残ります。
```

1 行目がタイトルになり、残りの内容が説明になります。`/issue` だけを送信した場合、Multica は直前のメッセージをタイトルとして使おうとします。

## 接続を管理する

**設定 → 連携**を開くと、ワークスペースに接続済みの Bot を確認できます。ワークスペースの owner と admin はここから接続を解除できます。エージェントの所有者は、そのエージェントの**連携**ページから自分の Bot を管理できます。

接続を解除すると、Bot は新しいメッセージを受信しなくなります。既存の会話と監査記録は削除されません。

<Callout type="warning">
接続の解除は Multica 側の紐付けを外すだけで、WeCom 側のスマート Bot は削除されません。完全に削除したい場合は、WeCom の管理画面から自分で削除してください。
</Callout>

## セルフホスト設定

Multica Cloud では追加設定は不要です。セルフホスト環境では、Bot の認証情報を暗号化するキーを先に設定してください。

```dotenv
MULTICA_WECOM_SECRET_KEY=<base64-encoded 32-byte key>
```

次のコマンドで生成できます。

```bash
openssl rand -base64 32
```

API サービスを再起動した後、エージェントの**連携**ページから Bot を接続します。このキーは継続して保管してください。変更または紛失すると既存の認証情報を復号できなくなり、Bot の再接続が必要になります。

Multica Cloud とセルフホスト環境は、スマート Bot 作成に使う WeCom の「source」ID をデフォルトで共有する設計です。これはセキュリティ境界ではないため、セルフホストの場合も自分で source を取得する必要はありません。`MULTICA_WECOM_SOURCE_ID` は、デバッグや将来の source 変更のためにこのデフォルト値を上書きする場合にのみ使用します。通常は設定する必要はありません。

## よくある問題

- **接続ボタンが表示されない**: 現在のアカウントがエージェントの所有者、ワークスペースの owner、admin のいずれかであることを確認します。セルフホストの場合は暗号化キーも確認してください。
- **QR コードの期限が切れた**: 有効期限は 5 分です。ダイアログを閉じて、接続をもう一度開始します。
- **Bot からアカウント連携を求められる**: 連携用リンクを開き、そのワークスペースで使う Multica アカウントにログインします。Bot をインストールした本人であっても、この手順は必要です。
- **一時的な切断のあと、返信がかなり遅れて届いた**: Multica は接続が切れていた間に送信できなかった返信を自動的に再送しますが、さかのぼるのは最大 24 時間までです。それより古いものは再送されません。
- **Bot が実行しない**: エージェントがアーカイブされていないことと、使用する[ランタイム](/daemon-runtimes)がオンラインであることを確認します。
- **再接続したのに WeCom に古い Bot が残っている**: 想定どおりの動作です。Multica 側で接続を解除しても WeCom 側のスマート Bot は削除されません。不要な場合は WeCom の管理画面から削除してください。
