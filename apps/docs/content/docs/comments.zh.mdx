评论是 [任务](/issues) 中持续协作的地方。成员和智能体可以在这里补充背景、提出问题、提交结果，后续打开任务时仍能看到完整上下文。

## 发表评论和回复

在任务的动态区输入内容并发送，即可创建一条评论。评论支持格式、代码块、链接和附件。

回复某条评论会形成一条讨论线程。回复可以继续嵌套，但都归在同一条顶层讨论下。

## 批注评论与任务描述

在 Web 或 Desktop 中，选中任意已发表的评论文字，包括自己的评论，点击选区工具条中的 **加入回复**，引用即加入当前讨论的 reply 草稿。可在选区旁填写意见，随写随存，无需点击完成；点击原文编号标记可继续编辑，也可点击批注框右侧的删除图标，直接移除该批注及其原文标记和草稿条目。鼠标悬停在批注计数上，即可在浮层中查看、删除引用，或点击引用返回原位编辑意见；也支持点击或使用键盘打开浮层。通过原有发送按钮合并发送为一条回复，各条批注之间保留一个空行，任务描述的选区工具条提供 **加入评论**，批注进入新评论草稿，发送后创建新的讨论；评论批注仍进入原讨论的回复草稿。

评论批注的首次引用会确定具体回复目标，包括嵌套回复。同一讨论中其他消息的引用会加入这份草稿。填写至少一条批注内容或整体回复后，使用原有发送按钮，将全部内容作为一条评论发布。引用中的提及不会通知或触发任何人；你自己填写的提及仍遵循普通规则。

草稿仅保存在当前设备和工作区，刷新后可恢复，30 天后过期。每条回复最多包含 20 条批注，每次引用最多 4,000 个字符。原文更改后仍保留引用快照；回复目标被删除时会阻止发送。首版不包含 Chat、移动端批注输入或跨设备草稿同步。

## 解决一条讨论

问题得到结论时，可以把整条讨论标记为已解决，或将某条回复设为结论；一条讨论同时只保留一个结论。已解决的讨论会折叠，仍可展开查看。

在已解决的讨论中继续回复，会自动重新打开这条讨论。

## @提及

输入 `@`，从列表中选择目标：

| 目标 | 效果 |
|---|---|
| **成员** | 收件箱收到提及通知；评论中的 @ 不会产生订阅。 |
| **智能体** | 为该智能体创建一次运行；智能体没有收件箱。 |
| **小队** | 通知小队中的成员，并触发小队 leader 执行。 |
| **任务** | 插入另一条任务的链接，不发通知，不触发智能体。 |
| **@all** | 通知全部工作区成员，不触发任何智能体。 |

直接输入纯文本 `@name` 不会创建提及，需从编辑器的候选列表中选择。输入有效的任务编号时，编辑器会自动转换为任务链接。

<Callout type="info">
在评论中 @智能体不会改变任务的负责人或状态。关于触发预览、普通回复的自动路由和连续评论如何合并，见[在评论中 @智能体](/mentioning-agents)。
</Callout>

## 订阅和收件箱

参与评论的成员会自动订阅这条任务，后续动态和 @提及会进入[收件箱](/inbox)；也可以在任务右上角手动订阅或取消。完整的订阅来源和通知规则见[收件箱与订阅](/inbox)。

## 表情反应

给评论添加表情，可用于确认已读、表达同意或快速反馈。表情不触发智能体，也不改变任务状态。

## 编辑和删除

评论作者可以编辑或删除自己的评论，工作区的 `owner` 和 `admin` 也可以编辑和删除任何人的评论。对智能体发表的评论，界面只提供删除入口，不提供编辑入口。

编辑评论后，Multica 会按新内容重新计算触发。编辑时新增的 @提及同样会创建运行；保存前输入框下方会显示触发预览。

<Callout type="warning">
删除评论无法撤销。删除顶层评论时，其下所有回复一并删除。内容有误时编辑即可。
</Callout>
