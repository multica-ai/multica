**設定 → 外観** では、このデバイスでの Multica の見た目（モード、テーマ、文字、レイアウト）を設定します。変更はすぐに反映されます。

<Callout type="info">
  テーマとテーマストアはベータ版です。今は正しく表示されるテーマでも、Multica のリリース後に作者の更新が必要になることがあります。
</Callout>

## モードとテーマ

**モード** はライト、ダーク、システム（OS の設定に従う）から選びます。検索ボックス（`⌘K`）で「テーマ」と入力して切り替えることもできます。

**テーマ** はアプリ全体の色、枠線、影、角丸を決めます。Multica には Default、Pop、GitHub、Blueprint、Notion が含まれています。ドロップダウンから選びます。隣の **管理** では、ほかのテーマのインストール、アップデート、削除ができます。テーマはライト、ダーク、または両方に対応し、選んだモードに従います。

アクセントカラーやページ幅など、オプションを持つテーマもあります。そのテーマを使っている間は **テーマのオプション** に表示され、**オプションをリセット** でテーマの既定値に戻せます。

ページのほかの設定はテーマとは独立しています。

| グループ | 設定する内容 |
|---|---|
| **インターフェースの文字** | メニュー、ボタン、リスト、サイドバー、見出しのフォントとサイズ。 |
| **本文の文字** | タスクの説明、コメント、チャット、ドキュメントのフォント、サイズ、行の高さと、コードフォント。 |
| **レイアウトとアクセシビリティ** | 表示密度、視差効果を減らす、コントラストを上げる。 |

既定以外のフォントを選んだときや、コントラストを上げるをオンにしたときは、テーマよりあなたの選択が優先されます。色はテーマが決めます。オプションにない色にしたい場合は、別のテーマを選ぶか[自分で作って](/developers/themes)ください。

## テーマストア

**管理** を開くと、インストールしたテーマとコミュニティのテーマストアのテーマがひとつのウィンドウに並びます。組み込みのテーマはここには表示されず、常にドロップダウンにあります。名前や作者で検索でき、**インストール済みのみ表示** をオンにすると持っていないテーマを隠せます。

ストアのテーマはカードで表示されます。スクリーンショット（隅でライトとダークを切り替え）、作者、説明、ダウンロード数、GitHub リポジトリへのリンクがあります。まだインストールしていないテーマはダウンロード数の多い順に並びます。

<Steps>
<Step>

### インストール

カードの **インストール** をクリックします。テーマがダウンロード、チェックされ、このデバイスに保存されて使われます。

</Step>
<Step>

### 切り替え

インストール済みのテーマで **使う** をクリックするか、ドロップダウンから任意のテーマを選びます。使っているテーマには **使用中** と表示されます。

</Step>
<Step>

### 削除

インストール済みのテーマで **削除** をクリックします。使用中だった場合は Default に戻ります。

</Step>
</Steps>

ストアのテーマはコミュニティが作成したもので、掲載前に自動でチェックされます。コードを実行したり、インターネットから何かを読み込んだり、テーマ外のファイルを使ったりはできません。それでも、テーマはダイアログや警告を含むすべてのページのスタイルを変更できます。

ダウンロード数には、同じ Multica サーバーを使うすべての人のインストールとアップデートが 1 回ずつ数えられます。

## アップデート

ストアのテーマをインストールすると、外観ページに **ストアのテーマ** の行が表示されます。**アップデートを確認** で新しいリリースを探し、**すべてアップデート** をクリックします。カードの **… に更新** でテーマを 1 つずつ更新することもできます。アップデートしてもテーマのオプションの値は保たれ、使用中のテーマも変わりません。

テーマが勝手にアップデートされることはありません。

## テーマを読み込む

ファイルで受け取ったテーマや自作のテーマは、**自分で作る → テーマを読み込む** からインストールします。

- **テーマファイル（.zip）** は zip 形式のテーマをインストールします。
- **テーマフォルダ** は展開済みのテーマをインストールします。

インストール前に、テーマの名前、作者、バージョンが表示されます。信頼できる作者のテーマだけをインストールしてください。インストール済みのテーマと同じ id のテーマを読み込むと置き換わります。

テーマを自作するには[テーマを作る](/developers/themes)を参照してください。

## テーマで表示が崩れたとき

テーマによってインターフェースの一部が隠れたり崩れたりすることがあります。Default に戻すには、次のどちらかを行います。

- アドレスの末尾に `?theme=default` を付けて Multica を開く。
- ページの読み込み直後に **Shift** をしばらく押し続ける。デスクトップアプリでは `⌘R`（Windows と Linux では `Ctrl+R`）で再読み込みしてから **Shift** を押し続けます。

ウィンドウを閉じるまでテーマは一時停止します。外観ページに通知が表示され、**テーマを戻す** で再び有効にできます。そこで別のテーマを選んだり、問題のテーマを削除したりもできます。

## 保存場所

モード、テーマ、テーマのオプション、インストールしたテーマはこのデバイスに保存され、アカウントには同期されません。ブラウザごと、デスクトップアプリごとに別々です。同じデバイスのすべてのワークスペースで共通です。

## セルフホスト

セルフホストのサーバーは、既定で公式レジストリ [multica-ai/multica-themes](https://github.com/multica-ai/multica-themes) を表示します。サーバーが GitHub からテーマとスクリーンショットを取得してキャッシュし、アプリはそれをあなたのサーバーからダウンロードします。ダウンロード数はサーバーごとに数えられます。

| 変数 | 効果 |
|---|---|
| `MULTICA_THEME_REGISTRY_URL` | 公式レジストリの fork など、別のレジストリの `index.json` をストアに読ませます。 |

サーバーのほかの設定は[環境変数](/environment-variables)を参照してください。
