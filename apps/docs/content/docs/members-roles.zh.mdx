在[工作区](/workspaces)中，`owner`、`admin` 和 `member` 都能创建任务和发表评论，但管理设置和成员的权限不同。[访客](#访客)只能在分享给自己的项目中查看任务和发表评论。

## 成员管理权限 [#三种角色]

| 操作 | owner | admin | member |
|---|:---:|:---:|:---:|
| 查看工作区并参与日常协作 | ✓ | ✓ | ✓ |
| 修改工作区设置 | ✓ | ✓ | — |
| 邀请 `admin` 或 `member` | ✓ | ✓ | — |
| 调整或移除 `admin`、`member` | ✓ | ✓ | — |
| 授予、收回或移除 `owner` | ✓ | — | — |
| 删除工作区 | ✓ | — | — |

工作区必须始终保留至少一名 `owner`：最后一名 `owner` 不能被降级、移除或离开。

<RolesDemo />

<Callout type="info">
访客无法运行智能体。每个智能体有独立的访问范围（Access），`owner` 和 `admin` 也不能绕过它运行未授权的智能体。详见[智能体](/agents#权限与-access)。
</Callout>

<Callout type="info">
角色同样不会打开私有项目。`owner` 或 `admin` 只有在成员名单里时才能看到私有项目。详见[私有项目](/projects#private-projects)。
</Callout>

## 邀请成员

`owner` 和 `admin` 在**设置 → 成员**中点击**邀请成员**，填写邮箱、选择角色后发送。邀请可以授予 `admin`、`member` 或[访客](#访客)身份；`owner` 需要先加入工作区，再由现有 `owner` 提升。

![成员管理：邀请表单与带角色的成员名册](/images/docs/members-roster.webp)

受邀者用该邮箱登录即可接受，无需提前注册。邀请有效期 7 天，过期后重新发送。在限制注册的自部署实例中，待接受且未过期的邀请允许该邮箱创建账号，无需另外加入白名单，见[登录与注册](/auth-setup#邀请与注册限制)。

邀请链接只出现在邮件里，产品界面中没有查看或复制它的入口。邮件发送失败时邀请记录仍然存在，可以撤销后重新发送。

需要一条能直接转发的链接时，在**设置 → 成员**的**分享链接**中选择角色和有效期后生成。拿到链接的人都可以以所选角色加入，直到链接过期或被撤销；前提是工作区还有空余的成员名额（见下文）。

### 成员上限

在 Multica Cloud 上，Free 套餐的工作区最多 5 位成员。成员和待接受的邀请各占一个名额，访客不占。上限生效时，超出上限的新邀请、接受邀请和通过分享链接加入都会被拒绝，直到空出名额（撤回邀请或移除成员）或工作区升级。已有成员不会被移除。工作区满员时，管理员会在邀请弹窗里看到**升级并邀请**：付款完成后，在**设置 → 账单与套餐**里可以发出这份邀请。Pro 和 Business 每位成员占一个付费席位。自部署的工作区没有成员上限。

## 访客

访客只能看到分享给自己的项目。在这些项目里，访客可以查看任务、评论、添加表情回应和关注任务；不能创建或修改任务，不能运行或 @ agent，也不能打开工作区设置，看不到其他项目、agent、autopilot 和 runtime。访客免费，不占付费席位，也不占成员名额。

`owner` 和 `admin` 在邀请弹窗里选择**访客**并勾选可访问的项目，即可邀请访客。在成员的操作菜单里，可以把成员设为访客（释放其席位，并收回其 agent、autopilot 和 runtime 权限），把访客设为成员（占用一个席位），或通过**管理可访问的项目**调整访客能看到的项目。

在 Multica Cloud 上，Pro 和 Business 包含访客。试用结束或工作区降到 Free 后，已有访客保留访问权限，仍然可以移除、缩小范围或设为成员，但不能再添加新访客。自部署的工作区可以使用访客。

## 调整角色

在成员列表中打开某位成员右侧的操作菜单，选择**更改角色**，角色立即生效。

`admin` 可以在 `admin` 和 `member` 之间调整角色，也可以移除这两类成员。涉及 `owner` 的变更——提升、更改或移除——只有 `owner` 能执行。

## 移除成员

被移除的成员立即失去工作区访问权限。该成员创建的任务、评论和其他协作记录保留在工作区中。

<Callout type="warning">
移除成员会同时停用该成员拥有的运行时、归档绑定在其上的智能体，并取消尚未结束的运行。该成员在智能体访问范围（Access）中获得的授权也会被清除，重新加入后不会自动恢复。
</Callout>
