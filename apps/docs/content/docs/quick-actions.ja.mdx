title: クイックアクション
description: よく使う依頼を保存し、タスクごとに書き直さずに使えます。
---

クイックアクションは、繰り返し使う依頼をタスクのボタンにする機能です。誰に何を頼むかを一度保存すれば、ほかのタスクでも同じ依頼を使えます。

たとえば、レビューエージェント向けに**コードレビュー**を作り、次のように書きます。

> このタスクに関連する変更をレビューしてください。誤りや不足しているテストを確認し、見つけた問題をここに返信してください。

エージェントはタスクの背景を読めるので、説明を依頼にコピーする必要はありません。

## クイックアクションを使う

Web またはデスクトップアプリでは、2 通りの使い方があります。

| 場所 | 起こること |
|---|---|
| タスクのサイドバーの**クイックアクション** | クリックすると保存した依頼をすぐに投稿します。エージェントやスクワッドを設定していれば、その相手に作業を依頼します。 |
| コメント欄で `/` を入力 | アクションを選ぶと、依頼が下書きに入ります。今回の内容に合わせて編集し、準備ができたら送信します。選ぶだけでは投稿されません。 |

クイックアクションを使うこと自体では、担当者やステータスは変わりません。返信はタスクの議論で、エージェントの進み具合は[実行ログ](/tasks)で確認できます。

**対象なし**のアクションは、誰も @メンションせずに保存した文章を投稿します。チェックリストや定型の返信に使えます。

## クイックアクションを作る

1. **設定 → クイックアクション**で**クイックアクションを作成**を選びます。
2. **コードレビュー**や**進捗の要約**など、用途が分かる短い名前を付けます。
3. 個人用なら**自分のみ**、ワークスペースで共有するなら**チーム**を選びます。チーム用の作成・管理には `owner` または `admin` 権限が必要です。メンバーは**自分のみ**を選んでください。
4. **実行者**でエージェントかスクワッドを選びます。メンションのない文章だけを保存したい場合は**対象なし**を選びます。
5. **プロンプト**に送信したい依頼を書き、保存します。書いたとおりに送信され、変数は使えません。

チーム用では、ワークスペースの全員が呼び出せるエージェントを選びます。スクワッドの場合はリーダーに同じ条件が当てはまります。個人用では、自分が呼び出せるエージェントを使えます。

「自分のみ」が制限するのは、保存したアクションを見て使える人です。タスクで投稿したコメントは、そのタスクを見られる人にも見えます。

## 保存したアクションを管理する

**設定 → クイックアクション**で編集、アーカイブ、復元ができます。あとで使う可能性がある場合はアーカイブします。削除すると保存したアクションはなくなりますが、過去のコメントや実行記録は残ります。

使える個人用・チーム用のアクションがない場合、タスクのサイドバーにはクイックアクション欄が表示されません。

エージェントを呼び出せない場合は、管理者に実行者と呼び出し権限の確認を依頼してください。コンピューターがオフラインなら作業はまだ始まりません。[トラブルシューティング](/troubleshooting)を参照してください。
