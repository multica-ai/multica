已有钉钉连接会继续把私聊和 @ 消息交给已绑定的[智能体](/agents)。`/issue`、`/new`、图片、身份绑定和已发现群执行也继续保留。

<Callout type="info">
  新的智能体级钉钉连接与群重新分配入口已退役。已有连接和路由映射继续用于执行兼容。
</Callout>

## 使用已有 Bot

- 私聊会成为与已绑定智能体的 Multica [Chat](/chat)。
- 群聊中只有 @ Bot 的消息会按保留的群路由运行。
- 符合条件的消息所带图片会复制到 Multica 存储。
- **`/issue <标题>`** 会以已绑定成员的身份创建 issue。
- **`/new <消息>`** 会保留历史，但不带之前的上下文运行。

首次符合条件的消息可能返回一次性的 `/dingtalk/bind` 链接。请登录正确的工作区后打开。这个身份回调是独立合同。

## 管理保留连接

在 **Settings → Integrations** 查看已有 Bot 及其已绑定智能体。已发现群路由只读展示，新的重新分配入口已退役。工作区所有者和管理员可以断开连接；会话与审计记录会保留。

已绑定智能体归档后，该路由会停止处理，直到智能体恢复。

## 自部署

已有加密凭证需要 `MULTICA_DINGTALK_SECRET_KEY`。请稳定保留密钥，否则已存凭证将无法解密。Stream mode 主动向外连接，因此不需要公开 webhook URL。

## 故障排查

- **没有新的连接或路由选择操作**：智能体级 writer 已退役。
- **Bot 不响应**：检查连接、已绑定智能体和 [Runtime](/daemon-runtimes)。
