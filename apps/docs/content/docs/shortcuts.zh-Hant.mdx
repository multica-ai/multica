## 搜尋

按 `⌘K`，或者點側邊欄頂部的**搜尋...**，開啟搜尋框。不輸入時，這裡列出**新建任務**和你最近開啟過的任務。輸入關鍵詞後，結果分組顯示：

| 分組 | 能找到什麼 |
|---|---|
| **頁面** | 收件箱、聊天、任務、專案、AI 代理、設定等工作區頁面。中文名稱可以用拼音搜，例如輸入 `renwu` 找到"任務"。 |
| **命令** | 新建任務、新建專案，切換淺色、深色主題或跟隨系統主題。開啟任務詳情時還有複製任務連結、複製識別符號、收起全部評論、展開全部評論。 |
| **成員** | 按姓名或信箱查詢，中文姓名同樣支援拼音。 |
| **工作區** | 你加入的其他工作區，選中後切換過去。 |
| **專案**、**任務** | 匹配標題，也匹配專案說明、任務描述和評論。命中的片段顯示在結果下方；已完成的任務也會出現。 |
| **已取消** | 已取消的專案和任務統一排在最後，不會擠到前面。 |

選中結果後直接跳轉。按住 `⌘`（Windows / Linux：`Ctrl`）再點選或按Enter，會在新標籤頁裡開啟。按 `Esc` 關閉搜尋框。

## 鍵盤快捷鍵

| 操作 | macOS | Windows / Linux | 說明 |
|---|---|---|---|
| 開啟搜尋 | `⌘K` | `Ctrl+K` | |
| 新建任務 | `C` | `C` | 開啟你常用的建立方式。在專案頁按，新任務會預先填好這個專案。 |
| 顯示或隱藏左側邊欄 | `⌘B` | `Ctrl+B` | |
| 顯示或隱藏右側邊欄 | `⌘/` | `Ctrl+/` | 只在有右側欄的頁面可用，例如任務詳情。 |
| 顯示或隱藏聊天窗 | `⌘J` | `Ctrl+J` | 開啟時游標落在輸入框裡。見[懸浮聊天窗](/chat#在任意頁面開啟懸浮聊天窗)。 |
| 在任務中查詢 | `⌘F` | `Ctrl+F` | 見下文。 |
| 歸檔通知 | `E` | `E` | 歸檔收件箱裡當前開啟的通知；檢視已歸檔時則取消歸檔。 |
| 傳送 | `⌘↵` | `Ctrl+Enter` | 傳送評論和聊天訊息，也用於提交新任務。 |
| 後退 | `⌘[` | `Ctrl+[` | |
| 前進 | `⌘]` | `Ctrl+]` | |

單鍵快捷鍵（`C`、`E`）和後退、前進在輸入框裡不起作用，避免打字時誤觸。

**導航**類操作還有前往收件箱、聊天、我的任務、任務、專案、自動化、AI 代理、小隊、統計、執行時、Skills 和設定，預設都沒有設定按鍵，需要時自己繫結。

### 固定的系統快捷鍵

下面這些不能修改。除了 `Esc`，其餘只在[桌面端](/desktop-app)有效；網頁版裡這些按鍵由瀏覽器處理。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 開啟設定 | `⌘,` | `Ctrl+,` |
| 關閉當前標籤頁 | `⌘W` | `Ctrl+W` |
| 選擇第 1–8 個標籤頁 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 選擇最後一個標籤頁 | `⌘9` | `Ctrl+9` |
| 放大 / 縮小 / 重置縮放 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 關閉對話方塊或選單 | `Esc` | `Esc` |

## 修改快捷鍵

<Steps>
<Step>

開啟**設定 → 快捷鍵**。操作多時，用頂部的搜尋框按名稱查詢。

</Step>
<Step>

點選某個操作右側的按鍵，看到"請按鍵"後按下新的組合。`Esc` 取消，`Delete` 清除這個操作的按鍵。

</Step>
<Step>

每行右側的兩個按鈕分別把這一項恢復預設、停用這一項。頂部的**恢復預設設定**會一次撤銷所有自定義。

</Step>
</Steps>

快捷鍵只儲存在當前裝置上。換一臺電腦，或者從瀏覽器換到桌面端，需要重新設定。

錄入時會拒絕幾類組合，並在按鍵下方說明原因：

- 已經分給其他操作的組合。
- 瀏覽器、桌面視窗或系統佔用的組合，例如 `⌘W`、`⌘R`、`⌘Q`、`⌘,`、複製貼上這類編輯鍵、`⌘0`–`⌘9` 和縮放鍵。網頁版裡 `⌘P`、`⌘L`、`⌘T`、`⌘N`、`⌘D`、`⌘U` 也不能用，桌面端可以。Windows 和 Linux 上帶 Win / Super 鍵的組合都不能用。
- 開啟搜尋、聊天窗、在任務中查詢這類在輸入框裡也生效的操作，必須帶 `⌘`、`Ctrl` 或 `Control`，否則打字時會誤觸。
- **傳送**只能是 `↵` 或 `⌘↵`。

<Callout>
把**傳送**改成 `↵` 後，換行改用 `Shift+Enter`：它會插入新段落、繼續列表，或者在程式碼塊裡換行。
</Callout>

## 在任務中查詢

在任務詳情頁按 `⌘F`，開啟的是 Multica 自己的查詢欄，不是瀏覽器的查詢。瀏覽器查詢只能找到已經捲動到螢幕上的評論；這裡會把整條時間線都納入查詢，包括標題、描述和所有評論。

查詢不區分大小寫，查詢欄顯示"當前 / 總數"，沒有結果時顯示"無匹配結果"。按 `↵` 跳到下一個，`Shift+Enter` 跳到上一個，`Esc` 關閉。一段文字中間跨了格式（例如一半加粗）時，查不到這段。

在桌面端，只有當前顯示的標籤頁會響應 `⌘F`。

## 偏好設定

個人偏好在**設定 → 偏好設定**裡，改動立即生效。各組的儲存範圍不同：

| 分組 | 設定 | 儲存在 |
|---|---|---|
| **語言與地區** | 語言：English、中文、한국어、日本語、Français。切換後頁面會重新載入。<br />時區：預設跟隨瀏覽器；用於所有工作區的日期和圖表，可以搜尋全部時區。 | 帳號，其他裝置同步 |
| **外觀** | 主題：淺色、深色、跟隨系統。也可以在搜尋框裡輸入"主題"切換。 | 當前裝置 |
| **評論與聊天** | **固定底部評論欄**：開啟時，閱讀很長的時間線也能隨時看到評論框。<br />**回覆正在執行的 AI 代理時**：預設"插話到當前執行"還是"本輪結束後開始"，傳送前每條訊息仍可單獨改，見[給正在執行的 AI 代理插話](/mentioning-agents#給正在執行的 AI 代理插話)。<br />**懸浮聊天窗**：關閉後，頁面右下角不再顯示聊天按鈕。 | 當前裝置 |
| **開啟任務** | 點選卡片或行時開啟詳情頁還是懸浮預覽。按住 Shift 點選會開啟另一種。 | 當前裝置 |
| **建立任務時顯示的欄位** | 分別為"AI 代理建立"和"手動建立"選擇工具欄上常駐的欄位。隱藏的欄位仍可從 ⋯ 選單使用，有值時自動顯示。 | 當前裝置上的當前工作區 |
