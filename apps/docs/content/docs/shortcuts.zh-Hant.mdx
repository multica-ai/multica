## 搜尋

按 `⌘K`，或者點應用側欄中的**搜尋...**，開啟搜尋框。不輸入時，這裡列出**新建任務**和你最近開啟過的任務。輸入關鍵詞後，結果分組顯示：

| 分組 | 能找到什麼 |
|---|---|
| **頁面** | 收件箱、聊天、任務、專案、AI 代理、設定等工作區頁面。中文名稱可以用拼音搜，例如輸入 `renwu` 找到"任務"。 |
| **檢視** | 按名稱尋找內建任務檢視和你有權存取的已儲存檢視。 |
| **命令** | 新建任務、新建專案，切換淺色、深色主題或跟隨系統主題。開啟任務詳情時還有複製任務連結、複製識別符號、收起全部評論、展開全部評論。 |
| **成員** | 按姓名或信箱查詢，中文姓名同樣支援拼音。 |
| **工作區** | 你加入的其他工作區，選中後切換過去。 |
| **專案**、**任務** | 匹配標題，也匹配專案說明、任務描述和評論。命中的片段顯示在結果下方；已完成的任務也會出現。 |
| **已取消** | 已取消的專案和任務統一排在最後，不會擠到前面。 |
| **交給 AI 代理** | 有輸入時固定顯示在最後一行。選中後開啟**透過 AI 代理建立**，預填你輸入的內容、目前專案，並把目前開啟的任務設為父任務；在彈窗裡確認後才會建立。 |

選中結果後直接跳轉。按住 `⌘`（Windows / Linux：`Ctrl`）再點選或按Enter，會在新標籤頁裡開啟。按 `Esc` 關閉搜尋框。

## 鍵盤快捷鍵

在輸入框以外的任何地方按 `?`，可以看到全部快捷鍵。目前頁面用得上的分組排在最前面，標著**目前頁面**；在頂部的框裡輸入可以按名稱篩選。底部的連結開啟**設定 → 快捷鍵**。

| 操作 | macOS | Windows / Linux | 說明 |
|---|---|---|---|
| 顯示快捷鍵 | `?` | `?` | |
| 開啟搜尋 | `⌘K` | `Ctrl+K` | |
| 新建任務 | `C` | `C` | 開啟你常用的建立方式。在專案頁按，新任務會預先填好這個專案。 |
| 顯示或隱藏左側邊欄 | `⌘B` | `Ctrl+B` | |
| 顯示或隱藏右側邊欄 | `⌘/` | `Ctrl+/` | 只在有右側欄的頁面可用，例如任務詳情。 |
| 顯示或隱藏聊天窗 | `⌘J` | `Ctrl+J` | 開啟時游標落在輸入框裡。見[懸浮聊天窗](/chat#在任意頁面開啟懸浮聊天窗)。 |
| 問 Multica | `⇧⌘J` | `Ctrl+Shift+J` | 在懸浮聊天窗裡開始新對話。 |
| 在任務中查詢 | `⌘F` | `Ctrl+F` | 見下文。 |
| 歸檔通知 | `E` | `E` | 在收件箱頁面上，歸檔當前開啟的通知並開啟下一條；在已歸檔分頁下則把它移回收件箱。見[收件箱](/inbox#處理通知)。 |
| 延後通知 | `H` | `H` | 在收件箱頁面上，延後當前開啟的任務並開啟下一條；已延後的任務則讓它現在回來。 |
| 切換通知未讀狀態 | `U` | `U` | 在收件箱頁面上，原地切換目前開啟的活躍通知的未讀/已讀狀態，不離開目前通知。 |
| 下一條通知 | `J` | `J` | 在收件箱頁面上，切換到目前分頁的下一條通知，不歸檔目前通知。 |
| 上一條通知 | `K` | `K` | 在收件箱頁面上，切換到目前分頁的上一條通知，不歸檔目前通知。 |
| 復原收件箱操作 | `Z` | `Z` | 歸檔、延後或取消訂閱的提示還在時，復原這次操作；沒有提示時，把已歸檔的目前通知放回收件箱，或復原**收件箱已清空**頁面上寫明的操作。 |
| 傳送 | `⌘↵` | `Ctrl+Enter` | 傳送評論和聊天訊息，也用於提交新任務。 |
| 語音輸入 | 未設定 | 未設定 | 僅 Desktop；先在設定 → 語音輸入中啟用。見[語音輸入](/desktop-app#語音輸入)。 |
| 後退 | `⌘[` | `Ctrl+[` | |
| 前進 | `⌘]` | `Ctrl+]` | |

單鍵快捷鍵和後退、前進在輸入框裡不起作用，避免打字時誤觸。

### 前往頁面

先按 `G`，再在一秒半內按第二個鍵：

| 按鍵 | 前往 |
|---|---|
| `G` `I` | 收件箱 |
| `G` `M` | 我的任務 |
| `G` `T` | 任務 |
| `G` `P` | 專案 |
| `G` `C` | 聊天 |
| `G` `A` | AI 代理 |

設定裡的**導航**類還有前往自動化、小隊、統計、執行時、Skills 和設定，預設沒有按鍵，需要時自己繫結。前往收件箱開啟的是收件箱頁面，通知列表本身是工作面板裡的一個分區，就在固定下面。前往我的任務開啟的是"我的任務"頁面，和工作面板裡的**我的工作**檢視不是一回事。

`G` 等第二個鍵的時候，這個鍵歸這組按鍵：`G` 再按 `P` 會開啟專案，而不是設定優先級。按別的鍵就結束等待，那個鍵照常生效。

### 處理任務

這些按鍵作用於你眼前的任務：開啟的任務詳情頁、懸浮預覽裡的任務、列表裡選取的任務，或列表游標所在的那一行。每個鍵開啟的選擇器和搜尋框裡對應的命令一樣，並且已經對準這個任務或這些選取項。

| 操作 | 按鍵 | 說明 |
|---|---|---|
| 變更狀態 | `S` | |
| 指派負責人 | `A` | |
| 設定優先級 | `P` | |
| 編輯標籤 | `L` | |
| 設定截止日期 | `⇧D` | Windows 和 Linux 上是 `Shift+D`。 |
| 移動到專案 | `⇧P` | Windows 和 Linux 上是 `Shift+P`。 |
| 執行快捷操作 | `Q` | 針對單個任務，工作區裡有啟用的快捷操作時可用。 |
| 回覆 | `R` | 把游標放進目前任務的評論框。 |

訪客只能用 `R`。

### 在列表和看板中移動

在任務列表、表格或看板上，下面的鍵會在任務之間移動一個游標。這些鍵不能改。滑鼠指向某一行時，游標移到那一行並隱藏；下一次按鍵從那一行接著走。

| 操作 | macOS | Windows / Linux | 說明 |
|---|---|---|---|
| 下移 / 上移 | `J` / `K`，或 `↓` / `↑` | `J` / `K`，或 `↓` / `↑` | 第一次按從頂部開始，往上按則從底部開始。 |
| 在看板欄之間移動 | `←` / `→` | `←` / `→` | 只在看板上。看板的懸浮預覽裡，`H` / `L` 作用相同。 |
| 開啟 | `↵` | `Enter` | 按偏好設定裡**開啟任務**的方式開啟。 |
| 預覽 | `Space` | `Space` | 開啟或關閉懸浮預覽。 |
| 選取 | `X` | `X` | 把任務加入選取，或從選取裡去掉。 |
| 擴展選取 | `⇧↓` / `⇧↑` | `Shift+↓` / `Shift+↑` | |
| 全選 | `⌘A` | `Ctrl+A` | 游標已顯示或已有選取項時可用。 |
| 取消選取 | `Esc` | `Esc` | 再按一次 `Esc` 隱藏游標。 |

### 固定的系統快捷鍵

下面這些不能修改。除了 `Esc`，其餘只在[桌面端](/desktop-app)有效；網頁版裡這些按鍵由瀏覽器處理。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 開啟設定 | `⌘,` | `Ctrl+,` |
| 關閉當前標籤頁 | `⌘W` | `Ctrl+W` |
| 選擇第 1–8 個標籤頁 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 選擇最後一個標籤頁 | `⌘9` | `Ctrl+9` |
| 放大 / 縮小 / 重置縮放 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 關閉對話方塊或選單 | `Esc` | `Esc` |

## 修改快捷鍵

<Steps>
<Step>

開啟**設定 → 快捷鍵**。操作多時，用頂部的搜尋框按名稱查詢。

</Step>
<Step>

點選某個操作右側的按鍵，看到"請按鍵"後按下新的組合。`Esc` 取消，`Delete` 清除這個操作的按鍵。

**導航**類操作還可以錄兩個連按的鍵，例如 `G` 再按 `U`。按下一個字母後，這一行會等第二個鍵：`↵` 保留單個字母，`Backspace` 重新開始。

</Step>
<Step>

每行右側的兩個按鈕分別把這一項恢復預設、停用這一項。頂部的**恢復預設設定**會一次撤銷所有自定義。

</Step>
</Steps>

快捷鍵只儲存在當前裝置上。換一臺電腦，或者從瀏覽器換到桌面端，需要重新設定。

錄入時會拒絕幾類組合，並在按鍵下方說明原因：

- 已經分給其他操作的組合。單個鍵也會和以它開頭的連按衝突：前往收件箱是 `G` 再按 `I` 時，其他操作不能單獨用 `G`。
- 非**導航**類操作的連按，或者第一個鍵不是普通字母、數字或符號的連按。
- 瀏覽器、桌面視窗或系統佔用的組合，例如 `⌘W`、`⌘R`、`⌘Q`、`⌘,`、複製貼上這類編輯鍵、`⌘0`–`⌘9` 和縮放鍵。網頁版裡 `⌘P`、`⌘L`、`⌘T`、`⌘N`、`⌘D`、`⌘U` 也不能用，桌面端可以。Windows 和 Linux 上帶 Win / Super 鍵的組合都不能用。
- 開啟搜尋、聊天窗、在任務中查詢這類在輸入框裡也生效的操作，必須帶 `⌘`、`Ctrl` 或 `Control`，否則打字時會誤觸。 語音輸入也允許 `Option` / `Alt` 加 `Space` 等不輸入文字的按鍵，但不能使用已被佔用的組合。
- **傳送**只能是 `↵` 或 `⌘↵`。

<Callout>
把**傳送**改成 `↵` 後，換行改用 `Shift+Enter`：它會插入新段落、繼續列表，或者在程式碼塊裡換行。
</Callout>

## 在任務中查詢

在任務詳情頁按 `⌘F`，開啟的是 Multica 自己的查詢欄，不是瀏覽器的查詢。瀏覽器查詢只能找到已經捲動到螢幕上的評論；這裡會把整條時間線都納入查詢，包括標題、描述和所有評論。

查詢不區分大小寫，查詢欄顯示"當前 / 總數"，沒有結果時顯示"無匹配結果"。按 `↵` 跳到下一個，`Shift+Enter` 跳到上一個，`Esc` 關閉。一段文字中間跨了格式（例如一半加粗）時，查不到這段。

在桌面端，只有當前顯示的標籤頁會響應 `⌘F`。

## 偏好設定

個人偏好在**設定 → 偏好設定**裡，改動立即生效。各組的儲存範圍不同：

| 分組 | 設定 | 儲存在 |
|---|---|---|
| **語言與地區** | 語言：English、中文、한국어、日本語、Français。切換後頁面會重新載入。<br />時區：預設跟隨瀏覽器；用於所有工作區的日期和圖表，可以搜尋全部時區。 | 帳號，其他裝置同步 |
| **外觀** | 在獨立的 **設定 → 外觀** 頁面：模式（淺色、深色、跟隨系統）、主題、字型和版面。也可以在搜尋框裡輸入"主題"切換模式。見 [主題與外觀](/themes)。 | 當前裝置 |
| **評論與聊天** | **固定底部評論欄**：開啟時，閱讀很長的時間線也能隨時看到評論框。<br />**回覆正在執行的 AI 代理時**：預設"插話到當前執行"還是"本輪結束後開始"，傳送前每條訊息仍可單獨改，見[給正在執行的 AI 代理插話](/mentioning-agents#給正在執行的-ai-代理插話)。<br />**懸浮聊天窗**：關閉後，底部狀態列裡不再有快捷聊天（窄視窗也不再顯示右下角的圓形聊天按鈕）。 | 當前裝置 |
| **開啟任務** | 點選卡片或行時開啟詳情頁還是懸浮預覽。按住 Shift 點選會開啟另一種。 | 當前裝置 |
| **建立任務時顯示的欄位** | 分別為"AI 代理建立"和"手動建立"選擇工具欄上常駐的欄位。隱藏的欄位仍可從 ⋯ 選單使用，有值時自動顯示。 | 當前裝置上的當前工作區 |
