Docs는 배포 환경에서 기능이 활성화된 경우에만 워크스페이스에 표시됩니다. 자체 호스팅 환경에서 테스트하려면 서버 환경 변수에 `FF_DOCS_V1=true`를 설정하세요.

웹 또는 데스크톱 앱에서 워크스페이스 사이드바의 **문서**를 엽니다. 온보딩 체크리스트나 프로젝트 결정 사항처럼 팀이 나중에 다시 볼 정보를 정리할 수 있습니다.

## 문서 만들기 및 공유

문서와 폴더는 워크스페이스 범위에 속합니다. 비공개 프로젝트에서 문서에 링크하거나 폴더에 프로젝트 이름을 붙여도 해당 프로젝트 멤버로 접근이 제한되지는 않습니다.

1. 문서 사이드바에서 **새로 만들기**를 선택한 뒤 **새 문서** 또는 **새 폴더**를 선택합니다. 폴더 옆의 더하기 버튼으로 해당 폴더에 문서를 만들 수 있습니다.
2. 제목을 추가하고 본문을 작성합니다. `/`를 입력하여 제목, 체크리스트, 표 등의 블록을 삽입합니다. 이미지를 붙여넣거나 끌어다 놓으면 워크스페이스 첨부 파일로 추가됩니다.
3. **저장됨**이 표시되면 공유합니다. 상단 바에서 링크를 복사하거나 이슈, 댓글 또는 채팅에서 `@` 뒤에 문서 제목을 입력해 링크를 삽입합니다.

문서나 폴더를 대상 위치로 끌어 놓거나 메뉴에서 **이동...** 항목을 선택하여 정리할 수 있습니다. 비어 있는 폴더는 삭제할 수 있습니다. 문서를 삭제하면 버전 기록도 삭제됩니다.

워크스페이스 소유자와 관리자는 모든 문서와 빈 폴더를 삭제할 수 있습니다. 다른 멤버는 자신이나 자신이 소유한 에이전트가 만든 항목을 삭제할 수 있습니다.

워크스페이스 검색에서 문서 제목이나 본문에 있는 단어를 검색할 수 있습니다.

## 초안 및 버전 복원

편집 중에 다른 사람이 새 버전을 저장하면 Multica가 초안을 보존하고 **최신 버전 불러오기**를 안내합니다. 기존 초안은 최신 내용 옆에서 확인할 수 있습니다. 유지할 부분을 복사하세요.

**기록**에서 이전 버전을 미리 볼 수 있습니다. **이 버전 복원**을 선택하면 해당 내용이 현재 버전이 됩니다. 복원하면 새 버전이 기록되고 기존 기록도 유지됩니다. 연속으로 편집하는 동안의 자동 저장은 하나의 기록으로 묶일 수 있습니다.

## 에이전트와 문서 작업

에이전트에게 링크한 문서를 읽거나 업데이트하도록 요청하고, 유지해야 할 내용을 알려 줍니다. [CLI](/cli)에서는 `multica doc search "<query>"`로 문서를 찾고 `multica doc get`으로 Markdown과 리비전을 확인합니다. `multica doc update`에 `--base-revision`으로 해당 리비전을 전달합니다. 그사이에 다른 사람이 저장했다면 최신 내용을 가져와 변경 사항을 합친 뒤 다시 시도합니다.
