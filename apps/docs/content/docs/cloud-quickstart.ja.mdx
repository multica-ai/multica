<Callout type="info">
エージェントが実行するには、実行するコンピュータに Claude Code、Codex、Cursor などの[サポートされている AI コーディングツール](/providers)が少なくとも 1 つインストールされ、ログイン済みである必要があります。Multica にこれらのツールは同梱されていません。
</Callout>

<Steps>
<Step>

## ログインしてワークスペースに入る [#1-ログインしてワークスペースに入る]

Web（[multica.ai](https://multica.ai)）または [Multica Desktop](https://multica.ai/download) でログインします。メール認証コードと Google に対応しています。Desktop でログインした場合は次のステップでこのコンピュータを自動で接続でき、Web の場合はコマンドラインから接続します。

</Step>
<Step>

## コンピュータを接続する [#2-コンピュータを接続する]

エージェントは接続されたコンピュータ上で作業を実行します。サイドバーの **AI チーム** にある **ランタイム** を開きます。

- **Desktop の場合**：Desktop がこのコンピュータをランタイムとして自動登録し、インストール済みの AI コーディングツールを検出します。インストールしたばかりのツールは、「更新」をクリックして再検出します。
- **Web の場合、または別のコンピュータを追加する場合**：右上の **追加** をクリックして **他のマシンまたはサーバー** を選び、ダイアログに表示される 2 つのコマンドを対象コンピュータのターミナルで実行します。

<Tabs groupId="os" persist items={["macOS / Linux", "Windows"]}>
<Tab value="macOS / Linux">

```bash
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
multica setup
```

</Tab>
<Tab value="Windows">

```powershell
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
multica setup
```

</Tab>
</Tabs>

`multica setup` はブラウザを開いてログインを完了し、その後デーモンをバックグラウンドで実行し続けます。デーモンがオンラインになると、通常 1 分以内にダイアログがこのコンピュータを検出します。

**成功の目安**：ランタイム一覧にオンラインのコンピュータが表示されます。

![「コンピュータを追加」ダイアログ：2 つのコマンドと検出待ちの案内](/images/docs/quickstart-add-computer.webp)

<Callout type="info">
セルフホストインスタンスでは接続コマンドが少し異なります。[セルフホストクイックスタート](/self-host-quickstart)を参照してください。
</Callout>

</Step>
<Step>

## エージェントを作成する [#3-エージェントを作成する]

サイドバーの **AI チーム** にある **エージェント** を開き、**新規エージェント** をクリックします。まず接続したコンピュータ上の AI コーディングツールを選び、名前を入力して **エージェントを作成** をクリックします。必須項目はランタイムと名前だけです。

設定を一から書きたくない場合は、設定画面で **AI に書いてもらう** をクリックすると、Agent Builder が質問しながら設定を補います。これには選択したランタイムがオンラインである必要があります。残りの設定は後から整えられます。詳しくは[エージェントの作成と構成](/agents-create)を参照してください。

**成功の目安**：エージェント一覧に作成したエージェントが表示され、オンラインと表示されます。

</Step>
<Step>

## 最初のタスクを任せる [#4-最初のタスクを任せる]

サイドバー上部の **新規タスク** をクリックします（またはショートカット `C`）。デフォルトのエージェントモードでは次のように進めます。

1. **作成者** で、作成したばかりのエージェントを選択します。
2. やってほしいことを一言二言で説明します。例：「このワークスペースの使い方を紹介して」。
3. 送信します。Multica がタスクを作成し、エージェントを担当者に設定して、すぐに実行を開始します。

![新規タスクダイアログのエージェントモード：Created by に Multica Assistant が選択されている](/images/docs/quickstart-new-issue.webp)

</Step>
<Step>

## 進捗と結果を確認する [#5-進捗と結果を確認する]

送信後にそのタスクを開きます。実行ログには実行のステータスが表示され、エージェントの進捗と返信はタイムラインに表示されます。

**成功の目安**：実行ログのステータスが「完了」に変わり、タイムラインにエージェントの返信が表示されます。全過程を確認するには、「トランスクリプトを表示」をクリックします。

![タスク内のエージェントの返信と完了した実行ログ](/images/docs/quickstart-run-result.webp)

</Step>
</Steps>

## よくある問題

| 症状 | まず確認すること |
|---|---|
| ランタイムが見つからない | AI コーディングツールがインストール済みで、ターミナルから実行できることを確認します。Desktop では「更新」をクリックし、CLI の場合は `multica setup` を再実行します。 |
| ランタイムがオフラインと表示される | Desktop を開いたままにします。CLI の場合は `multica daemon status` を実行し、起動していなければ `multica daemon start` を実行します。 |
| タスクがキューに入ったまま | エージェントが使うランタイムがオンラインであることを確認します。ランタイムが同時実行の上限に達している場合、新しい実行はキューで待機し続けます。 |

その他のケースは[トラブルシューティング](/troubleshooting)を参照してください。
