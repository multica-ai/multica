title: CodeGraph 代码图谱
description: 让智能体查询仓库快照中的代码和文档。
---

CodeGraph 为 Git 仓库中的源代码和 Markdown、YAML 文档建立索引。
智能体可以查找符号、查看调用关系、读取源码行，无需在自己的电脑上克隆仓库。

## 导入仓库

导入第一个仓库前，就可以在 CodeGraph 首次使用页面管理 **Git 凭据**。
注册表单的凭据选择框旁也有 **管理凭据** 入口，不需要先注册仓库。
环境未配置加密密钥时，会说明暂时不能保存 Token；这与“还没有添加凭据”是两种状态。

打开 **团队 → 资源 → CodeGraph → 注册仓库**，填写 HTTPS Git 地址和分支。
私有仓库选择已保存的 Git 凭据，公开仓库可以明确选择匿名访问。验证访问后再注册。

工作区所有者和管理员可以管理仓库和 Git 凭据，成员可以查看仓库详情并查询构建成功的快照。
导入后的内容供工作区内使用，Git Token 只负责拉取仓库。
请确认你有权向当前工作区共享这些代码。

Git 凭据属于工作区。Token 加密保存，保存后不会显示原文。
建议使用只包含所需仓库读取权限的 Token。撤销 Token 会阻止后续拉取，
但不会删除已经建立的索引；如需停止提供这些内容，请删除仓库。

## 构建和查询

构建过程显示排队、拉取、解析和保存等阶段，排队不计入执行超时。
可以取消排队或正在执行的构建，也可以在代码更新后重新构建。
重新构建失败时，上一次成功的快照仍可查询。

需要排查问题时，打开 **详情 → 高级 → 查询检查**，可以搜索符号和文档、查看调用方与被调用方、
分析影响范围或读取源码行。结果会标明构建版本和 Git 提交。
连续查询时使用同一个构建 ID，核对源码后再判断调用关系；
没有结果不代表代码或行为一定不存在。

## 设置使用范围

打开 **团队 → 资源 → CodeGraph**，进入仓库详情，点击 **设置使用范围**。
三个分区分别显示当前已选对象及数量。点击 **选择智能体** 或 **选择项目**，勾选后保存；
点击 **开启共享**，则允许工作区现有和以后创建的全部智能体使用。

| 范围 | 什么时候可以使用 | 谁能管理 |
| --- | --- | --- |
| 指定智能体 | 该智能体的任务和对话 | 智能体所有者、工作区所有者和管理员 |
| 指定项目 | 该项目的任务和项目对话 | 工作区所有者和管理员 |
| 工作区全部智能体 | 工作区现有及以后创建的智能体 | 工作区所有者和管理员 |

新图谱默认不向智能体分配。各范围取并集，移除一项分配后，其他来源的权限仍然有效。
工作区成员可以在页面查询所有图谱；这里设置的是智能体工具的使用范围，不是成员之间的仓库隔离。
Git 凭据始终保留在服务端，不会交给智能体。

项目页面显示项目分配和工作区共享的图谱；智能体配置显示直接分配及工作区共享。
执行记录中可以查看本次运行当前可用的图谱和授权来源，这不是之前实际读取代码的审计记录。

服务端根据已认证任务关联的任务项或项目对话判断项目，在提示词中提及其他项目不会获得权限。
任务项移动到其他项目后，下一次工具调用按新的项目检查。
没有关联项目的普通对话，只能使用直接分配及工作区共享的图谱。

## 使用智能体工具

分配并构建成功后，在任务或对话中让智能体查找相关代码、分析调用关系并核对源码即可。
不需要在管理页面填写符号 ID 或源码行范围；**查询检查** 主要用于排查索引和查询问题。

分配图谱不会安装工具，也不会让离线运行时上线。图谱仍需至少一次构建成功才能查询。
守护进程会为支持本地工具的运行时注入 CodeGraph MCP 工具；
需要使用包含此功能的 CLI，并在升级后重启旧守护进程；只升级平台不会让旧 CLI 自动具备注入能力。
无法接收本地工具的云端运行时不支持这种接入方式。

每次工具调用都会重新检查所有授权来源。移除全部来源后，正在运行的任务也不能继续查询该仓库，
但已经进入对话的源码不会因此消失。

## 查询权限

查询图谱需要工作区成员身份或已授权的智能体运行令牌。
通过匿名方式拉取公开 Git 仓库，不会让图谱变成公共内容。
本集成不提供匿名图谱查询或 skill 导出。

本集成只使用其中一部分接口，不代表已接入原项目最新版本的全部功能。
