title: ワークスペースのドキュメント
description: チームのメモ、決定事項、参考資料をまとめ、以前のバージョンを復元します。
---

Docs は、デプロイ先で機能が有効な場合にワークスペースに表示されます。セルフホスト環境で試すには、サーバーの環境変数に `FF_DOCS_V1=true` を設定します。

Web またはデスクトップアプリで、ワークスペースのサイドバーから **ドキュメント** を開きます。オンボーディング用のチェックリストやプロジェクトの決定事項など、チームで後から参照する情報をまとめておけます。

## ドキュメントを作成して共有する

ドキュメントとフォルダーはワークスペース単位で管理されます。非公開プロジェクトからドキュメントにリンクしたり、そのプロジェクト名をフォルダーに付けたりしても、アクセスはプロジェクトのメンバーに限定されません。

1. ドキュメントのサイドバーで **新規** を選び、**新規ドキュメント** または **新規フォルダ** を選びます。フォルダの横にあるプラスボタンから、そのフォルダ内にドキュメントを作成できます。
2. タイトルを付けて本文を入力します。`/` を入力すると、見出し、チェックリスト、表などを挿入できます。画像を貼り付けるかドロップすると、ワークスペースの添付ファイルになります。
3. **保存済み** と表示されてから共有します。上部のバーでリンクをコピーするか、課題、コメント、チャットで `@` に続けてドキュメントのタイトルを入力するとリンクできます。

整理するには、ドキュメントやフォルダを移動先にドラッグするか、メニューの **移動...** を選びます。空のフォルダは削除できます。ドキュメントを削除すると、そのバージョン履歴も削除されます。

ワークスペースのオーナーと管理者は、すべてのドキュメントと空のフォルダーを削除できます。他のメンバーは、自分または自分が所有するエージェントが作成したものを削除できます。

ワークスペース検索では、ドキュメントのタイトルや本文に含まれる語句で検索できます。

## 下書きやバージョンを復元する

編集中に他の人が新しいバージョンを保存すると、Multica は下書きを保持し、**最新版を読み込む** ように促します。下書きは現在の内容と並べて確認できます。残したい部分をコピーしてください。

**履歴** を開くと以前のバージョンを確認できます。**このバージョンを復元** を選ぶと、その内容が現在のバージョンとなります。復元は新しいバージョンとして記録され、既存の履歴は保持されます。続けて編集している間の自動保存は、履歴の一つの項目にまとまることがあります。

## エージェントとドキュメントを扱う

リンクしたドキュメントの読み取りや更新をエージェントに依頼できます。更新時には残すべき内容も伝えてください。[CLI](/cli) では `multica doc search "<query>"` でドキュメントを探し、`multica doc get` で Markdown とリビジョンを取得します。更新するには `multica doc update` に `--base-revision` でその値を渡します。別の変更が先に保存された場合は、最新版を取得して変更を反映してからやり直します。

`multica doc folder list` でフォルダー ID を確認し、`multica doc folder create --title "<title>"` でフォルダーを作成できます。別のフォルダー内に作成するには `--parent <folder-id>` を指定します。ドキュメントの移動には `multica doc move <doc-id> --folder <folder-id>` を使います。最上位に移動する場合は `--folder root` を指定します。フォルダーの名前変更と移動のコマンドは `multica doc folder --help` で確認できます。
