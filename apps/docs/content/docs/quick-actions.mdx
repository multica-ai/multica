Quick Actions turn requests you use often into buttons on an issue. Save who to ask and what to say once, and reuse it on other issues with a click.

For example, create **Code Review** for your review agent with this prompt:

> Review the changes linked to this issue. Check for mistakes and missing tests, and post your findings here.

The agent already has the issue's context, so you do not need to copy its description into the request.

## Use a quick action

In the web or desktop app, there are two ways to use an action:

| Where | What happens |
|---|---|
| **Quick Actions** in the issue sidebar | Click an action to post its saved request immediately. If it has an agent or squad, it asks them to work on this issue. |
| Type `/` in the comment box | Choose an action to insert its request as a draft. Edit it for this issue, then send when ready. Nothing is posted just by choosing it. |

<QuickActionDemo />

Using a quick action does not change the issue's assignee or status. Follow the reply in the issue's discussion and check the [execution log](/tasks) for the agent's progress.

An action with **No target** posts the saved message without @mentioning anyone. Use it for a checklist or a response you often write.

## Create a quick action

<Steps>
<Step>

Open **Settings → Quick Actions** and choose **New quick action**.

</Step>
<Step>

Give it a short name that describes the request, such as **Code Review** or **Summarize progress**.

</Step>
<Step>

Choose **Just me** for your own use, or **Team** to share it with the workspace. Creating and managing Team actions requires `owner` or `admin` permissions; members should choose **Just me**.

</Step>
<Step>

Choose an agent or squad under **Runs as**, or choose **No target** to save a message without a mention.

</Step>
<Step>

Write the **Prompt** as you want it sent, then save. It is sent as written; variables are not supported.

</Step>
</Steps>

Team actions that call an agent must use one everyone in the workspace can run. For a squad, this applies to its leader. Personal actions can use agents you have permission to run.

“Just me” controls who can see and use the saved action. Once you use it on an issue, its posted comment is visible to people who can see that issue.

## Manage saved actions

In **Settings → Quick Actions** you can edit an action, archive it, or restore an archived one. Archive an action you don't need now but may want later. Deleting it removes the saved action; past comments and run records stay.

When there are no personal or Team actions you can see, the issue sidebar does not show a Quick Actions section. The sidebar list is not filtered by who can run each action; permission is checked when you click one.

If clicking an action tells you it can't run, ask an admin to check the action's agent and who can run it. If the agent's computer is offline, the work starts once it comes back online; see [Troubleshooting](/troubleshooting).
