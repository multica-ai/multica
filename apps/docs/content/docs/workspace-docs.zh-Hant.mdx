啟用文件功能後，工作區才會顯示文件入口。若要在自架環境中測試，請設定伺服器環境變數 `FF_DOCS_V1=true`。

在網頁版或桌面應用程式中，從工作區側欄進入**知識庫**。可在這裡保存團隊日後會查閱的資訊，例如到職清單和專案決策。

## 新增和分享文件

文件和資料夾以工作區為範圍。在私人專案中連結文件，或以私人專案的名稱命名資料夾，都不會將存取權限限制為該專案的成員。

1. 在知識庫側欄選擇**新增**，再選擇**新增文件**或**新增資料夾**。按一下資料夾旁的加號，可直接在該資料夾中新增文件。
2. 加入標題並開始撰寫。輸入 `/` 可以插入標題、待辦清單、表格等區塊。貼上或拖入圖片可將其加入工作區附件。
3. 等待顯示**已儲存**後再分享。可從頂部工具列複製連結，也可在任務、留言或聊天中輸入 `@` 和文件標題，插入文件連結。

將文件或資料夾拖曳到目的地，或在選單中選擇**移動到...**。空的資料夾可以刪除。刪除文件也會刪除其版本歷史。

工作區擁有者和管理員可以刪除任何文件或空資料夾。其他成員只能刪除自己或自己擁有的 AI 代理建立的項目。

使用工作區搜尋，可依文件標題或內文中的字詞查找文件。

## 找回草稿和歷史版本

如果其他人在你編輯時儲存了新版本，Multica 會保留你的草稿，並提示你**載入最新版本**。草稿會顯示在目前內容旁，可複製想保留的部分。

開啟**歷史**可預覽先前的版本。選擇**還原此版本**可將該內容設為目前版本。還原會新增版本，並保留已有的歷史記錄。連續編輯時的多次自動儲存可能合併為一筆歷史記錄。

## 讓 AI 代理處理文件

可請 AI 代理閱讀或更新已連結的文件，並說明要保留哪些內容。在 [CLI](/cli) 中，用 `multica doc search "<query>"` 尋找文件，再用 `multica doc get` 取得 Markdown 內容和修訂編號。更新時透過 `--base-revision` 將修訂編號傳給 `multica doc update`。如果期間有人儲存了變更，先讀取最新版本並合併你的變更，再重試。

用 `multica doc folder list` 查詢資料夾 ID，用 `multica doc folder create --title "<title>"` 新增資料夾。要在另一個資料夾下新增，請加上 `--parent <folder-id>`。用 `multica doc move <doc-id> --folder <folder-id>` 移動文件，或用 `--folder root` 將文件移到最上層。用 `multica doc folder --help` 查看資料夾重新命名和移動指令。
