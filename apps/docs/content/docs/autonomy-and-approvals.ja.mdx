判断のたびにあなたを待たせる必要はありません。**自律性（autonomy）** は、スクワッドがあなたに確認せずにどこまで行動してよいかを定めます。**常時承認（standing approval）** は、狭い範囲のプロポーザルを事前に承認します。承認は事前ではなく、事後にあなたが結果を確認します。

## 自律性レベル

各スクワッドは 0〜3 のレベルを持ちます。既定は 1 です。変更できるのはあなたか管理者だけで、変更はすべてガバナンスログに記録されます。レビューが変更を勧告することがあり、その場合はプロポーザルとして提出されます。

| レベル | 名前 | プラットフォームが許可する範囲 |
| --- | --- | --- |
| L0 | Suggest（提案） | スクワッドのルーティンは保留されます。誰かが割り当てるかメンションしたときにしか動きません。プロポーザルは引き続き提出できます。 |
| L1 | Work（作業） | ルーティンが実行されます。スクワッドは調査、分析、ナレッジの下書きの作成、プロポーザルの提出を行います。決定はすべてあなたが行います。 |
| L2 | Trusted（信頼） | L1 と同じ。ナレッジの下書きはレビュー後に公開できます。常時承認でプロポーザルを承認できます。 |
| L3 | Autonomous（自律） | L2 と同じ。常時承認は、上限と予算の範囲内で、スクワッド自身の機会から最初のステージのイニシアチブを作成することもできます。 |

レベルに関係なく決まっていることが二つあります。**公開** は常にあなたが決定します。**組織変更** も同様です。支出は常に[予算](/budgets)で制限されます。

<Callout type="warning">
自律性が制限するのは、プラットフォームの動作です。どのルーティンが実行されるか、共有の記録に何が公開されるか、どのプロポーザルがあなた抜きで決定されるか、どのイニシアチブが作られるか、どれだけ支出されるか、といったことです。実行の内部でエージェントが何をするかは制限しません。エージェントは、その認証情報が許す外部サービスを呼び出せます。認証情報の範囲は絞り、ワークスペースの外に影響を与えるものには外部のゲートを設けてください。
</Callout>

**ガバナンス** の Autonomy タブには、各スクワッドのレベルが表示され、変更もできます。スクワッドのパネルとオフィスには、レベルがタグとして表示されます。API は `GET` と `PUT /api/squads/{id}/autonomy` です。

## 常時承認

**ポリシー** は、あらかじめ承認しておいたプロポーザルの範囲を定めます。

- **種類（kind）**：プロポーザルの種類のいずれか（`decision`、`opportunity`、`goal`）。対象になり得ない種類は拒否されます。`org_change`、公開ゲート、`budget`、`stage_gate`、`standing_approval` 自体がこれにあたります。
- **一致条件（match）**：対象となるスクワッドやフロア、最大コスト、ペイロードが一致すべき項目。プロポーザルはラベルを持たないため、ラベルによる一致は拒否されます。
- **週あたりの上限**：1〜50。既定は3。
- 任意の **有効期限（valid until）** と、有効フラグ。

スクワッドがプロポーザルを提出すると、ポリシーエンジンは有効な各ポリシーを確認します。ポリシーが適用されるのは、提出したスクワッドがL2以上の場合だけです。機会によって最初のステージのイニシアチブを作る場合はL3が必要です。プロポーザルがポリシーに一致し、週あたりの上限に達しておらず、緊急ではない必要があります。推定コストがポリシーの最大額とスクワッドの残り予算に収まっている必要もあります。

一致すると、そのプロポーザルはポリシー自身の名義で承認されます。その承認は人による承認と同じように適用され、ガバナンスイベントとして記録されます。次のブリーフの **Auto-approved by policy**（ポリシーにより自動承認）に記載されます。ポリシーが自動承認したものが後のレビューで覆された場合、そのポリシーは週次レビューで指摘されます。

ポリシーを作成できるのはあなたか管理者だけです。エージェントは `standing_approval` プロポーザルとしてポリシーを提案できます。それをあなたが他のプロポーザルと同じように承認します。どのエージェントも、ポリシーや自律性レベルを編集できません。

ポリシーを取り消すには、Autonomy タブの **Policies**（ポリシー）から取り消します。取り消しは直ちに有効になり、記録されます。

```bash
curl -X POST "$MULTICA_API/api/approval-policies" -H "Authorization: Bearer $MULTICA_TOKEN" \
  -H "X-Workspace-ID: $WORKSPACE_ID" -H "Content-Type: application/json" \
  -d '{"name": "Pilot follow-ups", "kind": "decision", "match": {"squad_ids": ["<squad-id>"], "max_cost_micros": 5000000}, "max_per_week": 2}'
```

その他のポリシーの API は、`GET /api/approval-policies`、`POST /api/approval-policies/{id}/revoke`、`GET /api/approval-policies/{id}/auto-approvals` です。CLI にポリシーのコマンドはありません。

## ナレッジの公開と自律性

L2 未満のスクワッドのナレッジ下書きは、公開ポリシーの設定にかかわらず自動公開されません。[ナレッジの分類](/knowledge-taxonomy)を参照してください。
