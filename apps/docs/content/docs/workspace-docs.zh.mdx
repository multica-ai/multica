title: 工作区知识库
description: 集中保存团队笔记、决策和参考资料，并找回之前的版本。
---

在网页版或桌面应用中，从工作区侧栏进入**知识库**。可以把团队需要反复查阅的信息放在这里，例如入职清单和项目决策。

## 新建和分享文档

1. 在知识库侧栏选择**新建**，再选择**新建文档**或**新建文件夹**。点击文件夹旁的加号，可直接在该文件夹中新建文档。
2. 添加标题并开始写作。输入 `/` 可以插入标题、待办列表、表格等内容块。粘贴或拖入图片可将其添加为工作区附件。
3. 等待显示**已保存**后再分享。可以从顶部栏复制链接，也可以在任务、评论或聊天中输入 `@` 和文档标题，插入文档链接。

拖动文档或文件夹到目标位置，或者在菜单中选择**移动到...**。空文件夹可以删除。删除文档也会删除其版本历史。

## 找回草稿和历史版本

如果其他人在你编辑时保存了新版本，Multica 会保留你的草稿，并提示你**刷新最新版本**。旧草稿会显示在当前内容旁，可以复制需要保留的部分。

打开**历史**可预览之前的版本。选择**恢复此版本**可把该内容设为当前版本。恢复会生成一个新版本，并保留已有的历史记录。连续编辑时的多次自动保存可能合并为一条历史记录。

## 让智能体处理文档

可以请智能体阅读或更新已链接的文档，并说明需要保留哪些内容。在 [CLI](/cli) 中，用 `multica doc list` 查找文档，然后用 `multica doc get` 获取 Markdown 正文和修订号。更新时，用 `--base-revision` 将该修订号传给 `multica doc update`。如果期间有人保存了改动，先读取最新版本并合并你的改动，再重试。
