**スターター会社** は、デジタル会社のための既製の構成です。秘書、ライブラリアン、そして調査、製品、構築、公開、ガバナンスを担当するスクワッドがあります。作成するスクワッドを選ぶと、フロア、憲章、ルーティン、会社の予算も一緒に作成されます。

新しい、またはほぼ空のワークスペースで使ってください。既存のものを削除することはありません。もう一度実行しても、重複して作成されることはありません。

## ウィザード

オフィスを開き、会社ウィザードを起動します。四つのステップがあります。

1. **ランタイム。** 新しいエージェントが動作するランタイムです。オンラインのものを選んでください。
2. **選択。** 作成するスクワッドです。各カードには、スクワッドのミッションとルーティンが表示されます。
3. **見積もり。** 選んだルーティンのコストの見積もりです。
4. **開始オプション。** 次の三つから選びます。
   - `all`：すべてのルーティンが有効で開始されます。
   - `per_floor`：各フロアの主要ルーティンが有効で開始され、残りは一時停止です。
   - `leave_paused`：すべてのルーティンが一時停止で開始され、あなたが一つずつ開始します。

ウィザードは `POST /api/office/company-template/apply` を呼び出します。応答はレポートで、作成されたか見つかったフロア、スクワッド、エージェント、ルーティンが一覧されます。途中で止まった場合は、もう一度実行してください。レポートの続きから再開し、不足しているものだけを作成します。

## 作成されるもの

スクワッドはフロアごとにまとめられます。フロア名は英語で固定されているので、再実行時に見つけられます。

| フロア | スクワッド |
| --- | --- |
| Executive（経営） | **Executive Office**：秘書とライブラリアン。毎日のブリーフと毎週のレビューのルーティン、ライブラリアンのルーティンを含みます |
| Research（調査） | **Market Research**、**Opportunity Lab**、**Competitor Intelligence**、**Customer Voice** |
| Product（製品） | **Product Discovery**、**Product Analysis**、**Planning** |
| Build（構築） | **Build** |
| Launch（公開） | **Release & Ops**、**Growth & GTM**、**Support** |
| Governance（ガバナンス） | **Finance & Risk**、**People & Performance** |

各スクワッドには、ミッション、責任範囲、成果、境界を含む憲章と、カードにあるルーティンが付きます。スクワッドの指示は、カードの役割に合わせて書かれています。各エージェントは、自分の役割の指示と、すべてのスクワッドが従う共通の指示を受け取ります。

**People & Performance** スクワッドは、[レビュー](/reviews-and-org-changes)で使われるレビュアーのエージェントを持ちます。**Executive Office** スクワッドは、[ナレッジベース](/knowledge-taxonomy)を整理しておくライブラリアンを持ちます。

パイプラインのステージは、次のスクワッドが担当します。Validate は Product Discovery、Define は Product Analysis、Plan は Planning、Build と Learn は Build、Launch は Release & Ops、Operate は Support です。[パイプラインとイニシアチブ](/pipeline)を参照してください。

## 会社の予算

スターター会社は、会社全体を対象とする予算を一つ作成します。月額500ドルで、`warn`（警告のみ）モードです。80% で警告し、どの実行も保留しないので、気づかないうちに止まることはありません。スターター会社はフロアやスクワッドごとの配分を設定しません。必要な場合は、Budgets タブで作成してください。[予算](/budgets)を参照してください。

## 制限

- オンラインのランタイムが少なくとも一つ必要です。エージェントは、あなたが選んだランタイム上に作成されます。
- スターター会社はイニシアチブを作成しません。イニシアチブは、承認された機会とあなた自身の依頼から生まれます。

<Callout type="info">
各スクワッドは、自律性レベル1で始まります。後から Autonomy タブでレベルを上げられます。[自律性と承認](/autonomy-and-approvals)を参照してください。
</Callout>
