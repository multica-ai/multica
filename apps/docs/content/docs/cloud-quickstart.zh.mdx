<Callout type="info">
智能体执行前，运行它的电脑上需要有至少一款已安装并登录的[支持的 AI 编程工具](/providers)，例如 Claude Code、Codex 或 Cursor。Multica 不自带这些工具。
</Callout>

## 1. 登录，进入工作区

用 Web（[multica.ai](https://multica.ai)）或 [Multica Desktop](https://multica.ai/download) 登录，支持邮箱验证码和 Google。

- **Desktop**：可以自动连接这台电脑。
- **Web**：需要在下一步通过命令行连接。

## 2. 连接一台电脑

智能体在你连接的电脑上执行工作。打开侧边栏底部的 **配置 → 运行时**：

- **用 Desktop**：Desktop 会自动把这台电脑注册为运行时，并检测已安装的 AI 编程工具。刚安装的工具，点"刷新"重新检测。
- **用 Web，或需要添加另一台电脑**：点右上角的 **添加电脑**，在目标电脑的终端里运行弹窗给出的两条命令：

 **macOS / Linux**

 ```bash
 curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
 multica setup
 ```

 **Windows PowerShell**

 ```powershell
 irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
 multica setup
 ```

 `multica setup` 会打开浏览器完成登录，然后让守护进程在后台运行。守护进程上线后，弹窗通常在一分钟内自动检测到这台电脑。

**成功标志**：运行时列表里出现一台在线的电脑。

![Add a computer 弹窗：两条命令与等待检测提示](/images/docs/quickstart-add-computer.webp)

<Callout type="info">
自托管实例的连接命令略有不同，见[自托管快速上手](/self-host-quickstart)。
</Callout>

## 3. 创建一个智能体

打开侧边栏的 **工作区 → 智能体**，点 **新建智能体**，选择一条路径：

- **从空白开始**：自己填字段。最少只需要名称，再确认运行时和 AI 编程工具即可创建。
- **通过 AI 创建**：描述你想要什么，由 Agent Builder 提问并生成配置。这条路径需要一个在线运行时。

其余配置可以之后完善，详见[创建和配置智能体](/agents-create)。

**成功标志**：智能体列表中出现你的智能体，并显示为在线。

![创建智能体的起点选择页：Start blank 与 Build with AI](/images/docs/quickstart-new-agent.webp)

## 4. 把第一个任务交给它

点侧边栏顶部的 **新建任务**（或按快捷键 `C`）。在默认的智能体模式下：

1. 在 **创建者** 中选择刚创建的智能体；
2. 用一两句话描述要做的事，例如"介绍一下这个工作区可以怎么用"；
3. 提交。Multica 会创建任务、把智能体设为负责人并立即开始执行。

![新建任务弹窗的智能体模式：Created by 已选中 Multica Assistant](/images/docs/quickstart-new-issue.webp)

## 5. 查看进度和结果

提交后打开这条任务：执行日志显示运行状态，智能体的进展和回复出现在时间线中。

**成功标志**：执行日志状态变为"已完成"，时间线中出现智能体的回复。需要查看完整过程时，点"查看记录"。

![任务中智能体的回复与已完成的执行日志](/images/docs/quickstart-run-result.webp)

## 常见问题

| 现象 | 先检查什么 |
|---|---|
| 没有找到运行时 | 确认 AI 编程工具已经安装并能在终端中运行。Desktop 点"刷新"；CLI 方式重新运行 `multica setup`。 |
| 运行时显示离线 | Desktop 保持打开；CLI 方式运行 `multica daemon status`，未启动时运行 `multica daemon start`。 |
| 任务一直排队 | 确认智能体使用的运行时在线。运行时达到并发上限时，新 task 会继续排队。 |

更多情况见[故障排查](/troubleshooting)。
