**設定 → 外觀** 決定 Multica 在當前裝置上的樣子：模式、主題、文字和版面。所有改動立即生效。

<Callout type="info">
  主題和主題商店目前是 Beta。Multica 發版後，一個原本正常的主題可能需要作者更新。
</Callout>

## 模式與主題

**模式** 可選淺色、深色或跟隨系統。也可以在搜尋框（`⌘K`）裡輸入"主題"切換。

**主題** 決定全域性的顏色、邊框、陰影和圓角。Multica 自帶 Default、Pop、GitHub、Blueprint 和 Notion；在下拉框裡直接選，或者點 **管理** 帶預覽檢視所有主題。一個主題可能支援淺色、深色或兩者都支援，並跟隨你選的模式。

有些主題帶選項，比如強調色或頁面寬度。使用這個主題時，選項會出現在 **主題選項** 裡；**恢復主題預設** 把選項恢復成主題的預設值。

頁面上的其他設定與主題無關：

| 分組 | 設定什麼 |
|---|---|
| **介面文字** | 選單、按鈕、列表、側邊欄和標題的字型與字號。 |
| **內容文字** | 任務描述、評論、聊天和文件的字型、字號和行高，以及程式碼字型。 |
| **版面與輔助功能** | 資訊密度、減少動態效果、提高對比。 |

選了非預設的字型，或者開啟了提高對比時，以你的選擇為準，而不是主題的。顏色由主題決定；想要主題沒有提供選項的顏色，換一個主題，或者[自己做一個](/developers/themes)。

## 主題商店

**管理** 開啟一個視窗，列出所有主題：內建主題、當前裝置上的主題和社群主題商店。可以按名稱或作者搜尋，開啟 **只看已安裝** 隱藏沒裝的主題。

商店裡每個主題是一張卡片：截圖（在角落切換淺色和深色截圖）、作者、描述、下載次數，以及它的 GitHub 倉庫連結。沒裝的主題按下載次數從多到少排列。

<Steps>
<Step>

### 安裝

點卡片上的 **安裝**。主題會被下載、檢查、儲存到當前裝置，並立即使用。

</Step>
<Step>

### 切換

在任意已安裝或內建的主題上點 **使用**。正在用的主題標著 **使用中**。

</Step>
<Step>

### 移除

在已安裝的主題上點 **移除**。如果它正在使用，Multica 會回到 Default。

</Step>
</Steps>

商店主題由社群製作，上架前會經過自動檢查：不能執行程式碼，不能從網路載入任何東西，也不能使用主題以外的檔案。但主題仍然可以改變每個頁面的樣式，包括彈窗和警告。

下載次數包含每一次安裝和每一次更新，統計的是使用同一個 Multica 伺服器的所有人。

## 更新

裝過商店主題後，外觀頁會出現 **商店主題** 一行。點 **檢查更新** 查詢新版本，然後點 **全部更新**；也可以在卡片上用 **更新至 …** 單獨更新一個主題。更新會保留主題的選項值，也不會改變你當前在用的主題。

主題不會在你不知情的情況下自動更新。

## 匯入主題

別人發給你的主題檔案，或者你自己做的主題，從 **製作自己的主題 → 匯入主題** 安裝：

- **主題檔案（.zip）** 安裝壓縮包形式的主題。
- **主題資料夾** 安裝解壓後的主題。

安裝前，Multica 會顯示主題的名稱、作者和版本。只安裝你信任的人做的主題。匯入一個與已安裝主題 id 相同的主題，會替換它。

想從頭做一個主題，見[製作主題](/developers/themes)。

## 主題出問題時

主題可能隱藏或弄亂介面的一部分。回到 Default 有兩種方法：

- 在地址末尾加上 `?theme=default` 開啟 Multica；
- 頁面載入完後立刻按住 **Shift** 一會兒。桌面端先用 `⌘R`（Windows 和 Linux 上是 `Ctrl+R`）重新載入，再按住 **Shift**。

關閉視窗前，主題會一直暫停。外觀頁會顯示一條提示，點 **恢復我的主題** 重新啟用；你也可以在那裡換一個主題，或者移除出問題的主題。

## 儲存在哪裡

模式、主題、主題選項和已安裝的主題都儲存在當前裝置上，不會同步到賬號。每個瀏覽器、每個桌面端各有一份，同一裝置上的所有工作區共用。

## 自託管

自託管的伺服器預設讀取官方倉庫 [multica-ai/multica-themes](https://github.com/multica-ai/multica-themes)。伺服器從 GitHub 拉取主題和截圖並快取，應用從你的伺服器下載。下載次數按伺服器分別統計。

| 變數 | 作用 |
|---|---|
| `MULTICA_THEME_STORE` | 設為 `off` 關閉主題商店。之後 **管理** 只列出各裝置上已有的主題，伺服器也不再請求倉庫。 |
| `MULTICA_THEME_REGISTRY_URL` | 讓主題商店改讀另一個倉庫的 `index.json`，比如官方倉庫的 fork。 |

伺服器的其他設定見[環境變數](/environment-variables)。
