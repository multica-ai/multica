---
title: 워크플로
description: 프로젝트 태스크가 거칠 단계와 각 단계를 이어받을 담당자를 정합니다.
---

워크플로는 프로젝트의 일을 같은 절차로 진행하게 해 줍니다. 태스크가 거칠 단계, 각 단계의 담당자, 해야 할 일을 정할 수 있습니다.

예를 들어 개발 작업을 다음과 같이 구성할 수 있습니다.

| 단계 | 담당 | 할 일 |
|---|---|---|
| 개발 | 개발 에이전트 | 변경을 구현하고 리뷰를 준비합니다. |
| 리뷰 | 리뷰 에이전트 | 결과를 확인한 뒤 QA로 넘기거나 수정을 위해 돌려보냅니다. |
| QA | 팀 멤버 | 결과를 직접 사용해 보고 완료해도 될지 판단합니다. |

태스크를 리뷰 단계로 옮기면 리뷰 에이전트가 이어받습니다. 설명, 논의, 이전 결과는 같은 태스크에 남아 다음 담당자가 이어서 일할 수 있습니다.

이는 **개발 딜리버리** 템플릿과 같은 구성입니다. 워크플로를 선택하지 않은 프로젝트는 **Default**를 사용합니다. 모든 상태를 쓸 수 있고 자동 인계도 없어 이전과 똑같이 동작합니다.

## 워크플로 만들기

워크스페이스의 `owner` 또는 `admin`이 웹이나 데스크톱 앱에서 만들 수 있습니다.

1. **설정 → 워크플로**에서 **새 워크플로**를 선택합니다. 빈 상태로 시작하거나 **개발 딜리버리**, **콘텐츠 제작**, **커뮤니티 운영** 템플릿을 사용할 수 있습니다.
2. 이름을 정하고 필요한 상태 열을 선택합니다. 가운데 열은 드래그해 순서를 바꿉니다.
3. 열을 선택하고 태스크가 들어올 때 인계하지 않을지, 에이전트 또는 멤버에게 넘길지 정합니다. 멤버 목록에서 프로젝트 리드도 선택할 수 있습니다.
4. 에이전트 단계에서는 할 일을 적고, 완료 후 이동할 단계(지정하지 않으면 다음 열)와 수정이 필요할 때 되돌릴 단계를 선택합니다.
5. 에이전트가 받을 설명을 미리 보고 저장합니다.

새 상태를 추가했다면 워크플로를 먼저 저장한 뒤 그 상태의 인계를 설정합니다.

인계하지 않으면 담당자는 그대로입니다. 멤버에게 인계하면 담당자만 바뀌며 에이전트가 실행되지는 않습니다. 에이전트에게 넘기면 해당 단계를 시작하도록 요청합니다. 호출 권한이 있어야 하며, 실제 실행에는 에이전트의 컴퓨터가 온라인이어야 합니다.

## 프로젝트에서 사용하기

프로젝트를 열고 **워크플로** 속성에서 선택합니다. 워크스페이스의 `owner`, `admin`, 그리고 멤버인 프로젝트 리드가 변경할 수 있습니다.

확인 창에 현재 상태를 유지하는 태스크가 표시됩니다. 새 워크플로에 없는 상태를 사용하는 태스크는 이동할 곳을 선택합니다. 워크플로를 바꾸는 것만으로는 담당자 인계나 에이전트 실행이 일어나지 않습니다.

프로젝트 보드는 워크플로의 열을 따릅니다. 태스크의 상태 목록도 해당 단계만 제공하며, 누가 이어받는지 보여 줍니다. 다른 워크플로를 선택하지 않은 프로젝트는 **Default**를 사용하며, 나중에 다시 돌아갈 수 있습니다.

## 다음 단계로 넘기기

태스크의 상태를 바꾸거나 카드를 다른 열로 드래그합니다. 인계가 있는 단계라면 받을 사람을 확인합니다. 에이전트라면 받을 설명도 확인할 수 있습니다.

프로젝트에서 담당자를 고르지 않고 태스크를 만들었는데 그 상태에 인계가 설정되어 있으면, 태스크는 해당 단계의 담당자에게 바로 넘어갑니다. 에이전트라면 즉시 작업을 시작합니다. 생성 창에 누구에게 인계되는지 표시됩니다. 아직 아무것도 시작하지 않으려면 Backlog에 만드세요.

이전 에이전트가 아직 실행 중이거나 시작을 기다리고 있다면 확인 창에서 중지하거나 취소할 수 있습니다. 기본으로 선택되어 있으므로 둘 다 계속 작업하기를 원하는 경우가 아니면 그대로 둡니다. 이미 게시한 댓글과 저장한 작업은 유지됩니다.

완료 후 이동할 단계와 수정 시 돌아갈 단계는 에이전트에게 전달되는 지침입니다. 실행이 끝났다고 태스크가 저절로 다음 단계로 넘어가지는 않습니다. 해당 단계의 멤버나 에이전트가 상태를 바꿉니다.

인계 내역과 설명은 태스크 타임라인에 남습니다. 프로젝트 보드의 워크플로 메뉴에서 전체 흐름을 볼 수 있습니다.

## 워크플로 조정하기

여러 프로젝트가 같은 워크플로를 사용할 수 있습니다. **설정 → 워크플로**에서 저장한 변경은 사용하는 모든 프로젝트에 적용됩니다. 한 프로젝트만 바꾸려면 워크플로를 복제하고 해당 프로젝트에서 사본을 선택합니다.

관리자는 프로젝트 보드에서 바로 인계를 설정할 수도 있습니다. 열 머리글에 마우스를 올리고 **넘기기…**를 클릭하거나, 이미 표시된 담당자를 클릭합니다. 다른 프로젝트와 공유하는 워크플로라면 **이 변경을 어디에 적용할까요?**라고 묻습니다. 현재 프로젝트에만 적용하면 그 프로젝트용으로 워크플로가 복제되고 다른 프로젝트는 바뀌지 않습니다.

열을 제거할 때 태스크가 남아 있다면 새 상태를 선택합니다. 나머지 태스크는 그대로이며 이 이동으로 에이전트가 시작되지는 않습니다. 워크플로 목록 아래 상태 라이브러리에서 이름과 색을 바꾸면 같은 상태를 쓰는 모든 곳에 반영됩니다.

워크플로를 삭제하려면 먼저 사용 중인 프로젝트를 다른 워크플로로 전환하세요. 태스크는 현재 상태를 유지합니다.

**설정**에 **워크플로**가 없다면 이 워크스페이스에서는 아직 사용할 수 없습니다. 상태는 계속 **설정 → 태스크 상태**에서 관리합니다.
