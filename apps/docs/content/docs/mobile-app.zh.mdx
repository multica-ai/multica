Multica iOS 客户端目前还没有上架 App Store。你可以在 Mac 上从公开的源码仓库构建 Release 版本，再安装到自己的 iPhone。Android 复用同一 React Native 客户端，可构建已签名、独立运行的 APK。

安装后的 App 默认连接 Multica Cloud，用已有账号登录即可。工作区、任务、评论和执行记录都保存在服务端，不需要从 Web 或 Desktop 同步。

工作区和项目的任务列表会加载全部分页，并按相同的状态顺序分组。点击状态标题可折叠或展开，完整数量始终保留。有子任务时，任务详情会在动态记录上方列出各子任务的标识、标题和状态，点击即可进入。

## Android APK

准备 JDK 17 和 Android SDK 36，配置仓库外的 Release 签名密钥，再从仓库根目录运行：

```bash
pnpm -C apps/mobile android:release
```

APK 默认连接 Multica Cloud，无需 Metro。签名、环境变体、自托管地址和安装验证见 [Android 构建指南](https://github.com/multica-ai/multica/blob/main/apps/mobile/docs/android-release.md)。首版不包含后台推送。下文为 iPhone 安装说明。

## 准备工作

你需要：

- 一台安装了 Xcode 的 Mac；
- 已在 **Xcode → Settings → Accounts** 中登录的 Apple ID；
- 一台通过 USB 连接的 iPhone；
- 在 iPhone 的**设置 → 隐私与安全性**中打开开发者模式；
- Node.js、pnpm 和 Git。

Xcode 或真机开发环境未配置时，先完成 Expo 的 [iOS Device 环境配置](https://docs.expo.dev/get-started/set-up-your-environment/)。

## 安装到 iPhone

<Steps>
<Step>
克隆仓库并安装依赖：

```bash
git clone https://github.com/multica-ai/multica.git
cd multica
pnpm install
```
</Step>
<Step>
从仓库根目录运行：

```bash
pnpm ios:mobile:device:prod:release
```

这会构建一个不依赖 Metro 的 Release 版本，并安装到已连接的 iPhone。第一次构建需要下载 iOS 依赖并编译 React Native，之后会复用 Xcode 缓存。
</Step>
<Step>
在 iPhone 上打开 App。如果系统阻止打开，到**设置 → 通用 → VPN 与设备管理**中信任对应的开发者证书。
</Step>
</Steps>

## 免费签名的 7 天限制

免费 Apple ID 签名的 App 只能使用 7 天。到期后，把 iPhone 重新连接到 Mac，并再次运行同一条构建命令即可续签。

Apple Developer Program 账号签名的有效期更长，也可以用于 TestFlight 和正式分发。无论使用哪种签名，服务端数据都不会因为重新安装或续签而丢失。

## 签名失败

如果 Xcode 提示 `No matching provisioning profiles found`，默认 bundle identifier 可能不属于你的 Apple ID。换成自己控制的反向域名后重新构建：

```bash
export EXPO_BUNDLE_IDENTIFIER_PROD=com.yourname.multica
pnpm ios:mobile:device:prod:release
```

这个值只需要在你的 Apple Developer team 中可用，不影响 Multica 账号或工作区。

## 更新

iOS 自助安装版不会自动更新。拉取最新代码、更新依赖并重新构建：

```bash
git pull --ff-only
pnpm install
pnpm ios:mobile:device:prod:release
```

## 连接自托管实例

在登录页打开**服务器设置**，或登录后进入**设置 → 服务器设置**。填写 **API 地址**（后端根地址）和**网页地址**（浏览器与链接使用的地址），然后保存。两个地址可同域，也可使用不同域名。重启 App 后仍会保留，无需重新打包。点击**恢复 Cloud 默认地址**后保存，即可回到 Multica Cloud。

两个地址都需要 HTTPS，且证书须受设备信任。支持自定义端口和基础路径，例如 API `https://multica.example.com:8443/backend`、网页 `https://multica.example.com:8443/app`。API 地址末尾的 `/api` 会移除，由接口路径自动添加；`/auth` 和 `/ws` 使用同一个后端根地址。交付的 APK 不支持 HTTP，也不会绕过证书验证。设备须能访问所填地址；`localhost` 指手机本身。

修改任一地址会退出登录，清除本地草稿、工作区选择和缓存。请在所选实例上重新登录。服务器上的数据仍保留在原实例。文件与图片会向所选实例获取新鲜的签名地址，不会把登录 token 交给外部浏览器。

开发构建和首次安装默认值见仓库中的 [`apps/mobile/README.md`](https://github.com/multica-ai/multica/blob/main/apps/mobile/README.md)。
