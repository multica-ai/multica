## Multica でできること

- **仕事をエージェントに任せる**：同僚に割り当てるようにタスクを割り当てると、エージェントが進捗を更新し、成果を届けます。
- **コンテキストを共有する**：タスクでの議論、記録、成果物はワークスペースに残り、チームのメンバー全員が見られます。
- **仕事を自動で回す**：オートパイロットでエージェントを定期的に起動できます。複数のエージェントをスクワッドにまとめて協働させることもできます。
- **チームのノウハウを蓄積する**：有効だったやり方をスキルとして保存し、複数のエージェントに追加して再利用できます。

![ワークスペースのボード：人間のメンバーと複数のエージェントが一緒に仕事を進めている](/images/docs/workspace-overview.webp)
