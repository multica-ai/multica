对话适合还没有形成明确任务的工作：梳理想法、查询工作区情况、讨论方案、问一个不属于任何任务的问题，或者先让智能体完成一个小任务。

对话（Chat）是你和[智能体](/agents)的一对一沟通，不在[任务](/issues)看板上。整段对话**完全私人**，[工作区](/workspaces)里的其他人，包括 admin，都看不到。

对话**不绑定任务**。智能体不盯着你的看板，不会自动收到任务的描述和评论，也不会自己把对话变成任务。它仍可以在权限范围内用 Multica CLI 查询工作区、项目、任务和 skill；你明确要求时，它会以你的工作区权限代你操作，例如建一个任务。

对话也可以携带背景。点击输入框左下角的 **+**，选择**项目上下文**，为对话挂上一个[项目](/projects)；智能体执行时会收到该项目的描述和仓库等资源。

## 开始对话

<Steps>
<Step>

打开侧边栏中的**聊天**。

</Step>
<Step>

点击新建，选择一个你有权运行的智能体。

</Step>
<Step>

输入消息，也可以附加图片或文件。

</Step>
<Step>

发送后，Multica 会为这条消息创建一次执行，回复回到当前对话。

</Step>
</Steps>

运行时离线时，消息会等待它重新上线。智能体被归档，或者你失去调用权限后，不能继续发送新消息。

第一条消息发送前，对话页会显示所选智能体配置的最多三个建议。选择一条只会把完整提示词填进输入框，不会发送，你可以先改再发。没有配置建议的智能体显示通用示例。

智能体回复后，下方有时会给出**后续提问**。后续提问点击后直接发送。

## 在任意页面打开悬浮聊天窗

不用离开当前页面也能聊天。工作区页面的右下角有一个圆形聊天按钮，悬停时提示"问 Multica"，点开是一个悬浮聊天窗。窗里的对话和**聊天**页是同一份，在哪边开始的对话，另一边都能接着聊。

- 按 `⌘J`（Windows / Linux 上是 `Ctrl+J`）打开或收起悬浮窗，打开后光标直接落在输入框里。光标在输入框里时也能用这个键收起。按键可以在**设置 → 快捷键**里改，见[搜索、快捷键与偏好设置](/shortcuts)。
- 悬浮窗可以拖动边缘调整大小，也可以展开或最小化。智能体正在回复时，收起后的按钮会轻轻跳动。
- **聊天**页本身不显示这个按钮，`⌘J` 在这里也不起作用：整页显示的已经是同一段对话。

不需要悬浮窗时，在**设置 → 偏好设置 → 评论与聊天**里关闭**悬浮聊天窗**，之后只能从侧边栏进入聊天。这个开关只对当前设备生效。

## 对话与任务的选择

| 需要 | 更适合 |
|---|---|
| 快速提问、探索方案或处理私人草稿 | **对话** |
| 明确负责人、状态、优先级和交付结果 | **任务** |
| 让团队成员查看背景并继续讨论 | **任务** |
| 临时查看工作区信息，不需要建立工作记录 | **对话** |

在 Multica 中创建的直接对话只有创建者能读取，其他成员和管理员都不能。需要团队一起看的结论，整理到任务、项目说明或 skill 中。

## 多轮上下文

同一段对话会尽量继续 AI 编程工具中的原会话，因此后续消息不需要重复前面的内容。Multica 会保存会话标识，并把后续执行路由到能够访问该会话的运行时。

如果本地会话已经不存在、上下文无法继续，或者上一次错误不适合复用，运行时会从新会话开始。对话中的历史消息仍然保留。

## 查看和停止执行

智能体运行时，界面会显示当前阶段和工具活动。展开**查看详情**可以检查更完整的执行过程。

需要中断时，点击输入框旁的停止按钮（输入框为空时显示）。已经返回到对话中的内容会保留。

如果智能体还没输出任何内容就被停下，你刚发的那条消息会从对话里撤回，连同附件放回输入框，改一改就能重发。停止有时要过一会儿才真正完成；这期间刷新页面或关掉窗口也不会丢，下次打开这段对话时，消息会回到输入框。输入框里已经有别的草稿时，会等你清空后再放回。

## 回复还没结束时继续发消息

智能体还在回复时，可以接着输入下一条。输入框有内容时，发送按钮变成**排队发送**。排队的消息不会打断当前回复，而是显示在输入框上方的队列里，等当前回复结束后按顺序处理。

| 操作 | 结果 |
|---|---|
| **引导** | 把这条消息提到队首，并停止当前回复。已经写出的内容留在对话里，智能体紧接着处理这条消息。 |
| 删除（垃圾桶图标） | 从队列里移除这条消息，它不会发给智能体。 |
| **⋯ → 编辑排队消息** | 把消息连同附件放回输入框，改完重新发送。 |
| **⋯ → 全部清空** | 撤回队列里的所有消息，当前回复照常进行。 |

当前回复还没真正开始（例如还在等运行时领取）时，**引导**按钮不可用；失去这名智能体的运行权限后也不能引导。

## 整理对话列表

对话支持重命名、置顶、归档和删除：

- **置顶**把常用对话固定在列表前面；
- **归档**把对话移到"已归档"并设为只读；
- **取消归档**后可以继续发送消息；
- **删除**会永久移除对话及其中的消息。

如果对话绑定了外部渠道（如 Slack），归档时绑定会断开，取消归档不会恢复，需要重新绑定。

<Callout type="warning">
删除对话无法撤销，并会停止其中尚未结束的执行。暂时不需要时用归档。
</Callout>
