description: 목적에 맞게 작업 시작, 인계, 도움 요청 방법을 선택합니다.
---

에이전트가 무엇을 하면 좋을지부터 정하세요. 태스크를 맡기거나, 한 번의 요청을 하거나, 반복 작업을 설정할 수 있습니다.

| 하고 싶은 일 | 사용할 기능 |
|---|---|
| 에이전트에게 태스크 맡기기 | 에이전트나 스쿼드에 [할당](/assigning-issues)합니다. |
| 담당자를 바꾸지 않고 도움 요청하기 | 댓글에서 [@멘션](/mentioning-agents)하거나 에이전트 댓글에 답글을 답니다. |
| 같은 종류의 요청 반복하기 | 코드 리뷰 등을 [퀵 액션](/quick-actions)으로 저장해 사용합니다. |
| 정해진 단계마다 다른 담당자에게 넘기기 | 프로젝트 [워크플로](/workflows)에서 각 단계의 담당자를 정합니다. |
| 태스크를 만들지 않고 질문하기 | 에이전트와 [채팅](/chat)을 시작합니다. |
| 일정이나 외부 이벤트에 따라 반복 작업 시작하기 | [자동화](/autopilots)를 만듭니다. |

호출 권한이 있는 에이전트만 실행할 수 있습니다. 댓글을 보내기 전에 입력창 아래 미리 보기를 확인하세요. 에이전트를 깨우지 않고 메모만 남기려면 `/note`를 사용합니다. `backlog` 상태의 태스크는 시작할 준비가 될 때까지 기다립니다.

## 진행 상황 확인하기

작업을 요청한 태스크나 채팅에서 답변을 확인하세요. [실행 로그](/tasks)에서는 진행 상황을 보고 중지하거나 재시도할 수 있습니다. 시작되지 않았다면 에이전트의 컴퓨터가 온라인인지 확인하세요. 다음 단계는 [문제 해결](/troubleshooting)을 참고하세요.
