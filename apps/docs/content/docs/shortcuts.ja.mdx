## 検索

`⌘K` を押すか、サイドバー上部の**検索...**をクリックすると検索ボックスが開きます。何も入力していないときは、**新規タスク**と最近開いたタスクが表示されます。キーワードを入力すると、結果がグループごとに表示されます。

| グループ | 見つかるもの |
|---|---|
| **ページ** | インボックス、チャット、タスク、プロジェクト、エージェント、設定などのワークスペースのページ。 |
| **コマンド** | 新規タスク、新規プロジェクト、ライト・ダーク・システムテーマへの切り替え。タスクの詳細を開いているときは、タスクのリンクをコピー、識別子をコピー、すべてのコメントを折りたたむ、すべてのコメントを展開も使えます。 |
| **メンバー** | 名前またはメールアドレスで探します。 |
| **ワークスペース** | 参加しているほかのワークスペース。選ぶとそこへ切り替わります。 |
| **プロジェクト**、**タスク** | タイトルのほか、プロジェクトの説明、タスクの説明、コメントにも一致します。一致した箇所が結果の下に表示され、完了したタスクも含まれます。 |
| **キャンセル済み** | キャンセルされたプロジェクトとタスクは、ほかの結果に混ざらず最後にまとめて表示されます。 |

結果を選ぶとそのページへ移動します。`⌘`（Windows / Linux では `Ctrl`）を押しながらクリックするか Enter を押すと、新しいタブで開きます。`Esc` で検索ボックスを閉じます。

## キーボードショートカット

| 操作 | macOS | Windows / Linux | 補足 |
|---|---|---|---|
| 検索を開く | `⌘K` | `Ctrl+K` | |
| タスクを作成 | `C` | `C` | 普段使う作成方法が開きます。プロジェクトのページで押すと、そのプロジェクトがあらかじめ入ります。 |
| 左サイドバーを切り替え | `⌘B` | `Ctrl+B` | |
| 右サイドバーを切り替え | `⌘/` | `Ctrl+/` | タスクの詳細など、右サイドバーのあるページでのみ使えます。 |
| チャットウィンドウを切り替え | `⌘J` | `Ctrl+J` | 開くとカーソルが入力欄に入ります。[どのページからでもチャットする](/chat#どのページからでもチャットする)を参照。 |
| タスク内を検索 | `⌘F` | `Ctrl+F` | 後述。 |
| 通知をアーカイブ | `E` | `E` | インボックスで開いている通知をアーカイブします。アーカイブ表示中はアーカイブを解除します。 |
| 送信 | `⌘↵` | `Ctrl+Enter` | コメントやチャットのメッセージを送信します。新しいタスクの作成にも使います。 |
| 戻る | `⌘[` | `Ctrl+[` | |
| 進む | `⌘]` | `Ctrl+]` | |

1 キーだけのショートカット（`C`、`E`）と「戻る」「進む」は、入力欄で文字を打っている間は反応しません。

**ナビゲーション**には、インボックス、チャット、自分のタスク、タスク、プロジェクト、自動化、エージェント、Squads、使用量、ランタイム、Skills、設定へ移動する操作もあります。どれも既定ではキーが割り当てられていないので、よく使うものに設定してください。

### 固定のシステムショートカット

以下は変更できません。`Esc` 以外は[デスクトップアプリ](/desktop-app)でのみ有効で、ブラウザではブラウザ側の動作になります。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 設定を開く | `⌘,` | `Ctrl+,` |
| アクティブなタブを閉じる | `⌘W` | `Ctrl+W` |
| 1〜8番目のタブを選択 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 最後のタブを選択 | `⌘9` | `Ctrl+9` |
| 拡大 / 縮小 / ズームをリセット | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| ダイアログまたはメニューを閉じる | `Esc` | `Esc` |

## ショートカットを変更する

<Steps>
<Step>

**設定 → ショートカット**を開きます。操作が多いときは、上部の検索欄で名前から探せます。

</Step>
<Step>

操作の右側にあるキーをクリックし、「キーを入力」と表示されたら新しい組み合わせを押します。`Esc` でキャンセル、`Delete` でその操作のキーを消去します。

</Step>
<Step>

各行の右端にある 2 つのボタンで、その操作をデフォルトに戻したり無効にしたりできます。上部の**デフォルトに戻す**は、すべてのカスタマイズをまとめて取り消します。

</Step>
</Steps>

ショートカットは今使っているデバイスにだけ保存されます。別のパソコンを使うときや、ブラウザとデスクトップアプリを行き来するときは、設定し直してください。

次のような組み合わせは登録できず、キーの下に理由が表示されます。

- すでにほかの操作に割り当てられている組み合わせ。
- ブラウザ、デスクトップウィンドウ、OS が使う組み合わせ。たとえば `⌘W`、`⌘R`、`⌘Q`、`⌘,`、コピー・貼り付けなどの編集キー、`⌘0`–`⌘9`、ズームのキーです。ブラウザでは `⌘P`、`⌘L`、`⌘T`、`⌘N`、`⌘D`、`⌘U` も使えませんが、デスクトップアプリでは使えます。Windows と Linux では、Win / Super キーを含む組み合わせはすべて使えません。
- 検索を開く、チャットウィンドウを切り替え、タスク内を検索のように入力欄でも働く操作には、`⌘`、`Ctrl`、`Control` のいずれかが必要です。文字入力中に誤って発動しないためです。
- **送信**に使えるのは `↵` か `⌘↵` だけです。

<Callout>
**送信**を `↵` にした場合、改行は `Shift+Enter` で入れます。段落の挿入、リストの継続、コードブロック内の改行ができます。
</Callout>

## タスク内を検索

タスクの詳細ページで `⌘F` を押すと、ブラウザの検索ではなく Multica の検索バーが開きます。ブラウザの検索は画面に描画済みのコメントしか見つけられませんが、こちらはタイトル、説明、すべてのコメントを含むタイムライン全体を検索します。

大文字と小文字は区別しません。検索バーには「現在の位置/総数」、見つからないときは「一致なし」と表示されます。`↵` で次の一致へ、`Shift+Enter` で前の一致へ移動し、`Esc` で閉じます。途中で書式が変わる文字列（半分だけ太字など）は見つかりません。

デスクトップアプリでは、表示中のタブだけが `⌘F` に反応します。

## 環境設定

個人の設定は**設定 → 環境設定**にあり、変更はすぐに反映されます。グループによって保存先が異なります。

| グループ | 設定 | 保存先 |
|---|---|---|
| **言語と地域** | 言語：English、中文、한국어、日本語、Français。変更するとページが再読み込みされます。<br />タイムゾーン：既定ではブラウザに従います。すべてのワークスペースの日付とグラフに使われ、全タイムゾーンから検索して選べます。 | アカウント（ほかのデバイスにも同期） |
| **外観** | テーマ：ライト、ダーク、システム。検索ボックスで「テーマ」と入力して切り替えることもできます。 | このデバイス |
| **コメントとチャット** | **コメント欄を下部に固定**：長いタイムラインを読んでいる間もコメント欄が見えたままになります。<br />**実行中のエージェントに返信するとき**：既定を「現在の実行に追加」と「この実行の後に開始」のどちらにするか。送信前にメッセージごとに変更できます。[実行中のエージェントに割り込む](/mentioning-agents#実行中のエージェントに割り込む)を参照。<br />**フローティングチャット**：オフにすると、右下のチャットボタンが表示されなくなります。 | このデバイス |
| **タスクを開く** | カードや行をクリックしたときに、ページ全体とサイドプレビューのどちらで開くか。Shift+クリックでもう一方で開きます。 | このデバイス |
| **タスク作成時に表示するフィールド** | 「エージェントで作成」と「手動作成」それぞれのツールバーに常に表示するフィールド。非表示のフィールドも ⋯ メニューから使え、値がある間は自動的に表示されます。 | このデバイスの現在のワークスペース |
