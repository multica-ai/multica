---
title: 微信 Bot
description: 扫码通过 iLink 将微信账号连接到 Multica 智能体。
---

Multica 参考腾讯 [OpenClaw Weixin 插件](https://github.com/Tencent/openclaw-weixin) 的协议，直接连接微信 iLink Bot 服务。这与企业微信通道独立，不需要安装 OpenClaw，也不通过桌面微信自动化收发消息。

## 连接

1. 以工作区所有者或管理员身份登录，打开智能体的「设置 → 集成」，选择「连接微信」。
2. 用**你自己的微信账号**扫码，并在手机上确认。微信要求验证码时，在弹窗中输入手机显示的数字。
3. 在微信中向机器人发送一条新私聊消息。智能体需要在线的运行环境才能执行任务。

扫码的微信账号会绑定到发起连接的 Multica 用户，消息按该用户的工作区权限执行。请勿分享二维码或让他人代扫。其他微信账号和群聊消息不会被接收。

登录窗口最长保留五分钟，微信也可能提前让二维码失效。过期后重新生成即可。关闭弹窗会取消待确认的登录。已连接到其他智能体或工作区的机器人必须先断开原连接。账号是否可用由微信决定，微信可能要求验证或拒绝连接。

## 消息与命令

- 文字消息会继续同一个 Multica 聊天，最终回复以纯文本返回微信。长回复按完整 Unicode 字符分段，不提供流式编辑。
- `/new [消息]` 新建聊天；`/clear [消息]` 重置当前聊天的智能体上下文；`/issue <标题>` 创建任务并分配给此智能体。
- 配置对象存储后，图片、文件、视频和未转写的语音会作为附件进入聊天。微信提供的语音转写作为文字处理；Multica 不额外提供语音识别，也不转换 SILK 音频。
- 智能体最终回复中的附件会发送回微信。支持的图片和 MP4 视频使用原生媒体消息，其他格式（包括音频）使用文件消息。本适配器限制每次传输不超过 **20 MiB**。文件发送失败时会提示，文件仍保留在 Multica 中。
- 暂不支持群聊、通讯录、主动通知、展开合并转发消息或读取引用消息的历史正文。

回复需要微信签发的当前会话上下文凭据。如果上下文过期导致拒绝发送，请发一条新消息。Multica 不假定固定的上下文有效期。API 成功仅表示微信接受了请求，不代表对方已收到或已读；发送响应丢失时记录为结果不明，不自动重发。

## 断开连接

在智能体「集成」页签或「设置 → 消息渠道 → 微信」中选择「断开连接」。新消息停止进入智能体，已保存的回复上下文会删除，Multica 聊天记录保留。微信明确返回授权过期时也会停用连接，需要重新扫码。

## 自托管配置

生成一个持久保存的加密密钥：

```sh
openssl rand -base64 32
```

将结果配置为 API 服务的 `MULTICA_WEIXIN_SECRET_KEY`，然后重启服务。所有副本使用相同密钥，并与部署密钥和备份一起妥善保存。更换密钥会导致原凭据无法解密，需要重新连接机器人。未配置时不开放连接入口，Docker Compose 已透传此变量。

API 服务需要通过 HTTPS 访问 `ilinkai.weixin.qq.com`、微信返回的 `*.weixin.qq.com` 区域地址和 `novac2c.cdn.weixin.qq.com`。无需公网 webhook 或入站隧道。浏览器只接收二维码展示内容及状态；机器人凭据和回复上下文在服务端加密保存。

执行常规数据库迁移。共用通道管理器跨副本保证每个安装只有一条长轮询，入站引擎接受整个批次后才保存游标。最终回复通过数据库投递租约去重。待发送事件位于内存中，服务重启可能中断回复；结果不明的发送不会重放，答案与附件仍可在 Multica 查看。
