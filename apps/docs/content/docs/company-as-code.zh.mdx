公司即代码将公司的结构描述为一个 JSON 文档：楼层、小队及其章程和例行任务、智能体的角色和指令、流水线、知识类型、策略，以及目标和预算。它既可作为结构的备份，也可用来以相同形态启动第二家公司。

只有所有者和管理员可以导出或导入。

## 导出

```bash
multica company export --file company.json
```

导出内容包括：

- 楼层和小队座位；
- 小队及其章程和例行任务；
- 智能体的角色、指令和模板引用；
- 流水线及其阶段；
- 知识类型、楼层负责智能体，以及治理部分。

导出不包含密钥、运行时、知识文档、进展、开支和历史记录。文件中会说明这一点。请将密钥和知识文档保存在各自的备份中。

## 导入

```bash
multica company import --file company.json --runtime <runtime-id> --dry-run
multica company import --file company.json --runtime <runtime-id>
```

先用 `--dry-run` 运行。它会打印计划，但不写入任何内容。

- 按名称匹配实体。导入同一文件两次不会产生任何变化。
- 智能体在 `--runtime` 指定的运行时上创建。若未指定，智能体会被报告为阻塞。
- 导入的例行任务创建时为**暂停**状态。由你自己启动，或按初始公司的启动选项启动。
- 请求体上限为 8 MiB。

## 不会迁移的内容

导入不会重建以下内容，请在导入后自行检查：

- 已关闭的倡议。它们属于历史记录，不会导出。未关闭的倡议会连同其目标和预算一起迁移；
- 进展和开支。

## 迁移方式不同的内容

- 处于活动状态的小队目标以**草稿**形式迁移。请在目标页面激活它；导入不会批准它。
- 已撤销的标准授权策略以**已撤销**状态迁移，且不会批准任何内容。
- 已归档的小队以**已归档**状态迁移。其成员和例行任务不会被重新激活，例行任务保持暂停。
- 倡议按其流程名称、阶段和标题进行匹配。会创建其关联的工单，但不会移交或唤醒任何内容。

## 限制

- 导出和导入端点为 `GET /api/office/export` 和 `POST /api/office/import`。

<Callout type="warning">
导入可能创建在你指定的运行时上行动的智能体。请检查试运行计划，并确认该运行时属于你计划使用的机器。
</Callout>
