エージェントに何をしてほしいかから選びます。タスク全体を任せる、1 件だけ相談する、繰り返す仕事を設定するなどの方法があります。

<TriggerChooserDemo />

| やりたいこと | 使うもの |
|---|---|
| エージェントにタスクを任せる | エージェントまたはスクワッドに[割り当てます](/assigning-issues)。 |
| 担当者を変えずに相談する | コメントで [@メンション](/mentioning-agents)するか、そのエージェントのコメントに返信します。 |
| 同じ種類の依頼を繰り返す | コードレビューなどを[クイックアクション](/quick-actions)に保存して使います。 |
| 決まったステップで担当者を引き継ぐ | プロジェクトの[ワークフロー](/workflows)で各ステップの担当者を決めます。 |
| タスクを作らず質問する | エージェントと[チャット](/chat)を始めます。 |
| 時刻や外部イベントから繰り返し作業を始める | [オートパイロット](/autopilots)を作成します。 |
| あとでエージェントにタスクへ戻ってもらう | 待つ時刻やイベントを決めて、タスクに[ウェイクアップ](/issue-wakeups)を追加します。 |

呼び出せるのは実行権限のあるエージェントだけです。コメントの送信前には入力欄の下のプレビューを確認してください。起動せずにメモを残す場合は `/note` を使います。`backlog` のタスクは開始の準備ができるまで待機します。

## 進捗を確認する

依頼したタスクやチャットで返信を確認します。[実行ログ](/tasks)では進み具合の確認、停止、再試行ができます。始まっていない場合はコンピューターがオンラインか確認してください。続きは[トラブルシューティング](/troubleshooting)を参照してください。
