---
title: Agent profile hover card
description: Check an agent's setup, active account status, and remaining usage without leaving your current page.
---

The agent profile hover card gives you a quick operational summary wherever an agent avatar appears. Hover over the avatar to check whether the agent is ready for work before you open the full agent page.

## Agent setup

The card shows the agent's **Runtime**, **Model**, **Thinking**, **Concurrency**, and **Owner**. **Skills** is included when skills have been assigned to the agent.

## Active account

When the agent's Runtime reports a current account, the card also shows:

- The account identity and provider.
- The account status: **Available**, **Throttled**, **Paused**, **No runtime**, or **Unknown**.
- Remaining **Next 5h** and **This week** usage, including tokens used and the next reset time.

If the Runtime does not report a current account, the account section stays hidden. The card only describes the account currently selected on that Runtime; open **Runtimes** to manage accounts or inspect the full Runtime status.

Select the agent's name in the card to open the full agent page.
