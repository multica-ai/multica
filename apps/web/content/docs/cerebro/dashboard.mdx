The **Dashboard** brings workspace activity and AI usage into one place. Open it from **Dashboard** in the left navigation.

## Dashboard sections

Use the tabs at the top to switch between:

- **Overview** for workspace activity and issue summaries.
- **Runs** for usage, cost, savings, quality, and run-level debugging.
- **Messages** for message activity and spend.

## Filter the Runs view

Choose a period, then use **Add filter** to filter by person, project, runtime, source, provider, model, skill, status, cost kind, or quality signal. Active filters are shown as chips and apply to every panel. Select a chip to remove it, or use **Clear all**.

Charts, table cells, source cards, and activity cells are also interactive. Selecting one adds the corresponding filter to the whole view.

## Explore activity and usage

The Runs view includes:

- total runs, tokens, gateway cost, measured savings, and missing cost data;
- an **Activity grid** with **Hour**, **Day**, and **Month** views;
- runs and savings over time;
- breakdowns by model, outcome, person, source, runtime, provider, skill, and project;
- quality gates and skill-learning signals;
- a paginated **Matching runs** table.

Use the previous and next controls on a panel to move through its data without changing the shared filters.

## Debug a run

Select a row in **Matching runs** to open **Run & debug context**. The panel shows the source, person, outcome, linked issue or thread, runtime, provider, model, token usage, cost, measured savings, skills, and trace preview.

Use **Open full Trace** to open the complete trace when one is available.

## Create a visual

Select **New visual** to choose a visualization, **Metric**, **Dimension**, **Breakdown**, and **Grain**. The new visual uses the current Dashboard filters and remains available after reload.

Use **Configure** on a visual to adjust its setup.
