## For everyone

### Sessions

**Plan** can now be selected directly on a session. When it is active, the agent knows it may investigate the issue and write a plan, but it must not start building, edit code, run migrations, deploy, or open a pull request.

This separates planning from implementation without requiring a complete Issue workflow. The choice belongs to the individual session, remains selected after a reload, and applies to every new agent run in that session.
