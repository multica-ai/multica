# Plan

**Plan** turns one issue session into a planning-only session. The agent may investigate the issue and produce a plan, but it must not edit code, run migrations, deploy, or open a pull request.

## When to use it

Use **Plan** when you want the agent to think through a larger or unclear task before anybody starts building. You can review and adjust the direction while keeping implementation safely out of the session.

## How to use Plan

1. Open an issue and find the session you want to control.
2. Open the mode select in the session header and choose **Plan**. The highlighted control confirms that Plan mode is active.
3. Send your message in the same session. Every new agent run in that session receives the planning-only restriction automatically.
4. Choose **Build** in the same select to return the session to normal execution.

The choice is stored on the session, so it remains active after a reload.
