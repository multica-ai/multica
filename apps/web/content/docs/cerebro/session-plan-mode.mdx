# Session modes

Session modes let you choose how an agent should approach the next run in an Issue or Chat session. The selected mode stays on the session after a reload.

## Available modes

- **Auto** lets the agent choose the working style that fits the request.
- **Plan** allows investigation and planning, but no implementation or external changes.
- **Build** allows implementation and verification within the agent's existing permissions and approvals.
- **Research** is a read-only investigation that finishes with sources and uncertainty.
- **Review** reviews existing work without changing, merging, or deploying it.

Each mode also applies a matching thinking level, maximum run time, turn limit, and completion instruction. Existing permissions and approval rules always remain the hard limit.

## Choose a mode

1. Open an Issue or Chat session.
2. Open the mode select in the session header.
3. Choose **Auto**, **Plan**, **Build**, **Research**, or **Review**.
4. Send the next message in that session.

Workflow phases automatically select **Plan**, **Build**, or **Review** when that phase starts. You can still choose another mode from the header afterward.
